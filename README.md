# COLLECTANEA

Public technical knowledge base by [@46slv](https://github.com/46slv).

COLLECTANEA is a Git-backed archive for technical knowledge that should be useful outside a private workspace.

## Sections

- **Manuals** — structured, maintained documentation
- **Articles** — standalone technical writing
- **Reference** — terminology, specifications, cheatsheets, and compact lookups
- **Research** — investigations, experiments, and source-backed findings

The first major manual is planned as a Japanese-language reference for DaVinci Resolve Fusion.

## Stack

- Docusaurus
- Markdown / MDX
- GitHub
- GitHub Pages
- GitHub Issues / Pull Requests for corrections and contributions

## Local development

```bash
npm install
npm start
```

Production build:

```bash
npm run build
```

## Contribution

Technical corrections, missing information, and readability improvements are welcome. Use an Issue for discussion or a Pull Request for a concrete edit.
