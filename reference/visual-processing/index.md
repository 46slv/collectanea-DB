# 映像表現と画像処理

映像の仕上がりを見て「これは何という処理か」「どの値を変えると、この見た目になるか」を探すための索引です。静止画の画像処理、動画固有の時間処理、撮影・レンズ由来の表現を横断します。

ここでの**技法・現象の名前**は、After Effectsのエフェクト名やDaVinci Resolveのノード名と必ずしも一致しません。まず仕組みと見た目を説明し、ソフト別の実現方法は検証したうえで個別ページから案内します。

このページは**最初の分類案**です。網羅済みの辞典ではありません。詳細解説・操作できるデモは、実装と確認が済んだ項目から増やします。最初の実験は[ディザリング](./dithering.mdx)です。

## 見た目から探す

- **滑らかなグラデーションが縞になる／粒で滑らかに見せる** → [階調・色・量子化](#tones)（Banding、Quantization、Dithering）

- **光がにじむ／レンズを通したように見える** → [光・レンズ・フィルム](#optics)

## 階調・色・量子化 {#tones}

| 用語 | 何が変わるか |
| --- | --- |
| **露出（Exposure）** | 画像の明るさを露光量に相当する考え方で変え、暗部からハイライトまでの分布を動かす。 |
| **コントラスト（Contrast）** | 暗いところと明るいところの差を広げたり縮めたりする。[倍率とピボットを操作して比較](./contrast.mdx)。 |
| **ガンマ（Gamma）** | 主に中間調の明るさの変化を扱う。どの色空間・処理位置で行うかによって挙動は異なる。[べき乗カーブを操作して比較](./gamma.mdx)。 |
| **トーンカーブ（Tone Curve）** | 入力の明るさや色の値を、曲線で別の出力値に対応させる。 |
| **トーンマッピング（Tone Mapping）** | 広い輝度範囲を、表示可能な範囲へ圧縮・再配置する。 |
| **ホワイトバランス（White Balance）** | 光源の色かぶりを補正し、白や灰色の見え方を調整する。 |
| **彩度（Saturation）** | 色の鮮やかさを上げ下げする。 |
| **色相の変更（Hue Shift）** | 色の方向を回転させ、赤を橙にするなど色味を移動する。 |
| **特定色の調整（Selective Color）** | ある色域だけを選んで色相・彩度・明るさなどを変える。 |
| **カラーグレーディング（Color Grading）** | ショット全体の色・明暗の関係を整え、視覚的な意図を作る工程。 |
| **ルックアップテーブル（LUT）** | 入力値と出力値の対応表を用いて、色や明るさを変換する。 |
| **色空間変換（Color Space Transform）** | 色域や伝達特性が異なる表現の間で、色を正しく扱うために値を変換する。 |
| **ビット深度（Bit Depth）** | 1成分を何段階の値で表せるかに関係する。少ないと階調が粗くなりやすい。 |
| **量子化（Quantization）** | 連続的・高精度な値を限られた段階に丸める。色数や階調が減る。[仕組みと4階調の操作実験](./quantization.mdx)。 |
| **ポスタリゼーション（Posterization）** | 階調の段数を減らし、明暗や色をはっきり分かれた面として見せる。[階調数を変えて面表現を試す](./posterization.mdx)。 |
| **バンディング（Banding）** | 本来滑らかなグラデーションに、意図しない帯状の段差が見える現象。[操作して比較する](./banding.mdx)。 |
| **ディザリング（Dithering）** | 限られた階調・色数の中で画素の配置を工夫し、段差を視覚的に目立ちにくくする。[操作して比較する](./dithering.mdx)。 |
| **閾値処理（Thresholding）** | 明るさなどが一定の境界を超えるかによって、画素を二値または少数の状態へ分ける。[操作して二値化を比較する](./thresholding.mdx)。 |
| **色域外処理（Gamut Mapping）** | 表示・出力できない色を、扱える色域の中へどう収めるかを決める。 |
| **クロマサブサンプリング（Chroma Subsampling）** | 輝度に対して色差情報の解像度を減らす信号表現。細かな色境界に影響が出る場合がある。 |

### 最初の操作できる実験：ディザリング

例えば「黒から白へ滑らかに変化するグラデーションを、4階調で表現する」と、明るさが4段の帯に分かれます。ディザリングでは黒と白、または近い明るさの画素を細かく配置し、人の目で見たときに中間の明るさがあるように感じさせます。

[ディザリングの詳細記事と操作デモ](./dithering.mdx)では、**階調数・ディザ方式・パターンサイズ・表示倍率・元画像**を変え、ディザなしの量子化結果と並べて観察できます。

## ぼかし・輪郭・ノイズ {#filters}

| 用語 | 何が変わるか |
| --- | --- |
| **ガウシアンブラー（Gaussian Blur）** | 周囲の画素を距離に応じて混ぜ、画像全体をなめらかにぼかす。[操作して比較する](./filters/gaussian-blur.mdx)。 |
| **ボックスブラー（Box Blur）** | 一定範囲の画素を均等に平均し、輪郭をぼかす。[操作してGaussian Blurと比較](./filters/box-blur.mdx)。 |
| **方向性ブラー（Directional Blur）** | 決めた方向へ画像を引き延ばしたようなぼけを作る。[角度と半径を操作して比較](./filters/directional-blur.mdx)。 |
| **バイラテラルフィルタ（Bilateral Filter）** | 距離だけでなく明るさの近さも見て平均し、輪郭を残しながら平滑化する。[Gaussian Blurと操作して比較](./filters/bilateral-filter.mdx)。 |
| **ガイド付きフィルタ（Guided Filter）** | 同じ画像や別のガイド画像の構造を利用して、輪郭を保ちながら平滑化する。[自己ガイドと理想ガイドを操作して比較](./filters/guided-filter.mdx)。 |
| **メディアンフィルタ（Median Filter）** | 近傍の中央値へ置き換え、孤立した明暗のノイズなどを除去する。[塩胡椒ノイズとGaussian Blurを比較](./filters/median-filter.mdx)。 |
| **シャープニング（Sharpening）** | 輪郭付近の局所的なコントラストを強め、細部がくっきり見えるようにする。 |
| **アンシャープマスク（Unsharp Mask）** | ぼかした画像との差から輪郭成分を取り出し、元画像へ加えて強調する。[輪郭とハローの比較](./filters/unsharp-mask.mdx)。 |
| **ハイパスフィルタ（High-pass Filter）** | ゆっくり変化する成分を抑え、輪郭や細部のような急な変化を取り出す。 |
| **エッジ検出（Edge Detection）** | 隣り合う画素の変化が大きい場所を取り出し、輪郭線に近い画像を作る。[Sobel輪郭抽出を試す](./filters/sobel-edge-detection.mdx)。 |
| **ガウス差分（Difference of Gaussians / DoG）** | ぼかし幅の異なる2つの画像の差から局所的な明暗変化を取り出す。[2種類のぼかしを比較する](./filters/difference-of-gaussians.mdx)。 |
| **膨張・収縮（Dilation / Erosion）** | マスクや画像内の明るい領域を広げたり狭めたりする。 |
| **空間ノイズ除去（Spatial Noise Reduction）** | 同じフレーム内の画素を比較し、細部を残すこととノイズを減らすことのバランスを取る。 |
| **エンボス（Emboss）** | 明暗の差に方向性をつけ、表面が浮き彫りのように見える陰影を作る。 |

## 光・レンズ・フィルム {#optics}

| 用語 | 何が変わるか |
| --- | --- |
| **グロー（Glow）** | 明るい領域から周囲へ光がにじんだような見え方を加える。 |
| **ブルーム（Bloom）** | とくに強い光やハイライトの広がりを再現する処理。Glowと呼び分けない実装もある。[操作して比較する](./optics/bloom.mdx)。 |
| **ハレーション（Halation）** | フィルムなどで強い光の周囲に赤みを帯びたにじみが出る現象や、その再現表現。 |
| **レンズフレア（Lens Flare）** | 強い光がレンズ内で反射・散乱し、光条や円形の像などが重なる現象。 |
| **ゴースト（Lens Ghosting）** | レンズ面の反射で、光源に対応した複数の像が画面内へ現れる。 |
| **周辺減光（Vignetting）** | 中央より画面周辺が暗くなる現象。演出として後付けすることもある。 |
| **色収差（Chromatic Aberration）** | 波長ごとの結像差によって、輪郭に色のずれやにじみが生じる。 |
| **レンズ歪曲（Lens Distortion）** | 直線が外側へ膨らんだり内側へ曲がったりして見える幾何学的な歪み。 |
| **被写界深度（Depth of Field）** | 距離によりピントが合って見える範囲が変わり、前景・背景がぼける。 |
| **ボケ形状（Bokeh）** | ピント外の点光源や模様が、絞り形状などを反映したぼけの形になる。 |
| **回折（Diffraction）** | 光が開口部などで広がることで、解像感や光条の形に影響する。 |
| **ライトラップ（Light Wrap）** | 合成した前景の縁に背景の光が回り込んだような明るさや色を加える。 |
| **フィルム粒子（Film Grain）** | フィルムの粒状構造に由来する明暗・色の細かな揺らぎを再現する。 |
| **ゲートウィーブ（Gate Weave）** | フィルムの搬送や位置ずれに由来する、ごく小さな画面の揺れを再現する。 |

## 透明度・合成・キーイング {#compositing}

| 用語 | 何が変わるか |
| --- | --- |
| **アルファ合成（Alpha Compositing）** | 透明度を使って前景と背景の画素を混ぜ、1枚に重ねる。 |
| **アルファマット（Alpha Matte）** | 透明度情報を使い、画像の見せる場所と隠す場所を決める。 |
| **ルミナンスマット（Luma Matte）** | 別画像の明るさを透明度の情報として利用する。 |
| **ブレンドモード（Blend Mode）** | 画像同士の明るさ・色を加算、乗算、スクリーンなど異なる計算方法で合成する。 |
| **プリマルチプライドアルファ（Premultiplied Alpha）** | 透明度をRGBへあらかじめ反映した画素表現。誤って扱うと輪郭に縁が出る。 |
| **クロマキー（Chroma Key）** | 緑や青など指定した色を手がかりに、背景を透明化して被写体を抜き出す。 |
| **ルマキー（Luma Key）** | 明るさの範囲を手がかりに、映像を抜き出す。 |
| **ロトスコープ（Rotoscoping）** | 被写体の形に合わせてマスクを作り、時間に沿って追従・修正する。 |
| **スピル除去（Spill Suppression）** | グリーンバックなどの色が被写体の縁に映り込んだ部分を補正する。 |
| **エッジ補正（Edge Refinement）** | 抜き出した髪・半透明部分・輪郭の硬さや色を整える。 |
| **差分マット（Difference Matte）** | 参照画像との差を利用して、変わった領域を取り出す。 |
| **深度合成（Depth Compositing）** | 奥行き情報を使い、前後関係や遮蔽を考慮して画像を重ねる。 |

## 画素の配置・幾何変形 {#geometry}

| 用語 | 何が変わるか |
| --- | --- |
| **リサンプリング（Resampling）** | 拡大縮小や変形の際に、元画像の画素から新しい位置の値を計算する。 |
| **最近傍補間（Nearest-neighbor Interpolation）** | 最も近い画素をそのまま使い、拡大時に四角い画素の輪郭が残る。 |
| **バイリニア補間（Bilinear Interpolation）** | 周囲4画素を混ぜ、拡大縮小を滑らかにするが輪郭が柔らかくなりやすい。 |
| **バイキュービック補間（Bicubic Interpolation）** | より広い周辺画素を用い、滑らかさと輪郭の見え方を調整する。 |
| **エイリアシング（Aliasing）** | 細い線や高周波模様が、階段状・モアレ・偽の動きとして見える現象。 |
| **アンチエイリアシング（Antialiasing）** | 画素より細かな線や斜めの輪郭に生じるギザつきを抑える。 |
| **ピクセレーション（Pixelation）** | 大きな色のブロックを作り、低解像度の画素が見える表現にする。 |
| **ディスプレイスメント（Displacement）** | 別画像の明るさ・色・ベクトルなどを使い、画素の参照位置をずらす。 |
| **ワープ（Warp）** | 一部の領域を引っ張り、曲げ、押しつぶすなど、画像の形を連続的に変える。 |
| **パース補正（Perspective Transform）** | 平面を斜めから見たように四隅や遠近関係を変換する。 |
| **コーナーピン（Corner Pin）** | 四隅を指定して画像を変形し、壁面や画面などの平面に合わせる。 |
| **モーフィング（Morphing）** | 形や画像の対応点を移動させ、別の形へ徐々に変化させる。 |
| **タイリング（Tiling）** | 小さな模様や画像を規則的に敷き詰める。 |
| **万華鏡（Kaleidoscope）** | 一部の画像を反射・回転して繰り返し、対称的な模様を作る。 |

## 時間・動き・フレーム {#temporal}

| 用語 | 何が変わるか |
| --- | --- |
| **フレームレート（Frame Rate）** | 1秒間を何枚の静止画像で表現するか。動きの刻み方に影響する。 |
| **リタイミング（Retiming）** | 映像の時間の進み方を変更し、スロー・早送り・速度変化を作る。 |
| **フレームブレンド（Frame Blending）** | 前後のフレームを重ねて中間の絵を作る。被写体が二重に見える場合がある。 |
| **オプティカルフロー（Optical Flow）** | フレーム間の見かけの移動を推定し、動きの補間や時間方向の処理に用いる。 |
| **フレーム補間（Frame Interpolation）** | 元画像の間に新しいフレームを作る。単純な合成から動きの推定まで複数の方法がある。 |
| **モーションブラー（Motion Blur）** | シャッターが開いている間の動きを積分したような、方向を持つぼけを作る。 |
| **モーショントレイル（Motion Trail / Echo）** | 過去の位置の像を残し、動きの軌跡が見えるようにする。 |
| **スタビライゼーション（Stabilization）** | カメラの不要な揺れを推定し、画面の位置や形を補正する。 |
| **モーショントラッキング（Motion Tracking）** | 画面内の点・領域・平面などの動きを追い、別の要素を合わせる。 |
| **ローリングシャッター（Rolling Shutter）** | 画面の行ごとの撮影時刻の差によって、速い動きが斜め・歪みとして写る。 |
| **時間方向ノイズ除去（Temporal Noise Reduction）** | 複数フレームの情報を比較してノイズを減らす。動く物体には残像が出る場合がある。 |
| **フリッカー（Flicker）** | 画面の明るさや色が時間方向にちらつく現象。修正にも演出にも用いる。 |
| **コマ落とし表現（Posterize Time / Stop-motion Feel）** | 表示する動きの更新頻度を下げ、カクカクした時間表現にする。 |

## 質感・スタイル表現 {#stylization}

| 用語 | 何が変わるか |
| --- | --- |
| **ハーフトーン（Halftone）** | 印刷の網点のように点の大きさや密度で明暗を表す。 |
| **走査線（Scanlines）** | 横線などを重ね、走査方式のディスプレイを思わせる質感を作る。 |
| **CRT表現（CRT Simulation）** | 走査線、蛍光体の配列、にじみ、曲面歪みなどを組み合わせ、ブラウン管表示を模す。 |
| **VHS表現（VHS Emulation）** | 色のにじみ、水平ずれ、ノイズ、帯域制限などを使ってアナログテープ風に見せる。 |
| **グリッチ（Glitch）** | 一時的な信号障害やデジタル処理の破綻を模したノイズ・ずれ・欠落を加える。 |
| **データモッシング（Datamoshing）** | 動画圧縮のフレーム間予測が乱れたような、像が流れ残る表現を作る。 |
| **ピクセルソート（Pixel Sorting）** | 画素を明るさなどの条件で並べ替え、線状に色が引き伸ばされたような模様にする。 |
| **ソラリゼーション（Solarization）** | 特定の明るさを境に明暗や色の関係が反転したような結果を作る。 |
| **ASCIIアート化（ASCII Art）** | 画像の明暗や形を文字・記号の並びに置き換える。 |
| **セル調表現（Toon / Cel Shading）** | 明暗を少数の段階へ分け、輪郭などを強調して絵のように見せる。 |
| **色分解・版ずれ（Channel Misregistration）** | RGBや印刷色の位置をずらして、輪郭の色ズレを意図的に作る。 |
| **フィルムの傷・汚れ（Film Damage）** | キズ、埃、汚れ、フレームの揺れなどを重ねて古いフィルムのように見せる。 |

## 詳細ページの共通形（育成方針）

今後は各用語について、次の情報を**必要なものから**追加します。

1. **何が起こるか** — 初めて聞く人にも伝わる説明と、何も加工していない画像との違い。
2. **触って比較する** — 画像・動画・波形などと、意味のある調整項目。元画像へ戻す操作と、処理前後の比較も用意する。
3. **なぜそうなるか** — 画素・時間・光学・信号処理としての仕組み。近似モデルならその限界も明示する。
4. **どこで使うか** — 作品中の効果、実務上の用途、失敗しやすい条件。
5. **各ソフトで再現する** — After Effects・DaVinci Resolve（Edit/Color/Fusionなど）の確認済みの機能・ノード・設定へつなぐ。
6. **関連表現** — 似た結果でも仕組みの異なる技法や、組み合わせやすい技法へ進める。

インタラクティブな教材はこの索引と分離して実装し、別分野のページでも同じ比較・パラメータUIを再利用できるようにします。**最初の操作できる実験：[ディザリング](./dithering.mdx)**。他の項目も順次追加していきます。
