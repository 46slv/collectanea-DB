# ライトラップ（Light Wrap）

切り抜いた人物や物体を別の背景に重ねると、輪郭だけがくっきりして浮いて見えることがあります。ライトラップは、**背景の色や明るさを前景の縁へ少し混ぜる**合成処理です。明るい窓際や発光する背景など、周囲の光が被写体に回り込んで見える状況を演出するために使います。

## 三画面で試す {#try-it}

<LightWrapPlayground />

最初に「回り込みの幅」を0 pxへ動かすと、出力が元の合成に戻ります。12 pxへ戻して「混合の強さ」を0から1へ増やすと、特に背景が明るい側の輪郭の色が変わります。背景を「寒色の光」にすると色の方向が切り替わり、前景の形を四角にすると角と辺の近くでの変化が観察できます。「初期値に戻す」で設定を復元できます。

## 入力と出力、計算の仕組み

入力は教材内で合成した320 × 180 pxの背景画像と、楕円または四角の前景RGB・アルファマットです。著作権のある外部写真は使用しません。三画面には**未加工の合成／白黒マット／処理後の合成**を表示します。白い場所ほど前景が見える領域です。

操作は背景2種類、前景2種類、回り込み幅0–18 px（初期12 px）、混合強さ0–1.5（初期1）です。混合強さは1を超えると上限1へ丸める場所があります。

教材は形状から求めた内側への符号付き距離d（近似）を使い、前景側の境界から幅r以内だけ背景色を混ぜます。混合率wは次の式です。

```text
w = clamp(a × max(0, 1 − d/r), 0, 1)
```

ここでaは混合強さです。r=0の場合はw=0と定義します。背景のRGBを近傍9点で平均した値B′と前景Fをwで混ぜ、F′=(1−w)F+wB′を作ります。最後に前景アルファαと元の背景BでC=αF′+(1−α)Bと合成します。マット外には回り込みを追加しません。

## どんな場面で使うか

夜景へ人物を合成するとき、背景のネオンの色を髪や肩の縁にわずかに乗せると、前景と背景のつながりを調整できます。幅や強度が大きすぎると、輪郭に色つきの帯ができたり、被写体の色が不自然に薄まったりします。キーイング後のエッジ補正やスピル除去とは目的も処理も異なり、前景の輪郭が適切に抜けていることが前提です。

**教材の限界**：前景の楕円は距離の近似式、四角は各辺までの最短距離で処理します。背景は8-bitの表示用RGBで9点平均し、線形光の輝度演算、実際の光散乱、物理的な反射、奥行き、毛髪の細密なマットや半透明物体の正確な光輸送を再現しません。特定のAfter Effects／DaVinci Resolve／Fusion機能と数値一致するモデルでもありません。幅は画像解像度に依存する教材内のピクセル数です。

**関連表現**：[ブルーム](./bloom.mdx)は光源自体の広がり、[ハレーション](./halation.mdx)はフィルム由来の赤いにじみを説明します。[映像表現索引へ戻る](../index.md#optics)。
