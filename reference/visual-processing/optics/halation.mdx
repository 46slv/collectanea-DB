# ハレーション（Film Halation）

**ハレーションは、強い光がフィルムの感光層を通過し、内部で反射・散乱して周辺を余分に感光させる現象**です。明るい輪郭の周りに柔らかいにじみが出て、とくに赤系の縁として見える例があります。ただし、すべてのフィルムや光源で赤い輪が出るわけではありません。ハレーション防止層はこの広がりを抑える役割を持ちます。

## 三画面で観察する {#try-it}

<HalationPlayground />

左から**元画像／色付けした拡散層／合成結果**です。最初は「街灯と点光源」で、**合成強度を0 → 1.5 → 2.5倍**にして明部の周囲の変化を見てください。0では左右が一致します。**赤みを100% → 0%**にすると、赤い縁から中立色のにじみへ変わり、[Bloom](./bloom.mdx)に近い印象になります。

次に**ぼかし幅σを0 → 5 → 12 px**へ切り替えます。0では抽出した明部の外側には広がらず、幅を増やすほど広い領域へ薄く拡散します。**閾値を140 → 245/255**に上げると抽出される明部が減り、にじみも弱くなります。「光るフレームと線」では細い輪郭の周囲の変化を観察できます。リセットで初期値に戻ります。

## 入力・出力と処理手順

テスト画像は外部素材に依存しない**320×160 pxの8-bit RGB画像2種類**です。すべてブラウザ内で生成し、アップロードやカメラへのアクセスは行いません。初期値は閾値185/255、σ5 px、合成強度1.5倍、赤み100%。調整範囲は閾値140〜245、σ0〜12 px、強度0〜2.5倍、赤み0〜100%です。

1. RGBの表示用コード値から、係数0.2126R + 0.7152G + 0.0722Bの重み付き明るさを計算します。**閾値以下を0**とし、閾値から255までを0〜255へ比例写像した値を明部マスクとします。
2. 明部マスクを横・縦の**Gaussian Blur**で広げます（標準偏差σ、画像外は端画素を複製）。ここが中央パネルの元になる拡散層です。
3. 拡散層のR成分を基準に、赤み100%ではGを18%、Bを5%に、赤み0%ではRGBを同じ値に設定します。途中の値は線形に補間します。
4. 最終パネルでは元画像に **合成強度 × 色付けした拡散層**を画素ごとに加え、表示時に0〜255へ収めます。強度0は元画像そのものです。

色付けと強度だけを変えるときは、明部マスクとGaussian Blurを再計算せず、拡散層を再利用します。画面の中間パネルは**原画像を含まない効果レイヤー**です。右パネルはそれを原画像へ合成した結果で、別の独立処理ではありません。

## なぜ赤く見えることがあるか

フィルムは複数の感光層と支持体でできています。フィルム内部で光が戻ると本来の像の外側を再露光し、色や広がりは材料の構造・波長・強い光の条件などに依存します。反射を抑える**アンチハレーション層**の方式も一様ではありません。たとえばKodakは2025年、従来の一部のVISION3で使われたremjetに代わるAnti-Halation Undercoat（AHU）構造を発表しました。「映画用フィルムは必ずremjet」「remjetが無ければ必ず大きな赤い輪が出る」とは言えません。

## BloomやLens Flareとは何が違うか

[Bloom](./bloom.mdx)は明部を抽出・拡散・合成する**画像処理の構成**を指します。この教材の実装も計算上は色付きBloomの一種ですが、模したい現象はフィルム内の再露光です。[レンズフレア](../index.md#optics)は主に撮影光学系内部の反射・散乱による像で、フィルムの感光層とは場所も原因も異なります。別の現象が写真上で同時に現れることはあります。

## 制約・制作時の注意

この実験は、**ハレーションの赤いにじみを理解するための単純な2D表示モデル**です。フィルムの多層構造、反射光路、分光感度、現像、粒子、レンズのPSF、HDR輝度、線形光合成をシミュレートしません。赤みの係数は観察のために選んだ教育用値で、特定のフィルム銘柄の測定値ではありません。

表示エンコード済みの8-bit RGBで計算するため、高強度では色のクリップや不自然な輪が出ます。強い光がある実写へ後付けするときは、閾値・広がり・合成強度の過剰設定に注意してください。After EffectsやDaVinci Resolve/Fusionのフィルム系エフェクトと同じ数値・出力になるとは保証しません。Canvas 2D非対応の環境では画像比較は表示されず、テキストで制約を案内します。
