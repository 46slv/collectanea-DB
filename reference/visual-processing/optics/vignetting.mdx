# 周辺減光（Vignetting）

**周辺減光は、中央と比較して画面の端、特に四隅が暗く見える現象**です。レンズ・撮影系の特性として起こるほか、視線を画面内へ誘導するために編集で加えることもあります。周囲がぼける[ブルーム](./bloom.mdx)とは異なり、この教材は画素の位置に応じて明るさを下げます。

## 三画面で操作する {#try-it}

<VignettePlayground />

初期値は強さ65%、中心を保つ範囲35%、横中心50%です。強さを **0 → 65 → 100%** と動かし、元画像と四隅の変化を比較します。続いて保護範囲を **10 → 35 → 75%** と変えると、暗くなり始める場所が移動します。横中心を **50 → 70%** にして左右の減光が非対称になることを確認してください。最後に「横方向グラデーション」を選ぶと、元の明るさと減光の掛け合わせを観察できます。

## 入出力・計算モデル

- **入力**：自動生成した384×160 px、表示用8-bitグレースケール。「格子と中央光点」「横方向グラデーション」を切り替えます。
- **操作**：暗さの強さ0〜100%（5%刻み）、中心の保護範囲0〜80%（5%刻み）、中心の横位置20〜80%（5%刻み）、画像選択、リセット。
- **出力**：元画像／滑らかな減衰（smoothstep）／二乗減衰の3画面。
- **計算**：横・縦の画素位置をそれぞれ0〜1に正規化し、指定中心から最遠の画像隅までの距離を1とします。距離 r のうち保護範囲 a 以下をそのまま保持し、外側では t = clamp((r−a)/(1−a), 0, 1) とします。smoothstep は t²(3−2t)、二乗減衰は t² です。強さ s（0〜1）のとき出力は「入力 × (1−s×減衰値)」として0〜255へ丸めます。

画面縦横を別々に正規化するため、**画素座標では楕円状の減光**になります。両方式とも保護範囲内は同じですが、その外側での暗くなり方が異なります。最遠の隅では両方とも指定の減光強度に達します。位置を中心からずらすと、隅ごとの明るさも異なります。

## 観察ポイント・用途

格子画像では、四隅に進むほど線と背景の両方が暗くなり、輪郭そのものをぼかすわけではないと分かります。減衰が弱いと背景になじみ、強すぎると四隅の情報が失われます。構図の中心へ視線を集める、古いレンズの印象を加える、光量ムラの説明などに利用できます。

撮影時の周辺減光と、編集ソフトのビネットは**同じ見た目でも発生原因が異なる**ことがあります。実レンズには光学的な光量低下、遮光、絞り、焦点距離やセンサー側の要因などが関係し、ここでの2種類の曲線はそれらを計測・再現したモデルではありません。Lightroomのビネット補正・演出にも様々な設定がありますが、このUIと数値対応は保証しません。

**制約**：表示エンコードされた8-bit白黒値へ直接乗算しています。リニアライト、HDR、色チャンネル、RAWレンズプロファイル、被写体の深度、レンズの実測光量、AE／Resolve／Lightroom内部処理とは一致を保証しません。端末にCanvasがなければ画像を描画できません。入力画像は全てこのページで生成するため、外部画像の権利問題はありません。
