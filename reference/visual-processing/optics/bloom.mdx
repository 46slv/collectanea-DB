# グロー／ブルーム（Glow / Bloom）

**Bloomは明るい部分の光が周囲へ広がって見える表現**です。単なるぼかしとは異なり、元画像の輪郭や細部を保ちつつ、強い光源の周りにぼけた明るさを足します。制作ソフトによってGlowとBloomの呼び方や実装は異なります。

## 触って比較する {#try-it}

3枚の画像は左から「元画像」「中間処理」「元画像へ合成した結果」です。中間処理は「ぼかした明部」（初期値）と「明部抽出（ぼかし前）」を切り替えられます。結果を先に並べ、操作はその下に配置しています。

<BloomPlayground />

最初は明るさの閾値190/255、閾値の境界幅（Soft Knee）0階調、ガウスぼかしの幅σ=7 px、合成強度1.5倍です。**合成強度を0**にすると元画像と結果が一致します。**ぼかし幅を0**にすると輪郭の外側への広がりが消えます。閾値を上げると選ばれる領域が減り、低くすると暗めの画素も光の元になります。**境界幅を0から増やすと**、閾値をまたぐ画素が徐々に抽出され、明部の境界がなだらかになります。「光量グラデーション」に切り替え、中間画像を「明部抽出（ぼかし前）」にすると、閾値・Soft Kneeによって明部が選ばれる領域を直接確認できます。同じ設定で「ぼかした明部」に戻せば、Gaussian Blurによって光が広がる様子を分離して観察できます。光点・光線／光る枠は明るさの種類が少ないため、閾値の広い範囲で結果がほとんど変わらないことがあります。

## 入力から出力まで

この教材は384 × 160 pxの自動生成グレースケール画像を使用します。中間画像の切替は表示だけを変更し、最終合成の演算結果は変更しません。外部の写真・フォント・動画素材は必要ありません。

1. **明部抽出（Bright pass）**：境界幅0では閾値以上の画素を残し、それ未満を黒にします。境界幅を増やすと、閾値の前後の区間（閾値±境界幅/2）で抽出量を0〜100%へ線形に変えます。これは教材用の単純なSoft Kneeであり、制作ソフト固有の演算とは異なります。
2. **拡散（Spread）**：抽出した明部へ横・縦2回のガウシアンブラーをかけます。σの単位は元画像上のピクセルです。
3. **加算（Composite）**：ぼかした明部に合成強度を掛け、元画像へ足します。255を超えた値はクリップします。

プレビューの下には、処理で新たに255へ到達した画素数も表示します。合成を強くしたときに白飛びの領域が増えることを確認できます。数値は8-bit表示上の端値で、物理的な光量ではありません。

最終画像は、明部の周囲が明るくなった一方、もとの輪郭が残ります。入力のすべての画素をぼかすGaussian Blurとは異なります。

## どんな場面で使うか

夜景の光源、点灯したランプ、発光グラフィック、金属の反射などに使います。**閾値が低すぎる、または境界幅が広すぎると**背景や中間調まで白っぽくなり、**強度が高すぎると**明部が255へ張り付いて階調を失います。**ぼかし幅が大きすぎると**光源の位置が曖昧になります。小さい明部ではぼかしによってピーク値が下がり、設定によっては光がほとんど見えないことがあります。

## Gaussian Blurとの関係

Gaussian Blurは画素の値を近傍平均へ置き換える処理です。Bloomではそれを**抽出した明部だけ**に適用し、元画像へ再合成します。このためGaussian BlurはBloomの材料の一つですが、両者は同じ現象ではありません。

## このブラウザ実験で再現しないもの

演算は**表示エンコード済み8-bitグレースケール**で行います。実写の色収差、絞り形状、回折、複数スケールの拡散、フィルムハレーション、HDRの光量、linear-light合成、実際のレンズPSFは再現しません。閾値・境界幅・ぼかし幅・強度の数値もAfter EffectsやDaVinci Resolve / Fusionの同名効果との互換値ではありません。各ソフトでの設定値と処理順は実機検証の後、別記事で案内します。
