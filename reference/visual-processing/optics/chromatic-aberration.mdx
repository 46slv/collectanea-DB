# 色収差（Chromatic Aberration）

**色収差は、光の波長によってレンズでの曲がり方や結像位置が異なるため、輪郭に色の縁が現れる現象**です。細い白黒の境界で赤や青などの色が見えることがあります。

大きく分けると、波長ごとにピントの前後位置が異なる**軸上色収差（縦色収差）**と、同じ撮像面で色ごとの像の大きさや位置が異なる**倍率色収差（横色収差）**があります。この教材が操作するのは後者の簡略モデルです。

## 三画面で操作する {#try-it}

<ChromaticAberrationPlayground />

まず**最大ずれ量を0 → 7 → 12 px**と変え、元画像・放射方向・水平方向の3画面を見比べます。放射方向では中心付近の輪郭はほぼ無彩色のまま、外周ほど赤・青の縁が強くなります。水平方向では中心付近にも同じ幅の色ずれが出ます。

次に**放射方向の横中心を50 → 70%**へ移動し、色ずれの少ない場所が変わるか確認します。「明暗の縦境界と横線」に切り替えると、白黒の境界に出る色を観察しやすくなります。「初期値に戻す」で最初の状態へ戻せます。

## 入力・出力と仕組み

- **入力**：ページ内で生成する384×160 pxの8-bitグレースケール画像。格子・中央光点、または明暗の縦境界・横線の2種類。
- **操作**：各色チャンネルの最大ずれ量0〜12 px（初期7 px）、放射方向の横中心20〜80%（初期50%）、パターン、リセット。
- **出力**：元画像、中心から周辺へずれが増す放射方向モデル、全画面で一定の水平方向モデル。いずれもCanvasのRGBAで表示します。
- **計算**：G（緑）を元の位置に固定し、R（赤）とB（青）を反対向きにサンプリングします。放射方向では中心からのベクトル `(x−cx, y−cy)` を、中心から最も遠い四隅までの距離 `D` で割り、赤と青の参照位置をそれぞれ `(x∓s(x−cx)/D, y∓s(y−cy)/D)` にします。水平方向では常に `(x∓s, y)` を参照します。小数位置は双線形補間し、画像外は端の画素を繰り返します。

表示される「最大ずれ量」`s`は、**RまたはBのそれぞれがGから離れる最大距離**です。赤と青の相対距離は最大`2s`になり得ます。横中心の値は放射方向の比較にだけ反映します。

## 観察ポイント・用途と制約

格子の直線が中央では重なり、端へ行くほど色が離れることから、色ごとに倍率や像の位置が異なるイメージをつかめます。輪郭に着色するだけの場合と、実際に各色の空間位置を変える処理との差も確認できます。

**この教材は実レンズの光学シミュレーションではありません。** 放射方向の色ずれをRGBの単純な反対向きの移動で近似しています。実際の横色収差はレンズ構成・波長・画面位置に依存し、R/Bの方向や大きさも固定ではありません。縦色収差のピント差、ボケ形状、歪曲、波長スペクトル、センサー処理は再現していません。「水平方向」は機械的なチャンネル位置ずれの比較対象であり、一般的なレンズの横色収差そのものを表しません。

8-bit表示エンコード値を直接補間しており、RAW・線形光・HDR・実写レンズプロファイル、After EffectsやDaVinci Resolveの内部処理と完全には一致しません。端末がCanvasを利用できない場合、画像を描画できません。入力画像は全てページ内生成で、外部画像の権利問題はありません。
