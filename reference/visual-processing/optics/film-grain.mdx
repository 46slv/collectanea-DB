# フィルム粒子（Film Grain）

**フィルム粒子は、感光材料の微細な構造が現像後の像で不均一な密度として見える粒状感**です。白黒フィルムでは現像後の金属銀、カラーフィルムでは露光されたハロゲン化銀の位置に形成される色素像が関係します。画素に独立した乱数を加えるデジタルノイズとは、発生場所も空間的な構造も異なります。

## 三画面で粒子を観察する {#try-it}

<FilmGrainPlayground />

左が未加工の合成画像、中央が**128を中立とした粒子差分**、右が最終合成です。最初に「粒子の強さ」を **24 → 0 → 60 / 255** と動かしてください。0では右が左と完全一致し、中央は灰色一色になります。強さを上げると粒状の濃淡が目立ちます。

次に「粒子の大きさ」を **1 → 6 px** にすると、独立した細かい変動から、より大きく連続した斑へ変わります。「色粒子の混合率」を **0 → 100%** にすると、RGBが一緒に変動する単色粒子から、各成分が独立した色付き粒子へ移ります。これは色素層の忠実な再現ではありません。

「暗部を優先」を **0 → 100%** にすると明るい部分の変動を抑えます。「暗い街灯と窓」へ切り替えて比較してください。「次のフレームの粒子へ」を押すと、画像の構図は変えずに乱数の配置だけを変更します。自動再生はありません。初期値へのリセットもできます。

## 入力・出力と計算方法

入力は教材が生成する**320×180 pxの8-bit RGB画像2種類**で、外部画像のアップロードやカメラ許可は不要です。初期値は強さ24/255、大きさ2px、色粒子20%、暗部優先40%、フレーム0です。範囲はそれぞれ **0〜60/255、1〜6px、0〜100%、0〜100%**。フレーム番号は0〜4095で循環します。

1. x/yの整数格子点とフレーム番号から、固定シードのハッシュで擬似乱数を発生させます。周辺4格子点を滑らかに補間して、粒子の大きさを調整します。
2. モノクロの乱数と、RGB各チャンネル別の乱数を色粒子混合率で補間します。0%ならRGBが同じ量だけ変動し、100%なら独立します。
3. 各画素の表示用明るさを `0.2126R + 0.7152G + 0.0722B` で求め、暗部優先値を使って明部への変動量を減らします。これは**演出用の重み**で、測定されたフィルム粒状度の関数ではありません。
4. 粒子の変動幅を強さで調整し、RGB各成分へ加算して0〜255に収めます。中央は `128 + 粒子差分`、右は `元画像 + 粒子差分` です。実際の変化量の平均とクリップした成分数を表示します。

同じ設定とフレーム番号なら結果は決定的に一致します。フレームを変えても元画像は変わりません。

## 粒状感と粒状度は同じではない

Kodakの技術資料では、人が見て感じる**graininess（粒状感）**と、一定条件で測った密度の変動を表す**granularity（粒状度）**を区別しています。後者の例である diffuse rms granularity は、画像密度の標準偏差に基づく測定値です。一般にフィルム銘柄や露光・現像・観察倍率によって見え方が変わるため、本教材の「強さ24」を特定フィルムの粒状度24と読み替えることはできません。

細かい粒子を持つフィルムもあれば、粗い粒子が目立つフィルムもあります。ILFORDはフィルムシリーズ間で乳剤技術や粒子の細かさが異なることを案内しています。光学的なピント外の[ボケ](./bokeh-shape.mdx)や、強い光の[ハレーション](./halation.mdx)とも発生機構は別です。

## 実務で確認したいこと

同じ粒子を固定したまま拡大・縮小すると、粗さの見え方は変わります。映像では全フレームに同じノイズを固定するより、フレームごとに粒子の配置が変化する場合の時間的な印象も確認します。ただし過度な変動はノイズのちらつきとして目立ち、圧縮時のビットレート増加や粒子のつぶれにつながることがあります。実際の制作では**最終配信解像度・視聴距離・圧縮後**の状態でも評価してください。

## この教材の制約

本教材は**表示エンコード済み8-bit RGBへ補間乱数を加える教育用モデル**です。乳剤結晶の形状・層構造、分光感度、感光・現像反応、フィルムスキャナの粒子検出、モーションピクチャーの実測粒状度を再現しません。均一な格子補間は実際の不規則な粒子構造と異なり、滑らかな斑になることがあります。サイズはこの320px実験画像上の値で、実フィルムのマイクロメートル尺度ではありません。

sRGBのガンマや線形光での合成を厳密には扱わず、クリッピングも起きます。AEやDaVinci ResolveのFilm Grain系エフェクトと数値・出力が一致する保証はありません。Canvas 2Dが使えない場合は比較画像の代わりに説明を表示します。
