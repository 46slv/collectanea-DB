# アンシャープマスク（Unsharp Mask）

**アンシャープマスクは、元画像からぼかした画像を引いた差を元画像に加え、輪郭の周辺に明暗差を作る処理**です。失われた細部を推測して復元するものではありません。目に見える輪郭を強調することで、シャープに感じられるようにします。

## 操作して比較する {#try-it}

元画像、差分に用いるぼかし画像、処理後の順に表示します。初期値はσ = 2.0 px、強さ1.5倍です。まず強さを0にすると、処理後と元画像が一致します。中間画像の表示を「**差分**（輪郭成分）」に切り替えると、ぼかし画像の代わりに`元画像 − ぼかし画像`を可視化できます。

<SharpenPlayground />

差分画像は**128（中間灰色）が変化なし、白側が正の差分、黒側が負の差分**です。符号を見える形にするため128を足しており、これは実際の合成用マスクではありません。強い差分は表示範囲0〜255で切り詰められるため、差分の正確な大きさを読み取る用途には使えません。

強さを上げると、明るい輪郭のすぐ外に白い縁、その反対側に暗い縁が見えることがあります。これは光学的に新しい線が発生したのではなく、輪郭の周辺で明暗が行き過ぎた**ハロー**（halo）です。「緩やかな濃淡と模様」に切り替えると、弱い模様も同時に強調されます。

## 入力・出力・操作

- **入力**：384 × 160 pxの白黒テストパターン。外部写真は使用しません。
- **操作**：ガウシアンブラーのσ（0〜12 px、0.5刻み）と強さ（0〜3倍、0.25刻み）、パターン切替、中間画像の「ぼかし／符号付き差分」表示切替。
- **処理**：`blur = Gaussian(source, σ)`、`result = source + amount × (source − blur)`。表示時に0〜255へクリップします。
- **出力**：輪郭の周辺で明暗差が大きくなった8-bitグレースケール画像。

プレビューの下では、処理で新たに0または255へ到達した画素数を確認できます。強すぎる設定で生じる黒潰れ・白飛びの目安であり、復元された情報の量ではありません。

強さ0では結果が元画像と同じです。σを0にしてもぼかしとの差が0になるため、シャープ化は発生しません。σは「ぼかし分布の標準偏差」であり、他アプリのRadius値と同じ単位・効果になるとは限りません。

## なぜシャープに見えるのか

ぼかした画像は細い模様や急な境界を弱めます。元画像とぼかし画像の差には、輪郭などの局所的に変化が大きい成分が残ります。差を増幅して元に足すと、明るい側はさらに明るく、暗い側はさらに暗くなります。

似た名称でも、輪郭を検出して明暗の縁を合成する別方式や、デコンボリューションによる逆問題の推定とは処理が異なります。アンシャープマスクは**既存の輪郭の局所コントラスト**を調整する方法です。

## 実制作での用途と失敗条件

**縮小書き出し後の見た目の調整**：解像度変更で柔らかくなった輪郭を補う目的で、最終表示サイズを見ながら少量適用します。縮小前後のどちらで処理するかによって結果は異なります。

**文字・細い図形の強調**：適度なら輪郭がくっきりしますが、強すぎると白黒の縁取り、ジャギー、階調の潰れにつながります。

**実写・フィルム粒子**：輪郭だけでなくノイズ、圧縮ブロック、肌の細かな凹凸も増幅します。被写体と背景の境界に強いハローが出ると不自然になります。失われたディテールを回復する処理ではありません。

## このブラウザ教材の限界

演算は**表示用8-bitグレースケール上の近似**で、RGB各チャンネル、リニアライト、色管理、HDR、アルファ、マスク、しきい値設定、ノイズ除去は扱いません。ブラウザ上のGaussian Blur実装を内部で再利用しているだけで、After EffectsやDaVinci Resolve/FusionのSharpen/Unsharp Maskノードの完全な再現ではありません。比較画像は本来の384px幅をレスポンシブ表示するため、画面幅・補間方式によって縁の見え方も変わります。

[ぼかし・輪郭・ノイズの索引](../index.md#filters)へ戻る。概念の違いを比べるには、ガウシアンブラー（ぼかし）とBloom/Glow（明部抽出・拡散・合成）も参考になります。関連記事へのリンクは該当ページの統合後に追加します。
