# Sobel輪郭抽出（Edge Detection）

**Sobel法は、隣り合う画素の明るさの変化を調べ、変化が大きい場所を明るい線として示す処理**です。ぼかしやシャープ処理と異なり、出力するのは元画像そのものではなく、輪郭の強さを表すマップです。

## 元画像から輪郭へ {#try-it}

左から「元画像」「縦横の明るさの変化を合成した強度（方向別に切替可能）」「閾値より弱い変化を除いた輪郭」の3枚を並べます。画像を見てから、その下にあるパラメータを操作してください。

<SobelPlayground />

最初は「垂直境界と図形」・強調倍率1.00倍・閾値70/255です。「斜め境界」では線が斜めにも検出され、「細かい模様と四角」では物体の輪郭だけでなく**繰り返し模様も検出される**ことが分かります。強調倍率を上げると弱い濃淡差まで明るくなりますが、強すぎると255に張り付いて差の大きさが区別できなくなります。閾値を上げると弱い線が消えます。中間プレビューを「横方向の変化（|Gx|）」へ切り替えると縦の境界が、「縦方向の変化（|Gy|）」では横の境界が主に明るくなります。

**明暗のどちらへ変わったか**を見るには「Gx（符号あり）」または「Gy（符号あり）」を選びます。中間灰色128は変化なし、白寄りは**暗→明の正方向**、黒寄りは**明→暗の負方向**です。Gxは左→右、Gyは上→下の方向に画素値が増えると正になります。例えば左から右へ白くなる垂直境界ではGxが正になり、同じ境界の白黒を反転すると負になります。これはエッジ強度とは異なり、明暗変化の向きを観察するための表示です。

## 仕組み・入力・出力

入力は外部素材に依存しない384×160ピクセルの8-bitグレースケール画像です。各画素の周囲3×3を調べ、Sobelの横方向 `Gx` と縦方向 `Gy` の重み付き差を計算します。中央画素自身は差分の中心にあり、周囲の画素が値へ寄与します。

```text
Gx = [ -1  0 +1 ]    Gy = [ -1 -2 -1 ]
     [ -2  0 +2 ]         [  0  0  0 ]
     [ -1  0 +1 ]         [ +1 +2 +1 ]
```

勾配の強さは `sqrt(Gx² + Gy²)`。この教材では値を4で割ってから強調倍率を掛け、255でクリップして中間プレビューにします。その後、指定の閾値より小さい画素を黒にして輪郭画像を作ります。画像の外側は最寄りの境界画素を複製して参照します。

中間プレビューの初期値は**勾配の大きさ**です。方向別の絶対値表示 `|Gx|` または `|Gy|` では変化の正負を区別しません。符号あり表示は `128 + Gx × 強調倍率 / 8` または `128 + Gy × 強調倍率 / 8` を0〜255にクリップした**観察用のグレー画像**です。入力差分の数学的な実数値そのものを保持したものではありません。中間灰色128をゼロとして、明るい側を正・暗い側を負に対応させます。特に強い勾配は表示上の0または255に飽和します。これらは線の向きではなく、明るさが変わる**方向**を表します。方向別表示を切り替えても、右端の最終輪郭画像には影響しません。右端の画像は二値画像ではなく、閾値以上の強さを残すグレースケール画像です。出力で明るさが残った画素数は面積の目安ですが、現実の物体の輪郭数や長さではありません。

## 使いどころと失敗条件

輪郭候補の可視化、マスクや図形の境界の観察、シャープ処理の仕組みの説明に使えます。ただし、Sobelの「輪郭」と、人が物体として認識する「形」は同義ではありません。**細かいテクスチャやノイズも明暗差があれば反応**します。滑らかなグラデーションでは勾配が小さくなるため、閾値によって線が消えます。強調を強くするとノイズやテクスチャも増幅されます。

本教材は**表示エンコード済みグレースケール・8-bit量子化**に対する近似です。線形光量、HDR、広色域、色成分ごとのエッジ、非最大値抑制、Canny法のような連結処理はありません。Sobel演算は、実在するAfter Effects／DaVinci Resolve / Fusionの特定機能と同等の数値や結果を保証しません。ソフトごとの具体的な再現手順は別途検証後に記載します。
