# ハイパスフィルタ（High-pass Filter）

**ハイパスフィルタは、画像のゆっくりした明暗変化を抑え、細い線・局所的な境界・細かな模様などの成分を取り出す処理**です。名前の「高域」は色の明るさの高さではなく、画面内で明暗が細かく変わる**空間周波数**を指します。大きな明暗差の境界も、変化が急なら高周波成分を含みます。

## 三画面で試す {#try-it}

<HighPassPlayground />

最初は「大きな明暗境界と細い線」で、**ぼかしの標準偏差σを0.5 → 3 → 8 px**と切り替えてください。σが大きいほど、より大きな形の変化まで差分へ現れます。「低周波の模様と細かな格子」に切り替えると、細かな模様が抽出される様子が分かります。

次に**倍率を0 → 1 → 2.5**へ変えます。0では高周波表示が中立灰色になり、再合成はぼかし画像です。1では再合成は元画像と一致し、1を超えると輪郭が強調されます。強すぎる倍率は明暗の縁にハローやクリッピングを生みます。リセットで初期値へ戻せます。

## 入力・計算・出力

入力はこのページ内で生成する**320×160 px、8-bitグレースケール**の2種類の画像です。アップロードや外部画像取得はありません。σは0.5〜8.0 px（初期3.0）、差分表示と再合成の倍率は0〜3.0倍（初期2.0）です。

1. 低周波成分 L = GaussianBlur(元画像, σ) を求めます。
2. **符号付き高周波成分 H = 元画像 − L** を求めます。
3. 中央パネルは表示しやすいよう **128 + 倍率 × H** を0〜255へ収めます。128が差なし、白は正の差、黒は負の差です。これは元画像そのものの明るさではありません。
4. 右パネルは **L + 倍率 × H** を再合成します。倍率1では原理上、元画像を再現します。画面下には再合成で範囲外に出た画素数を表示します。

ガウシアン平滑化は横・縦の分離畳み込みで計算し、画像外は最も近い端の画素を複製して扱います。演算中のLとHは浮動小数値で保持し、表示時だけ8-bitへ丸めます。σ・元画像の変更時のみぼかしを再計算し、倍率だけを動かすときは既存のぼかしを再利用します。

## 使い分けと制約

[アンシャープマスク](./unsharp-mask.mdx)は元画像とそのぼかしとの差を元画像へ加える鮮明化の代表例です。この教材の右パネルも倍率1より大きい場合は同等の**高周波強調という考え方**を示します。一方、[DoG](./difference-of-gaussians.mdx)は異なる2つのぼかしを引き算するため、通過させる空間スケールが異なります。ハイパスを単なるエッジ二値化と同一視しないでください。

細部と同時に粒状ノイズも強調されます。広いぼかし幅や高倍率はオーバーシュート／アンダーシュートを起こし、クリップされた部分では本来の差を復元できません。**8-bit・表示エンコード済みのグレースケールに対する教育用近似**であり、実際の色管理、線形光での処理、HDR、カラー画像の色ごとの演算、After Effects／Resolve／Fusionの特定エフェクトとの数値同等性は保証しません。Canvasが利用できない環境では動的画像は表示されません。
