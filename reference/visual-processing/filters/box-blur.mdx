# ボックスブラー（Box Blur）

**ボックスブラーは、指定した四角い近傍にある画素を、すべて同じ重みで平均する平滑化処理**です。画像の細かな明暗変化が弱くなり、硬い輪郭には中間の灰色が生まれます。中央ほど重みが大きい[ガウシアンブラー](./gaussian-blur.mdx)と違い、Boxでは近傍の内側は等しい重み、外側はゼロです。

## 三画面で操作する {#try-it}

<BoxBlurPlayground />

まず半径を**0 → 3 → 8 px**と動かし、境界と細線の変化を観察します。次に「明るい点と細い光線」に切り替え、Boxの四角い広がりとGaussianのなだらかな広がりを比較してください。初期値はBox半径3 px（7×7画素）です。

## 入力・出力と計算

- **入力**：384×160 pxの自動生成した8-bitグレースケール画像（輪郭・細線／点光源・細線）。
- **操作**：半径 r=0〜12 px、1 px刻み。r=0 は加工なし、r=3 は7×7画素を平均します。
- **出力**：元画像、Box結果、比較用Gaussian結果の3画面。値は0〜255へ丸めて表示します。
- **Gaussianとの比較**：Boxの離散カーネル分散 r(r+1)/3 に合わせて σ=√(r(r+1)/3) を使用します。平均的な広がりをそろえる**教材上の比較**で、形状や周波数特性が一致するわけではありません。

各出力画素は、近傍の `(2r+1)²` 個の画素の合計を個数で割った値です。実装では横方向の均等平均と縦方向の均等平均へ分解し、中間値を浮動小数点のまま保持して最後に8-bitへ変換します。画像端の外側は最も近い端画素の値を延長します。

## 何が観察できるか

明暗境界では黒と白が近傍に同居するため、中間の灰色に置き換わります。細い線は背景と平均されて弱くなり、点光源の周囲には四角いぼけが広がります。Boxの近傍範囲は急に終わるため、Gaussianと比べて変化の形が異なります。

一定色の領域では値は変わりません。**ボックスブラーは輪郭保存型ではない**ため、前景・背景を分けたままノイズだけを除去したい場合には、[バイラテラルフィルタ](./bilateral-filter.mdx)や[Guided Filter](./guided-filter.mdx)も比較対象です。

## 用途と制約

画面全体のラフな平滑化やマスクの下処理などに利用できます。ただし絞りによるボケ形状、レンズの収差、Glow/Bloomの光学特性を単独で再現するものではありません。複数回のBox適用は単発のBoxとは応答が異なり、Gaussianに似た形へ近づく場合があります。

この教材は**表示エンコードの8-bit白黒値**をブラウザで演算します。リニアライト、HDR、アルファ境界、色管理、動画時間方向、AE／Resolve／Fusionの特定エフェクトの数値・端処理を再現しません。画素の半径なので、素材解像度が違えば相対的な見た目も変わります。Canvasを表示できない環境では操作結果を描画できません。
