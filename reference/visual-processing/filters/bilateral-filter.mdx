# Bilateral Filter（バイラテラルフィルタ）

**Bilateral Filterは、近くにある画素を平均するときに「位置が近いか」だけでなく「元の明るさが似ているか」も評価する**平滑化処理です。一般的なGaussian Blurでは明るい領域と暗い領域の間にも平均値が広がります。Bilateralは強い境界を横切る画素の寄与を抑えるため、条件次第ではエッジを保ったまま小さなノイズを和らげられます。

## まず結果を比較する {#try-it}

<BilateralPlayground />

初期状態は、明るさ45と205の領域を持つ人工画像に、標準偏差15階調の加法性ガウスノイズを与えています。「Gaussian Blur」と「Bilateral」は**空間σを共有**する比較で、Bilateralにだけ「輝度差σ」があります。輝度差σを10まで小さくしてノイズが残る様子、100まで大きくして境界を横断する平均が増える様子を比べてください。次に「階調と細線」を選び、小さな構造が損なわれる場合も確かめます。

ここに表示するMAE（平均絶対誤差）は、**正解画像が既知の人工テストだけ**で算出できる8-bit画素値の平均差です。数値が小さくても、重要な線が消えている場合があります。知覚画質・見た目の自然さを表す尺度ではありません。

## 入力・処理・出力

入力は224×96pxの**表示用8-bitグレースケール**画像です。ノイズを加える前の参照画像を比較用に作り、実際のフィルタ処理にはノイズ付き画像だけを渡します。各画素の出力は近傍の加重平均で、重みは次の2つを掛け合わせたものです。

- **空間重み**：近くの画素ほど大きい。距離を空間標準偏差 `σs`（px）で評価します。
- **輝度差の重み**：処理対象と明るさが近い画素ほど大きい。差を標準偏差 `σr`（0〜255階調の値）で評価します。

`w = exp(−距離² / (2σs²)) × exp(−輝度差² / (2σr²))` とし、周囲の画素値と重みの積を合計した値を、重みの合計で割ります。中央画素の重みは1なので分母は0になりません。計算範囲は各方向で**空間σの2倍を切り上げた半径**に切り詰め、画面端では最も近い端画素を複製します。

出力はGaussian BlurとBilateral Filterの異なる画素配列です。入力は変更しません。この実験のGaussian Blurは1Dカーネルを水平・垂直に順番に適用しており、Bilateralの2D重み付き演算とは内部の打ち切り方法も異なります。**両者の空間σが同じでも、計算結果が同じになることを保証しません。**

## 観察したい現象と失敗例

輝度差σを下げるほど明暗の大きく異なる領域を混ぜにくくなります。境界を守る一方で、**ノイズで明るく変化した画素まで別領域だと判断し、ノイズを残す**場合があります。反対に輝度差σを上げると明るさによる区別が弱まり、境界をまたいで平均しやすくなります。

均一な平坦部では一定量のノイズを平均できても、細い線や微細な文字、鋭いテクスチャなどは残り方が変わります。また、輝度値の差が小さい境界は「明るさが似ている」と評価されるため、必ず保存されるわけではありません。強いノイズ・広い平滑化半径・不適切な輝度差σの組み合わせで、まだらな残留や輪郭付近の不自然な平坦化が生じます。

動画では隣接フレームのノイズ配置が変わるため、**1フレームだけの良好な見た目を時間方向の安定性と混同しない**よう注意が必要です。

## この教材で再現しないこと

処理対象はディスプレイ符号化された0〜255の単一チャンネルで、シーンリニアの光量、HDR、広色域、色差・彩度を使ったカラーBilateral、ガイド画像を用いるJoint Bilateral、時間方向の処理、実在センサーの信号依存ノイズを再現しません。ブラウザのCanvas 2D・ディスプレイ補間や表示色管理で見た目が変わります。After Effects／DaVinci Resolveの特定エフェクトの忠実なエミュレーションでもありません。外部画像・追加の依存パッケージは使っていません。

Gaussian Blurとの差は「位置だけの距離による平均」と「位置と明るさの差を同時に使う平均」の違いです。どちらが良いかは入力、保持したい構造、使用目的と評価基準で変わります。
