# ガウシアンブラー（Gaussian Blur）

**ガウシアンブラーは、各画素を、周囲の画素を距離に応じた重みで混ぜた値へ置き換えるぼかし処理**です。硬い輪郭はなだらかになり、細線や模様は見えにくくなります。一定範囲を均等に混ぜるボックスブラーと異なり、中央に近い画素ほど大きな重みを持ちます。

## 入力と出力

- **入力**：384 × 160 pxの自動生成した白黒画像（輪郭と細線／明るい点と細い光線）。
- **操作**：σ（標準偏差）0〜12 px、0.5刻み。単位は元画像上の画素数です。
- **処理**：ガウス分布の重みを正規化し、横方向と縦方向に分けて周辺画素を平均します。計算範囲は約3σです。
- **出力**：明暗の境界が滑らかになった画像。細部のコントラストは失われます。

## なぜ輪郭が柔らかくなるのか

σが小さいとごく近くの画素が強く影響します。σを大きくすると広い範囲が混ざるため、白と黒の境界は中間の灰色を伴って広がります。重みの合計は1なので、均一な領域の明るさはほぼ保たれます。明るい点は周囲へ明るさを分けるため、広がる一方で中心は暗くなります。

実装は**横方向→縦方向**の2回の計算で構成しています。画像端を越える参照は、端の画素値を延長して計算します。

## 制作での用途と失敗条件

**背景の整理**：背景の細部を抑えて前景を見やすくします。ただしレンズの被写界深度や絞り形状は、この処理だけでは再現できません。

**マスクの境界**：マスクの輪郭をぼかし、合成の硬い縁を和らげます。RGB画像自体をぼかす処理とは対象が違います。

**Glow/Bloomの下処理**：明るい部分を抽出し、ぼかして元画像へ合成します。画像全体をぼかすだけでは発光の表現になりません。

文字・髪・細線などのディテールは消えやすく、被写体の境界では前景と背景の色が混ざります。解像度を変えると同じσでも画面に対するぼかし幅は変わります。
