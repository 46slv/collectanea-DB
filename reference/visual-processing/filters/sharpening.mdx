# シャープニング（Sharpening）

シャープニングは、隣り合う画素の明暗や色の差を強め、輪郭をくっきり見せる画像処理の総称です。今回の教材では、上下左右または斜めを含む近傍画素との比較を使う、固定3×3カーネルのシャープ化を扱います。

輪郭がはっきり見えても、ピントが外れて失われた細部や、撮影時に記録されなかった情報が戻るわけではありません。

## 操作して比較する {#try-it}

元画像、符号付きの輪郭差分、処理後の順に表示します。初期値は上下左右4画素、差分の加算が1倍です。「差分を加える強さ」を0倍にすると、処理結果は元画像へ戻ります。

<KernelSharpenPlayground />

最初の「色の面と細い線」では、明るい面と暗い面の境界に沿って縁ができます。「細部とノイズ」へ切り替えると、細かな濃淡の揺れも増幅されることを確認できます。近傍を8画素にすると斜め方向の画素も平均へ入るため、差分の出方が変わります。

中央の差分画像は、各RGB成分の差に128を足し、観察しやすいよう1.5倍して表示しています。灰色128が差0、128より明るい成分が正、暗い成分が負です。これは差分の可視化であり、合成に使用する画像そのものではありません。

## 入力・処理・出力

- 入力：320 × 160 pxの自動生成された8-bit RGBパターン2種類。外部の写真・映像素材は使用しません。
- 近傍：中心の上下左右4画素、または斜めを加えた周囲8画素。画像の外を参照するときは最も近い端の画素を繰り返します。
- 強さ：0〜3倍（0.25刻み）。初期値1倍。選んだ近傍から得た平均との画素差を元画像へ加えます。
- 出力：RGB各成分で局所的なコントラストを強めた画像。0〜255を超えた値はクリップします。プレビュー下の数値は範囲外になったRGB成分数です。

中心画素を `C`、周囲の平均を `M`、強さを `a` とすると、輪郭差分は `D = C − M`、出力は `clip(C + a × D, 0, 255)` です。中心と周囲が同じ値なら差は0のため変化しません。

上下左右4近傍の場合、差分は `C − (上 + 下 + 左 + 右) / 4` です。これは符号を反転して正規化した4近傍の離散ラプラシアン（2次差分）に相当します。斜めを含む8近傍では、平均の対象が8画素になります。どちらも中心と周囲の合計係数が1になるシャープ化カーネルですが、輪郭の方向や細かな模様への反応が同一とは限りません。

## 使い分けと失敗しやすい条件

**縮小した画像の輪郭**：細い線や文字をはっきりさせたいときに、最終表示倍率を見て弱く調整します。拡大表示でシャープに見えても、通常サイズで白黒の縁取りが目立つことがあります。

**ノイズの多い素材**：輪郭とノイズはどちらも近傍との差を持つため、この処理ではノイズや圧縮由来の小さなブロックも強調されます。「細部とノイズ」で強さを上げると、その副作用を観察できます。

**彩度の高い境界**：RGBをそれぞれ処理するため、色成分ごとのクリップで輪郭に色の縁が出る場合があります。プレビュー下の範囲外成分数は、その一つの目安です。クリップ数が0でもハローや不自然な質感が生じない保証にはなりません。

## 似た処理との違い

[アンシャープマスク](./unsharp-mask.mdx)は、一定の幅でぼかした画像と元画像の差を足す処理です。今回のカーネルは隣接1画素だけを比較し、ぼかし半径を指定しません。[Sobelによるエッジ検出](./sobel-edge-detection.mdx)は主に方向付きの1次微分で輪郭を抽出します。[DoG](./difference-of-gaussians.mdx)は異なるぼかし幅の差を取ります。いずれも輪郭に反応しますが、処理の目的と出力は異なります。

## このブラウザ教材の限界

このデモは、表示用の8-bit sRGBコード値に直接適用する教育用のRGB処理です。線形光、HDR、RAW、アルファ、マスク、適応型シャープ化、デコンボリューション、時間方向のノイズ除去を扱いません。After EffectsやDaVinci Resolve/Fusionの特定エフェクトと同じ内部処理・値になることは保証しません。320px幅のCanvasを画面幅に合わせて縮小表示するため、閲覧環境の補間によって細い縁の見え方も変わります。
