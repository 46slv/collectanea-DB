# Guided Filter（ガイド付きフィルタ）

**Guided Filterは、別の画像（ガイド）に見える構造を手がかりに、処理対象の画像を平滑化する方法**です。各画素を単純に平均する代わりに、局所的な範囲で「ガイドが変わると出力がどのように変わるか」を一次式で表します。ガイドと処理画像を同じにする自己ガイドでは、強い輪郭を保ちながら小さな変動を抑える働きを観察できます。

## まず4画面で試す {#try-it}

<GuidedFilterPlayground />

初期値は「明暗境界と矩形」、ノイズ標準偏差20階調、半径3px、正則化の目安20階調、自己ガイドです。まず**近傍半径を1→6px**へ動かし、平坦部のノイズと境界の変化を見ます。次に正則化を5→75階調へ動かしてください。大きくすると、ガイドの小さな変動に追従しにくくなり、局所的な平均に近い傾向になります。細線のパターンでは、平滑化で線が弱くなることも確認できます。

「ガイドの種類」を**理想ガイド**へ切り替えると、ノイズを加える前の人工画像をガイドとして渡します。ノイズ入力と異なるガイドで形を保つ可能性を見せるための実験であり、**未知の実写画像からノイズのない正解画像を取り出せると仮定した実務手順ではありません**。実際の応用では位置合わせ済みの別モダリティ画像・高品質の参照・別途用意した構造情報などをガイドにする場合があります。

表示するMAEは、**正解画像を別に持つ人工テストでの0〜255階調の平均絶対誤差**です。数値が下がっても細線・局所構造が消えることがあります。ノイズ入力、ガイド、出力の見た目を併せて判断します。

## 入力・処理・出力

- **処理対象 p**：224×96pxの8-bitグレースケール画像。人工の明暗境界または階調＋細線に、固定seedの加法性ガウスノイズを加えます。
- **ガイド I**：処理対象そのもの（自己ガイド）またはノイズなし人工画像（理想ガイド）。必ず同じ画素配置・寸法で比較します。
- **半径 r**：1〜6pxを操作可能。各位置を中心に最大 (2r+1)×(2r+1) 画素の窓を使います。
- **正則化 ε**：画面の「正則化の目安」L階調を0〜1へ正規化し、ε=(L/255)² として計算します。これは**OpenCVのεを直接指定するUIではありません**。
- **出力 q**：別の8-bit配列。入力とガイドは変更しません。画素値0〜255への丸めとクランプは最後に行います。

各窓では、ガイドIと出力qを **q=aI+b** で近似すると考えます。窓の平均、分散、共分散から次を求めます。

- a = cov(I,p) / (var(I)+ε)
- b = mean(p) − a × mean(I)

各画素を含む複数の窓から計算されたaとbを再び局所平均し、最終的な **q = mean(a) × I + mean(b)** を得ます。分散が小さい場所ではεが傾きを抑え、ガイドに明確な変化がある場所では条件次第で構造を残せます。ただし**すべての境界・細部が常に維持されるわけではありません**。

この教材では各局所平均を積分画像による矩形平均で計算します。端の窓は画面内に切り詰め、存在する画素数で割ります。これは境界画素の複製ではありません。演算途中は倍精度値、表示結果のみ8-bitへ変換します。窓ごとに個別の最小二乗問題を解く代わりに局所平均を組み合わせる、グレースケールの標準的な定式化を使っています。

## 観察できる違いと失敗例

自己ガイドでは**ノイズそのものもガイドの変化として見える**ため、正則化が小さすぎるとノイズの揺れが残る場合があります。理想ガイドでは人工画像の構造がはっきりしているためノイズが抑えやすくなることがありますが、ガイドにない本来のテクスチャをpから削ってしまう可能性もあります。

ガイドの輪郭と処理対象の輪郭がずれていると、不適切な場所に構造が転写されることがあります。大きな半径・強い正則化では細い線が弱まる場合もあります。実写のノイズは明るさ・色・時間・センサーによって変わり、今回の単純な人工ノイズと同じ結果になるとは限りません。

[Gaussian Blur](./gaussian-blur.mdx)は主に位置の近さに基づく平均、[Bilateral Filter](./bilateral-filter.mdx)は位置と画素値の差に基づく重み付き平均です。Guided Filterはガイドとの**局所的な線形関係**を使い、異なる画像から構造を借りることもできる点が特徴です。これらは用途も計算も異なり、特定条件での優劣を普遍化できません。

## 再現範囲と制約

このページは**表示符号化された8-bit単一チャンネルの静止人工画像**を扱います。線形光量、HDR/広色域、色ガイド、動画の時間方向ノイズ除去、実センサー由来のノイズ、サブピクセル位置合わせ、深度画像のアップサンプリング等は再現しません。精度・窓端処理・ガイドの前処理も各ライブラリと異なります。After EffectsやDaVinci Resolveの特定エフェクトを同一計算で模したものではありません。外部の映像素材や追加パッケージは使用していません。

Canvas 2D上の表示は端末・補間・色管理に依存します。キーボード・タッチで標準のスライダー／選択欄を操作でき、結果を先に表示します。Canvasが使えない環境ではその旨を示します。
