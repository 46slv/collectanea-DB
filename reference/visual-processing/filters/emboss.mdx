# エンボス（Emboss）

**エンボスは、画像の明暗の変化を一方向から読み取り、境界の片側を明るく、反対側を暗くして、浮き彫りに見せる画像処理**です。平らな領域を中間灰色に置くと、境界の陰影が目立ちます。実物の立体形状や光源を復元しているわけではありません。

## 三画面で差を観察する {#try-it}

<EmbossPlayground />

左が入力、中央が方向付きの明暗差（128が差0）、右が陰影を加えた結果です。まず「階段と矩形」を選び、**差分方向を右 → 左**に変えてください。明暗の向きが反転し、浮き上がり方の印象が変わります。次に**差分の距離を1 → 5 px**にすると、近傍の比較位置が離れて陰影の幅も変わります。

**陰影強度を0 → 1.5 → 3倍**にすると、灰色を中心とした明暗差が増幅されます。**元の階調を0**にすると平らな領域は128の中間灰色になり、0.5へ近づけると入力の明暗が薄く残ります。強度と元の階調をともに0にすれば一様な灰色になります。「同心円」では向きが違う輪郭を観察してください。初期値へ戻すボタンがあります。

## 入力・出力と計算

入力はブラウザ内で自動生成する **320×160 pxの不透明な8-bit RGBテスト画像2種類**です。アップロードや外部画像は不要です。初期値は右方向、距離2 px、陰影強度1.5倍、元の階調0.15倍。範囲は4方向、距離1〜5 px、強度0〜3倍、階調0〜0.5倍です。

1. 入力の表示用RGBコード値から、`Y = 0.2126R + 0.7152G + 0.0722B` を画素ごとに求めます。ここでの`Y`は表示コード値の重み付き和であり、線形光の物理的輝度ではありません。
2. 方向と距離に対応するずれ`(dx, dy)`を選び、`D(x,y) = [Y(x+dx,y+dy) - Y(x-dx,y-dy)] / 2` を計算します。画像の外側は端画素を繰り返します。中央パネルは`clip(128 + D)`を灰色画像にしたもので、暗い部分は負、明るい部分は正の差分です。
3. 出力は`E(x,y) = clip(128 + 強度 × D(x,y) + 階調係数 × [Y(x,y) - 128])`です。`clip`は0〜255へ収める操作で、結果を8-bit灰色RGBとして表示します。

方向を逆にすると`D`の符号が反転します。これは**差の符号を捨てる輪郭強度画像**とは異なる点です。陰影強度と階調係数は計算済みの差分を再利用して変えられます。

## 輪郭検出・実際の凹凸との違い

[Sobelによる輪郭検出](./sobel-edge-detection.mdx)は横と縦の変化を組み合わせて輪郭の強さを調べる方法の一例です。一方、この教材は**指定した一方向の差の正負**を灰色の明暗へ残しているため、比較方向を変えるとハイライトとシャドウが入れ替わります。

本物の凹凸へ光を当てるには、表面の高さや法線、光源、反射特性など別の情報が必要です。エンボス画像はそれらを推定せず、**2D画像の境界を照明された起伏のように見せる**表現です。

## 制約と検証範囲

この教材は表示用8-bit RGBの重み付き和と対向2点差分による教育用近似です。畳み込みフィルタとして表現できる処理ですが、OpenCVやAfter Effects、DaVinci Resolve/Fusionの特定のEmboss実装とカーネル、係数、境界処理が同じとは限りません。色、透過、HDR、シーンリニア処理、実際の幾何形状・照明は再現しません。強い設定では0/255で階調がクリップされます。Canvas 2Dが利用できない場合、プレビューは非表示となり説明文で知らせます。
