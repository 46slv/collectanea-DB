# 方向性ブラー（Directional Blur）

**方向性ブラーは、画素の周囲を円や四角ではなく、指定した方向に沿う線として平均する処理**です。光点が線状に伸び、方向と直交する細い境界ほどぼけ方が変わります。全方向に広がる[ガウシアンブラー](./gaussian-blur.mdx)とは、ぼけの形が異なります。

## 三画面で操作する {#try-it}

<DirectionalBlurPlayground />

初期値は線の半径7 px、方向0°（横）です。まず方向を**0° → 45° → 90°**と動かし、同じ光点がどちらへ伸びるか確認します。次に半径を**0 → 7 → 16 px**へ変え、横方向と直交方向の残り方を比較してください。「矩形と斜線」に切り替えると輪郭の変化が分かります。

## 入力・出力と仕組み

- **入力**：384×160 pxの自動生成8-bitグレースケール画像。「光点と縦線」「矩形と斜線」の2種類。
- **操作**：角度0〜180°（15°刻み）、線の半径0〜16 px（1 px刻み）。0°は横、90°は縦です。
- **出力**：元画像、指定方向のぼけ、90°直交させたぼけの3画面。半径0 pxは加工なしです。
- **計算**：出力位置を中心に、角度θに沿って −r〜+r pxを1 px間隔で **2r+1点**サンプリングし、同じ重みで平均します。斜め方向の画素間値には双線形補間を使います。画像端を越えた座標は端画素に固定し、最後に0〜255の整数へ丸めます。

ここでいう「半径」は、線形フィルタの片側へ何pxサンプルするかです。線の全長は両端間で2r pxです。例としてr=7は両端間14 px、15点の平均になります。**回転した画像を重ねているのではなく、各出力画素の近傍を方向付きに集計しています。**

## 何が観察できるか

明るい点は線状へ広がります。長い線と同じ向きに平均すると線の明るさが比較的残り、線を横切る方向では背景が混ざって細線が弱くなります。角度を90°変えた比較画面を見ると、方向に依存するぼけだと確認できます。

方向性ブラーは**必ずしもモーションブラーと同じではありません**。この教材は静止画像の空間平均です。実際のシャッター開放中の移動には、加速度、被写体と背景の遮蔽、露光時間、動きごとのベクトルなどが関係します。

## 用途と制約

線状の残像表現、マスクの方向付き軟化、移動感のラフな試作などに使えます。一方、回転ぼけ、ズームぼけ、レンズ由来のボケ、奥行き差や物体ごとの運動は、この固定方向の平均だけでは再現できません。

計算対象は**表示エンコードされた8-bit白黒値**です。リニアライト、HDR、アルファ、色収差、端処理の選択、AE／Resolve／Fusionの特定エフェクトの内部実装とは一致を保証しません。斜め方向では補間そのものにも平滑化作用があります。Canvasが使えない端末では描画結果を表示できません。
