# バンディング（Banding）

バンディングは、滑らかにつながって見えるはずの明るさや色の変化が、帯状の境界として目立つ現象です。空のグラデーション、暗い背景、柔らかな光の周囲などで気付くことがあります。

**帯が見えることは観察結果であって、原因そのものの名前ではありません。** 階調の丸め（量子化）は分かりやすい発生例ですが、制作から再生までのどの段階で帯が生じたかは、元の値や処理順を調べなければ確定しません。

## 入力・変化・出力

- **入力**：少しずつ明るさが変わるグラデーションなど。隣り合う画素の差は小さく、境界は目立ちません。
- **変化**：階調数を減らす、値を丸める、色変換や出力で精度が不足するなどの要因により、連続していた値の一部が同じ段階へまとまります。
- **出力・観察**：同じ値にまとまった範囲が面として続き、次の段階へ切り替わる位置に帯の境界が見えます。帯が見える強さは、内容・表示・観察距離にも左右されます。

## 操作して見比べる {#try-it}

次の教材は、**元画像（左）／量子化のみ（中央）／ディザ適用結果（右）**を同時に表示します。初期設定は4階調・規則的ディザ（Bayer 4×4）です。まず中央の画像で、滑らかな明暗が帯へ分かれる様子を確認してください。

<DitheringPlayground />

1. 「階調数」を**2 → 4 → 8 → 16**と変えます。中央の帯は階調数が増えるにつれて細かくなります。16階調でも元画像と完全に一致するわけではありません。
2. 「元画像」を中心が明るいグラデーションへ変更します。帯が中心を囲む**楕円状**に見えます。この教材の384×160pxパターンは縦横を別々に正規化するため、真円ではありません。
3. 「処理方式」を「ディザなし（量子化）」にすると、右と中央が一致します。「規則的ディザ」や「誤差拡散」に切り替えると、同じ階調数のまま帯が目立ちにくくなる一方、点や粒が現れます。
4. 表示倍率を上げて粒の配置を確認した後、リセットで初期設定へ戻します。ディザは失われた元の値を復元する処理ではありません。

## なぜ帯になるのか

この教材の[量子化](./quantization.mdx)は、0（黒）〜1（白）の入力を黒白を含む**等間隔のL段階**へ丸めます。4階調なら出力値は0、1/3、2/3、1の4種類です。隣り合う異なる入力が同じ出力へ丸められるため、なだらかな変化の中に一定値の領域が生まれます。

| 入力の明るさ | 4階調へ丸めた値 | 表示用8-bit値 |
| ---: | ---: | ---: |
| 0.20 | 1/3 | 85 |
| 0.30 | 1/3 | 85 |
| 0.40 | 1/3 | 85 |
| 0.60 | 2/3 | 170 |

例えば入力0.20から0.40までは徐々に明るくなっていますが、この丸め方ではすべて85になります。0.60付近では170となり、両者の間のどこかで出力が切り替わります。入力の変化が緩やかでも、その切替位置が帯の境界として見えるわけです。

**ビット深度と階調数は区別します。** 8-bit成分には通常256個の整数コード値がありますが、この実験は意図的に4種類しか使いません。実際の映像で8-bitだから必ず同じ4本の帯になる、という意味ではありません。作業精度、変換、圧縮や表示系の条件で見え方は変わります。

## バンディングを観察したら

### どの段階で生じたか確認する

まず元素材と、カラー調整後・書き出し後・再生環境での表示を比較します。編集画面だけで見えるのか、書き出したファイルにも現れるのかを切り分けます。滑らかな暗部やグラデーションでは、値の丸め、処理順、後段の変換を確認します。**帯が見えたという事実だけで、特定のコーデックやエフェクトが原因と決めない**ことが重要です。

### 対処方法とその限界

- **中間処理の精度**：処理途中で不要に精度を落とさないようにします。After Effects公式ガイドは、より高いプロジェクト色深度がグラデーションの量子化アーティファクト低減に有効だと説明しています。ただし、最終出力側の精度まで自動的に高くなるわけではありません。
- **ディザリング**：限られた階調へ落とす際、近い値の画素を混ぜて境界を目立ちにくくします。帯が粒や模様へ変わるため、拡大表示では別の欠点が見えることがあります。
- **ノイズの追加**：細かな揺らぎによって輪郭を散らす方法がありますが、粒感や圧縮後の変化が生じ得ます。量や適用位置を決め打ちせず最終出力で確認します。

意図的な面分けを行う[ポスタリゼーション](./index.md#tones)では帯のような区切りそのものが表現になります。一方、バンディングは通常、意図しない段差を指します。似た画面でも目的が異なります。

## この教材が再現していないこと

上の比較は**静止した白黒テスト画像をCanvasで処理する、階調数2〜16の教材**です。表示用の8-bit値へ変換しており、HDR、広色域、色管理、動画圧縮、時間方向の変動やモニター側の処理を再現しません。After Effects／DaVinci Resolveの内部演算と画素単位で一致する保証はありません。

特定ソフトでの設定例は、対象バージョン・処理順と実際の出力を確認したうえで別途扱います。ここではバンディングの観察・原因の切り分け方と、限られた階調でのディザの働きを理解することが目的です。
