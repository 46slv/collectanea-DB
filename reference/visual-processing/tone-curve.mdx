# トーンカーブ（Tone Curve）と区分線形補間

トーンカーブは、**元の明るさ（入力値）をどの明るさ（出力値）へ対応させるか**を示す線です。横軸は入力、縦軸は出力で、45度の直線なら値は変わりません。線を上に曲げる領域は明るく、下に曲げる領域は暗くなります。

ここでは端点と中間点を結ぶ**2本の直線**だけを操作します。一般的なカーブ編集ソフトのベジェ補間、複数制御点、RGBチャンネル別調整を再現するものではありません。

## 入力・出力・操作

- **入力**：横方向または中心が明るい楕円状の、384×160画素の表示用8-bitグレースケール画像。
- **固定する点**：入力0 → 出力0、入力255 → 出力255。
- **変更する点**：入力128 → 出力 `m`。スライダーで `m=32〜224` を16刻みで変更します。初期値は128です。
- **補間**：0〜128の間は `y = v × m / 128`、128〜255の間は `y = m + (v−128) × (255−m) / 127`。各結果を整数へ丸め、256要素の対応表（LUT）として画素へ適用します。
- **出力**：元画像／処理後画像、入出力グラフ、入力64・128・192の出力値、暗部と明部それぞれの傾き。表示倍率は100・200・400%から選択でき、リセット可能です。

## 中間点を動かして比較する {#try-it}

まず元画像と出力画像を見比べ、その下のグラフが示す対応関係を確認してください。操作パネルはプレビューの後に配置しています。

<ToneCurvePlayground />

1. 中間点の出力が**128**なら2本が1本の斜め直線になり、入力と出力は一致します。
2. **192**へ上げると暗い側の傾きが1.5となり、入力64は96、入力128は192へ移動します。明るい側の傾きは `63/127` で、入力192は224になります。
3. **64**へ下げると暗い側の傾きが0.5となり、入力64は32、入力128は64になります。入力192は160となります。
4. 元画像を楕円へ切り替えると、同じ対応表が画面全体の明暗分布へ働くことを確認できます。200%・400%表示では8-bitの段差も見やすくなります。

## 数値で見る

| 入力 `v` | 中間点 `m=64` | `m=128`（無変更） | `m=192` |
| ---: | ---: | ---: | ---: |
| 0 | 0 | 0 | 0 |
| 64 | 32 | 64 | 96 |
| 128 | 64 | 128 | 192 |
| 192 | 160 | 192 | 224 |
| 255 | 255 | 255 | 255 |

暗部側の傾きは `m/128`、明部側は `(255−m)/127` です。中間点を上げたときに暗部の値は大きく動きますが、ハイライト側は白255へ近づくため変化幅が狭くなります。今回の `m` 範囲では曲線は常に単調増加し、**0・255の端点も変わりません**。ただし8-bitへ丸めると、異なる入力が同じ値になることがあります。

## ガンマ・コントラストと何が違うか

[ガンマ](./gamma.mdx)はべき乗で滑らかな曲線を作り、この教材は**128で傾きが切り替わる折れ線**を作ります。[コントラスト](./contrast.mdx)の例はピボットからの距離に同じ倍率をかけ、範囲外を切り詰めます。この教材は端点を固定して別々の傾きを与えるため、範囲外の計算値が出ない設定です。

制御点を増やせば、暗部・中間調・明部へ異なる変換を設計できますが、制御点の順序や補間方式によって単調性、局所的な段差や反転が変わります。本教材はそうした一般的な多点カーブエディターではありません。

## 制約と製品での利用

計算対象は**表示用に符号化されたグレースケールの8-bitコード値**です。光量の線形処理、HDR/広色域、色空間変換、RGBチャンネル別カーブ、撮影時の露光、色域外処理は扱いません。丸めとディスプレイ表示のため、画面で見える変化は高精度な映像処理とは一致しない場合があります。

After EffectsのCurvesエフェクトにはベジェ編集、チャンネル切替などの機能があります。本教材の2区間の直線をAfter EffectsやDaVinci Resolve ColorのCurves機能と数値・補間・色管理まで同等と主張しません。
