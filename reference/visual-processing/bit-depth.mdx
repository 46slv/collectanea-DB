# ビット深度（Bit Depth）

青空や壁の明暗が少しずつ変化する映像で、階調が十分に細かくないと帯状の境目が目立つことがあります。ビット深度は、その原因を考えるときに必要な「**1つの成分を何種類の整数値で表せるか**」という精度の指標です。ただし、帯ができた原因をビット深度だけで決めることはできません。

ここではRGB全体の画素容量ではなく、**1成分あたりの符号なし整数値**を扱います。8-bitなら0〜255の256通り、10-bitなら0〜1023の1024通りです。ビット数を1増やすと表現できる整数コード数は2倍になります。

## 入力・出力・操作

- **入力**：0〜1に正規化した人工の明暗標本と、横方向または中心が明るい楕円状のテストパターン。外部画像は使いません。
- **操作**：1成分4/8/10/12-bit、標本値0.0〜100.0%（0.1%刻み）、2種類のパターン、100/200/400%の表示倍率、初期化。
- **出力**：元パターンと整数へ丸めたパターンの比較、取り得るコード数、整数コード番号、復元比率、入力との差。
- **観察**：4-bitでは帯が大きく、8-bitでは細かくなる傾向を観察できます。10/12-bitで追加される数値の細かさは、後述の**8-bit Canvas制約**のため画面では正確に判別できません。

初期値は4-bitと標本値50.0%です。4-bitの整数コードは0〜15で、50%を最も近いコードへ丸めると8になり、復元した比率は8/15（約53.333%）です。続いて8-bit、10-bit、12-bitへ切り替え、同じ標本値の**整数コード番号と誤差**がどう変わるか確かめてください。画像の表示倍率だけでは計算結果は変わりません。

## 段階数と丸めの仕組み

符号なし・正規化整数（UNORM）のn-bitのコード最大値を `M = 2^n − 1` とします。入力 `v`（0〜1）をこの教材では `round(v × M)` へ丸め、`コード / M` で0〜1へ戻します。端点0と1を含む、等間隔の値への四捨五入です。

| 1成分の深度 | コード値 | 取り得る値の数 |
| ---: | ---: | ---: |
| 4-bit | 0〜15 | 16 |
| 8-bit | 0〜255 | 256 |
| 10-bit | 0〜1023 | 1024 |
| 12-bit | 0〜4095 | 4096 |

最大丸め誤差は、0〜1の単位では約 `1 / (2 × M)` です。例えば8-bitは最大約0.196%、10-bitは最大約0.0489%に相当します。いずれも**この等間隔UNORMモデル**での値で、光の明るさの誤差や知覚的な差を直接表すものではありません。

RGBの3成分がそれぞれ8-bitなら、各成分に256通りの値があり、理論上の組み合わせは `256³` 通りです。ただし「1画素24-bit」といった値を、そのまま動画の圧縮後容量や4:2:2形式の平均bit数と同一視できません。クロマサブサンプリング、α、符号化方式、フレーム間圧縮なども区別が必要です。

## 量子化・バンディングとの違い

[量子化](./quantization.mdx)は多くの値を少数の候補へ割り当てる**操作**です。ビット深度はその候補を保持するための表現精度の一側面で、[バンディング](./banding.mdx)は処理や表示で階調の境目が目立つ**現象**です。[ディザリング](./dithering.mdx)は、段階数を増やさずに画素の配置を工夫して境目を目立ちにくくする方法です。

たとえばグラデーションに補正を重ねると、中間演算の丸め、色変換、ファイル圧縮や表示条件も結果へ影響します。10-bitで記録した事実だけで「帯が絶対に出ない」とは判断できません。

## このブラウザ教材の制約

この教材は正規化標本を計算で丸めた後、**すべて最終的に0〜255の8-bit値としてCanvasへ表示**します。10-bit/12-bit画像をブラウザ上に保存したり、その階調差を忠実に表示したりする実装ではありません。10/12-bitの差は整数コードと数値で確認してください。画面の色管理、ディスプレイの実際のbit深度やディザリングも測定しません。

また「ビット深度」は形式によって意味が異なります。整数の映像信号にはフルレンジ以外の符号範囲もあり、浮動小数点の16-bit/32-bitは、この教材の符号なし整数コードモデルと同じではありません。広色域・PQ/HLG・scene-linear・RAW・実コーデックの丸め方、およびAfter Effects/DaVinci Resolveの内部処理を再現したものではありません。
