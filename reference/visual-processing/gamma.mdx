# ガンマ（Gamma）とべき乗変換

ガンマは、画像の入力値と出力値の関係を**直線ではない曲線**で表すときに使われる概念です。黒と白をそのままに、中間の明るさだけを持ち上げたり抑えたりできます。ただし「ガンマ」の値が大きいと明るくなるか暗くなるかは、ソフトウェアの**式・逆数の定義・処理する色空間**によって変わります。

この教材では、意味が確認しやすい**べき乗変換（Power-law Transform）**を1つだけ実装します。After EffectsやResolveの「Gamma」ノブそのものを模したものではありません。

## 入力・操作・出力

- **入力**：384×160画素の表示用8-bitグレースケール・テスト画像。横方向のグラデーション、または中心が明るい楕円グラデーションを選べます。
- **操作**：画素値を0〜1に正規化し、各画素について `y = x^g`（gはべき乗指数）を計算します。gは0.25〜3.00を0.25刻みで変更可能です。
- **出力**：計算結果を0〜255へ戻して四捨五入した画素。入力0は0、入力255は255のまま、間の値だけが変わります。

## 中間調を操作する {#try-it}

左が元画像、右が変換結果です。プレビューを先に見ながら、下のスライダーを動かしてください。

<GammaPlayground />

1. 初期値の**指数1.00**では `x^1 = x` なので両画像は同じです。
2. **0.50**では中間調が明るく、**2.00**では暗くなります。画像の黒端と白端は変わりません。「入力128 → 出力」の値でも確認できます。
3. 元画像を中心が明るい楕円グラデーションへ切り替えると、同じ曲線が二次元の明暗分布に作用する様子が分かります。200%・400%拡大では8-bit丸めの段差も観察できます。
4. 「初期値に戻す」で横グラデーション、指数1.00、倍率100%に戻ります。

## 数値で確かめる

この教材の式を8-bitの元の整数値 `v` で書くと、`round(255 × (v / 255)^g)` です。端点は動かさず、中間値のみ再割り当てします。

| 入力値 v | g = 0.50（明るく） | g = 1.00（同じ） | g = 2.00（暗く） |
| ---: | ---: | ---: | ---: |
| 0 | 0 | 0 | 0 |
| 64 | 128 | 64 | 16 |
| 128 | 181 | 128 | 64 |
| 192 | 221 | 192 | 145 |
| 255 | 255 | 255 | 255 |

例えば入力128は指数0.5では約181、指数2では約64です。**明るさを一律に一定値だけ足す操作ではありません。** 端点を保つ一方、暗部・中間調・明部の変化量は入力値によって異なります。

## 「Gamma」の向きが逆に見える理由

このページの指数gを大きくすると、`0 < x < 1` に対して `x^g` は小さくなり、画像は暗くなります。[scikit-imageの `adjust_gamma`](https://scikit-image.org/docs/0.26.x/api/skimage.exposure.html) と同じべき乗の定義です。

一方、[AdobeのAfter Effects「Exposure」エフェクト](https://helpx.adobe.com/sg/after-effects/desktop/adjust-colors/work-with-color-correction-effects/color-correction-effects.html)の**Gamma Correction**は、公式説明で**値を上げると明るくなる**とされています。つまり「Gamma=2」同士を機械的に同じ結果とみなせません。名称ではなく、実際に使われる式と処理順を確認する必要があります。

さらに、ディスプレイ用の信号変換（sRGBなどの伝達特性）、色管理上のエンコード／デコード、カラーグレーディングで中間調を動かすノブは目的が異なります。単純なべき乗曲線だけを「すべてのガンマ補正」と呼ばないようにします。

## 実制作での観察と制約

グレーディングでは、中間調の見え方を変えたい場面で曲線を利用します。ただし、この教材は各画素に固定の式を適用する**静止画像の演習**です。入力値はディスプレイ用の8-bitコード値であり、シーンリニア光量でも物理的な露光量でもありません。実素材の白飛び・黒つぶれの復元、HDRや広色域の階調保持を保証しません。

変換後は整数へ丸めるため、一部の異なる入力が同じ8-bit出力になることがあります。[量子化](./quantization.mdx)や[バンディング](./banding.mdx)と関連しますが、この教材は階調数を意図的に2〜16へ減らす操作ではありません。階調段数を大きく減らす処理は[ポスタリゼーション](./posterization.mdx)を参照してください。

**AE/Resolveについて**：公式マニュアルに似た名前のコントロールがあっても、画像処理位置・入力色空間・リニアライト変換・内部精度で結果が異なります。本CanvasがAfter EffectsのExposure/LevelsやDaVinci Resolve Color/Fusionと画素単位で一致するという主張はしていません。製品別の操作手順は環境とバージョンを検証したときに追加します。
