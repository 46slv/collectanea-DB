# 閾値処理（Thresholding）

**閾値処理**は、画素の明るさなどを決めた境界値（しきい値）と比べ、結果を別の値へ振り分ける処理です。ここでは、境界より明るい画素を白、それ以外を黒にする**二値化（Binary Thresholding）**を扱います。滑らかな陰影から明暗の領域を切り分け、シルエットやマスクの元になる画像を作れます。

色や明るさを複数段階に丸める[量子化](./quantization.mdx)と関係しますが、二値化では境界値を選ぶことが中心です。入力のどこを白に含めるかが、出力の形に直結します。

## 入力・操作・出力

- **入力**：0（黒）から255（白）までの表示用8-bitグレースケール画像と、0〜255の整数のしきい値。下の実験では384×160画素のテストパターンを使います。
- **操作**：各画素を同じしきい値と比較します。画素値がしきい値を**超えた場合だけ255（白）**にし、しきい値と等しい画素を含む残りは**0（黒）**にします。
- **出力**：画素値が0か255だけの画像。白い領域と黒い領域の境界を観察できます。中間の陰影は残りません。

## しきい値を操作する {#try-it}

左は元画像、右は二値化した画像です。プレビューを先に見てから、下の設定を変えて結果を比べられます。

<ThresholdPlayground />

1. 初期値128のまま「しきい値」を64へ下げます。より暗い画素まで白に含まれ、白い領域が広がります。次に192へ上げると、白い領域が狭くなります。
2. 「元画像」を「中心が明るい楕円グラデーション」に変更します。しきい値を動かすと、中心から広がる白い領域の大きさが変わります。元パターンは縦横を個別に正規化しているため、表示される境界は真円ではなく**楕円**です。
3. 「表示倍率」を200%または400%へ変え、黒と白の切り替わる画素を観察します。元画像の階調は連続的に見えても、出力には中間値がありません。「初期値に戻す」で、横方向・128・100%に戻ります。

表示される白と黒の画素数は二値化後の画像から数えています。しきい値を変えると白い面積がどう変わるかを数値でも確認できます。

## 128を境界にした場合の計算

この教材は、表示用の8-bit入力値を先に作ってから、固定した整数のしきい値と比較します。しきい値128のときの例は次の通りです。

| 元の画素値 | 128との関係 | 二値化後 |
| ---: | --- | ---: |
| 0 | 小さい | 0（黒） |
| 80 | 小さい | 0（黒） |
| 128 | 等しい | 0（黒） |
| 129 | 大きい | 255（白） |
| 220 | 大きい | 255（白） |
| 255 | 大きい | 255（白） |

等しい値を白に入れるか黒に入れるかは処理の定義によって変わります。この教材ではOpenCVのBinary Thresholdと同じ「**境界より大きいとき白**」という比較規則を使います。しきい値が0なら画素値0だけが黒、255なら全画素が黒になります。

## 2階調量子化との違い

[ディザリング教材](./dithering.mdx)にも「階調数2・ディザなし」の出力があります。どちらも黒か白になりますが、あちらは**黒と白への量子化**を表示し、しきい値を直接動かす操作はありません。このページでは、境界を0〜255のどこに置くかを指定して領域を選びます。境界値と等しい画素の扱いも、単純な丸め式と同じとは限りません。

[ポスタリゼーション](./posterization.mdx)は明暗を面として見せる表現上の目的を指し、2階調より多い色面も扱います。一方、この実験は**1つの固定境界から白黒の2値を作る演算**を確認するためのものです。

## 実制作での使い方と限界

**マスクを作る前段階**：被写体と背景の明るさに差がある場合、明るさを境界にして大まかな領域を分けられます。ただし輪郭の細部、半透明、逆光、被写体と背景の明るさが重なる部分は失われます。この実験はアルファチャンネルの書き出しやマスク合成を行いません。

**図案やシルエットの確認**：階調情報を捨て、明るい部分の形だけを見たい場合に使えます。境界をどこに設定するかで形や面積が変わるため、単に「白黒化する」だけで同じ結果になるわけではありません。

**照明むらのある素材**：画面全体に同じ値を使う固定しきい値は、場所によって背景の明るさが異なる画像に適さない場合があります。局所しきい値（Adaptive / Local Thresholding）やヒストグラムから境界を求めるOtsu法は別の手法であり、ここには実装していません。

## このCanvas教材の範囲

この実験は、ブラウザで生成する静止のグレースケールパターンを表示用8-bit値にしてから比較し、0か255をCanvasに描きます。入力画像の読み込み、カラー素材の輝度変換、時間変化、色空間・ガンマ・HDR・広色域、エッジの補間、アルファ作成、局所的なしきい値計算は対象外です。白黒2値になっても、保存形式が自動的に1-bitへ変わるわけではありません。

After EffectsやDaVinci Resolveで類似の表現を作ることは考えられますが、両ソフトの機能名・色処理・演算順・一致する結果をこの教材だけから保証しません。ソフト別の再現手順は、該当機能と実際の出力を確認した際に追加します。
