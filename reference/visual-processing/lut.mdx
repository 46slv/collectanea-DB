# LUT（ルックアップテーブル）

同じ映像へ同じ色調整を何度も適用したいとき、**入力値に対してどの出力値を割り当てるか**をあらかじめ表にできます。これがLUT（Look-Up Table）の基本です。LUT自体は「映画風の色」の名称ではなく、**数値の対応関係を保存して参照する仕組み**です。

LUTには、各R/G/B成分の値を個別に変える**1D LUT**と、RGBの組み合わせに応じた変換を格子点として持つ**3D LUT**などがあります。この教材ではまず1D LUTに絞り、少数の点しか記録されていない場合に、点の間をどう推定するかを確かめます。

## 入力・出力・操作

- **入力**：320×144画素の合成・不透明な8-bit RGB画像。灰色グラデーション、またはR/G/Bと2色の混色からなる6本のグラデーション帯。外部画像は使用しません。
- **変換式**：恒等、べき乗 `y = x^p`（`p` は0.5〜3.0、0.5刻み）、S字の `y = 3x² − 2x³`。いずれも0〜1へ正規化した各RGB成分に独立に適用します。
- **操作**：4／8／32／256点の1D LUT、最近傍／線形補間、変換式、パターン、100／200／400%の表示倍率、初期化。
- **出力**：元画像／式から直接計算した参照画像／LUTで再現した画像の3画面、代表的な入力コードの比較表、全256コードにおける最大絶対誤差（8-bitコード値）。
- **初期値**：べき指数2.0、4点、最近傍、灰色グラデーション、100%。**最近傍の段差が出る状態**から始まります。

## 点の間をどうつなぐか {#try-it}

<LutPlayground />

最初に「点の間の補間」を**最近傍から線形**へ切り替えます。4点のLUTでも大きな段差が連続した線分に変わりますが、曲線そのものとは少し異なります。次に記録点を4→32→256へ増やし、参照カーブとの最大差がどう変わるか比較してください。

「恒等（入力を維持）」を選んだ場合、**線形補間は4点でも正確に恒等変換**を再現できますが、最近傍は入力を段階的な値へ丸めます。これは「LUTなら必ず階調が壊れる」という意味ではなく、**記録点の配置・補間方式・元の変換式の曲がり方**によって誤差が変わることを示します。

RGBパターンを選ぶと、同じ1D曲線をR/G/B各成分へ独立に適用した場合の色の変化を観察できます。表示倍率は拡大するだけで、元の画素数や計算精度を変えません。

## 計算の仕組み

たとえば記録点4つなら、入力位置 `0`, `1/3`, `2/3`, `1` で式を評価し、4つの出力値を表に記録します。入力 `x` に対して、`t = x × (N − 1)` から表の位置を求めます。

- **最近傍**：`round(t)` 番目の記録値をそのまま使います。記録点数が少なければ同じ出力が続く領域ができます。
- **線形補間**：`floor(t)` と次の記録値を、`t` の小数部分の比率で混ぜます。入力が点の間にあっても連続的に値が変わります。
- **参照画像**：記録表を経由せず、同じ数式を各入力へ直接適用します。この教材でいう「正解」はあくまで**選択した人工的な数式**であり、視覚上の正しい色や標準化された色変換ではありません。
- **最大差**：各入力コード0〜255をそれぞれ正規化し、数式とLUTの出力を独立に8-bitへ丸めた後、絶対差の最大値を表示します。平均視覚差やΔEではありません。

この例は入力領域が**[0,1]で固定**された均等間隔の1D LUTです。現実のLUTには別の入力範囲、Logなどの非線形領域、浮動小数点や3D格子、異なる補間・外挿規則が使われる場合があります。点数の大小だけで実際の処理精度や品質は決まりません。

## 制作現場での読み方

LUTを受け取ったら、見た目だけでなく、**想定する入力色空間・伝達特性・データレンジ・出力条件**を確認してください。あるLog素材向けに作られたLUTを、変換済みのRec.709表示用映像へそのまま当てても、本来想定した色にはなりません。1D LUTは単純なチャンネル別階調変換を表せますが、RとGの組み合わせに応じてBの出力を決めるような**チャンネル間の相互作用はこのモデルでは表現できません**。こうした用途では3D LUTなど別の表現が必要です。

**制約**：この教材は表示用の8-bit RGBコードをそのまま0〜1へ正規化した単純な数学モデルであり、sRGBの線形光への変換を含みません。Rec.709/ACES/Logの色管理、3D LUT、ハードウェア精度、HDR・負の値・1を超える値、非等間隔の表、各製品のLUT外挿や逆変換は対象外です。After Effects／DaVinci ResolveのLUT演算と画素単位で一致するとは主張しません。
