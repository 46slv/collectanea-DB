# ポスタリゼーション（Posterization）

ポスタリゼーションは、画像の細かな明暗・色の変化を少数の段階にまとめ、なだらかな部分を輪郭のはっきりした**面**として見せる表現です。陰影を単純化したグラフィック、色面を強調する映像、セル調の見た目などに利用できます。

処理としては[量子化](./quantization.mdx)を使うことがありますが、用語の役割は異なります。**量子化**は値を段階へ丸める操作、**ポスタリゼーション**はそのような処理で作る画面表現、[バンディング](./banding.mdx)は意図しない帯状の段差が目立つ現象です。同じ段差でも、演出として残すのか、画質上の問題として減らすのかで判断が変わります。

## 入力・操作・出力

- **入力**：明るさが連続的に変わる画像と、出力に残す段階数。実際のカラー画像ではRGBなど各成分の扱いも結果を左右します。
- **操作**：近い値を同じ段階に割り当て、細かな変化を減らします。このページの実験では、黒と白を含む等間隔の2〜16階調へ丸めます。
- **出力**：明暗の値が少数に限られ、比較的大きな同じ明るさの領域と、その境界が見える画像です。細かなグラデーション情報は失われます。

## 操作して面の数を変える {#try-it}

以下は既存のディザリング教材を再利用した白黒の実験です。左の「01 / 元画像」と中央の「02 / 量子化のみ」を比べます。中央が、このページで扱う**階調を減らした面表現**です。

<DitheringPlayground />

1. 「処理方式」を**ディザなし**（量子化）に切り替えます。中央と右が同じ結果になり、面の境界に注目できます。
2. 「階調数」を**2 → 4 → 8 → 16**と変えます。2階調では黒と白、4階調では4種類の明るさに分かれます。段数を増やすほど、元の滑らかな変化に近づきます。
3. 「元画像」を「中心が明るい円形グラデーション」にすると、境界が中心を囲む形になります。この教材は384×160pxを縦横別々に正規化するため、実際の帯は**同心の楕円状**で、真円ではありません。
4. 「規則的ディザ」や「誤差拡散」に切り替え、面の境界が粒や模様に変わる様子を比較します。ディザは段階数を増やさず、面をはっきり見せたい意図とは逆に働く場合があります。「初期値に戻す」で元の設定へ戻れます。

## 4階調の仕組み

この教材では入力の明るさを0（黒）〜1（白）として扱い、4階調なら
**0、1/3、2/3、1**のうち最も近い値へ丸めます。式は `round(3 × 入力) / 3` です。

| 入力 | 丸めた値 | Canvas表示用の8-bit値 |
| ---: | ---: | ---: |
| 0.10 | 0 | 0 |
| 0.20 | 1/3 | 85 |
| 0.40 | 1/3 | 85 |
| 0.60 | 2/3 | 170 |
| 0.85 | 1 | 255 |

例えば0.20と0.40は異なる入力ですが、どちらも85になります。元の陰影が同じ明るさへ統合されるため、境界で値が急に変わって見えます。段階数が少なすぎると、顔の繊細な陰影や暗部の形が失われることもあります。

ここで扱う「4階調」は**白黒1成分の4種類**です。4色のカラーパレットへ置換する実験ではありません。Adobe After Effectsの［Posterize］エフェクトはRGBなどの**各チャンネル**の階調数を指定する方式で、公式ガイドでは各チャンネル2〜255段階と説明されています。例えばRGB各2段階では組み合わせとして最大8色あり得ますが、元画像に実際に8色すべてが現れるとは限りません。**本教材の4階調とAEのLevel 4は、カラー画像において同じ操作ではありません。**

## どのような場面で使うか

**画面をグラフィックな色面にする場合**：被写体の陰影を単純化し、少数の明暗の面で形を読ませます。2〜4階調では強い輪郭が出やすく、8〜16階調では元画像の立体感をより多く残します。望む形になる段数は素材の明暗分布によって異なります。

**別の表現と組み合わせる場合**：輪郭線や色の設計と組み合わせればセル調の表現に近づけられます。ただし、階調を減らすだけでは輪郭線の抽出や色設計は行われません。規則的ディザを加えれば、平坦な面とは異なるパターン表現になります。

**意図しない段差を見分ける場合**：最終映像でグラデーションに段差が生じたときは、意図的なポスタリゼーション設定か、変換・書き出し・表示で生じたバンディングかを切り分けます。原因を推測で決めず、元画像と処理前後、最終出力を比較してください。

## 間違えやすい関連用語

- **閾値処理（Thresholding）**：値が境界を超えたかで二値などに分類する処理。2階調の等間隔量子化と似た結果になる場合もありますが、閾値の決め方や出力値が同じとは限りません。
- **ポスタライズ時間（Posterize Time）**：After Effectsではフレームの更新頻度を制限する**時間方向の別エフェクト**です。色の段階を減らすPosterizeとは区別します。
- **ビット深度（Bit Depth）**：保存・処理で使えるコード値の精度に関係します。ここで4階調にしても、ファイルやCanvasの保存形式を自動的に2-bitへ変更するわけではありません。

## 実験の範囲とソフト別の扱い

このCanvas教材は、静止した**グレースケールのテストパターン**を2〜16階調へ丸め、表示用8-bit値へ変換します。色付き素材のチャンネル別処理、色空間・ガンマ・HDR・広色域、時間方向の変化、動画圧縮、エッジ抽出は検証対象ではありません。After EffectsやDaVinci Resolveの内部演算を画素単位で再現したものではありません。

After Effectsでは公式の［Posterize］が各チャンネルのレベル数を扱いますが、実際のプロジェクトでの色・処理順・出力を確認せずに、このブラウザの結果と一致すると説明しません。DaVinci Resolveについても、操作手順や同等性を確認できた場合にソフト別ガイドへ追加します。
