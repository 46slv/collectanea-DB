# 特定色の調整（Selective Color）

赤い服だけ鮮やかにしたいとき、画像全体の彩度を上げると背景の色まで変わります。特定色の調整は、**色を選ぶ処理（マスク）**と**選ばれた画素を変える処理**に分けて考えられます。

この教材は、表示用8-bit sRGBをHSLへ変換し、**色相の距離からマスクを作って彩度だけ調整する**一例です。Adobe製品の「Selective Color」という名前の効果や、DaVinci ResolveのQualifierと同じ内部処理を再現するものではありません。

## 入力・操作・出力

- **入力**：384×160画素の不透明な合成RGB画像。8色のパッチ（灰色を含む）と、上下で彩度が変わる色相帯を切り替えます。外部の写真は使いません。
- **選択**：色相中心0〜330°（30°刻み）、円周上の半幅30〜90°（15°刻み）、境界のやわらかさ0〜100%（25%刻み）で色相マスクを作ります。0°と360°は同じ赤です。
- **調整**：選択範囲の彩度係数0.00〜2.00（0.25刻み）。1.00なら変化なし、0.00なら完全選択した画素のHSL彩度を0にします。倍率100／200／400%と初期値へのリセットもあります。
- **出力**：入力・選択マスク・補正後の3枚のCanvas、マスクが0を超える画素数、代表的な赤・青・灰色の選択率とRGB値です。表示倍率は演算結果を変えません。

初期値は赤（0°）を中心に半幅45°、境界50%、彩度係数1.50です。左の画像は原画、中は白ほど強く選ばれるマスク、右は選択した部分だけ彩度を上げた結果です。

まず彩度係数を**0.00**にして、赤いパッチが灰色へ近づく一方、青や緑がそのまま残ることを観察してください。中心を240°へ動かすと青が選ばれます。色相帯では赤の領域が右端から左端へまたがるため、0°の近傍を一つの連続した範囲として扱う必要があります。

境界のやわらかさを0%にすると選択領域が急に切り替わります。100%では中心から半幅まで徐々に弱まります。マスクの灰色部分が「部分的に補正する画素」です。灰色のパッチは彩度0で色相を定められないため、この教材では常に選択しません。

## マスクと変換の仕組み

入力RGBのR'G'B'を0〜1へ正規化してHSLに変換し、画素の色相を h、選択中心を c とします。円周上の距離は **d = min(|h − c|, 360° − |h − c|)** です。円周をまたぐ赤付近でも距離が連続します。

半幅 w に対し、境界開始位置を **a = w × (1 − softness / 100)** とします。d ≤ a ではマスク m = 1、d > w では m = 0、その間は0〜1へ滑らかに変わる smoothstep（3t² − 2t³）の逆数形を使います。softness=0のときは境界を段階的に切り替えます。無彩色は m = 0 です。

HSL彩度 S と彩度係数 k から **S' = clamp(S × (1 + m × (k − 1)), 0, 1)** を計算します。HとLは数値として保ち、RGBへ戻して8-bitへ丸めます。したがって、マスク0や係数1では元の画素値が保たれます。

| 入力 | 中心0°・半幅45°・境界0% | 係数0.00の出力 | 説明 |
| --- | ---: | --- | --- |
| 赤（255, 0, 0） | 100% | 128, 128, 128 | 選ばれた赤の彩度を0にする |
| 青（0, 0, 255） | 0% | 0, 0, 255 | 色相が選択範囲外 |
| 灰（128, 128, 128） | 0% | 128, 128, 128 | 無彩色に色相はない |

マスク画素数は m > 0 を数えたもので、選択の強さの合計ではありません。柔らかな境界は、見た目の効果が弱くても画素数として数えられます。

## 実制作での使い分けと限界

特定の色域だけを補正すると、例えば背景の青を維持したまま赤い物体を弱くできます。ただし同じ色相の別の物体も選ばれます。被写体だけに限定したい場合は、色相のほかに明るさ・彩度・空間マスク・トラッキングなどの条件が必要です。

HSLの色相角度は知覚的に等間隔ではありません。またこの教材は、符号化された8-bit sRGBを単純に処理しています。**HDR・広色域・シーンリニア・肌色を保護する高度なキー処理・ノイズのある実写素材の選択精度は再現しません**。After Effects・DaVinci Resolveの色選択と画素単位の一致を保証するものではありません。

全体を調整する場合は[彩度](./saturation.mdx)、色の方向そのものを動かす場合は[色相の変更](./hue-shift.mdx)と比較してください。
