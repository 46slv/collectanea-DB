# カメラ資料の使い方

このマニュアルは、撮影用語を機種ごとに繰り返し説明するのではなく、**共通する仕組み**と**機種固有の操作**を分けて扱います。

## 基本の読み方

```text
何をしたいか
  ↓
共通する仕組みを理解する
  ↓
使うカメラの操作へ移る
  ↓
設定後に画面表示・記録条件を確認する
```

たとえば「Logで撮りたい」場合、最初に[Log撮影](../tasks/log-shooting.md)で共通する考え方を確認し、その後に[Sony FX3](../models/sony-fx3/index.md#log撮影)のメニュー操作へ進みます。

## 現在の対応

| やりたいこと | 共通知識 / Task | Sony FX3 | Panasonic S5IIX |
| --- | --- | --- | --- |
| 記録方式を選ぶ | [記録方式・圧縮・10bit](../concepts/recording-formats.md) | 記録方式と動画設定を掲載 | 対応フォーマットとSSD記録を掲載 |
| Logで撮る | [Log撮影](../tasks/log-shooting.md) | Flexible ISO / Cine EI Quick / Cine EIを掲載 | V-Log / V-Gamutの仕様を掲載 |
| 4:2:2 10bitで撮る | [記録方式・圧縮・10bit](../concepts/recording-formats.md) | XAVC系の対応設定を掲載 | 対応する高品位記録の概要を掲載 |
| 外付けSSDへ記録する | 機種固有 | 本マニュアルでは直接記録を確認していない | USB-SSD直接記録を掲載 |
| RAWを外部収録する | 機種固有 | HDMI RAW出力は今後詳細化 | HDMI RAW出力の概要を掲載 |

操作経路を一次資料で確認できていない項目は、対応していることだけでメニュー手順を推測しません。

## ページの書き方

機種別の記事は次の順で整理します。

1. 何をする設定か
2. どの共通知識につながるか
3. メニュー経路・物理操作
4. 設定値の読み方
5. 設定後にどこを確認するか
6. 制約・ファームウェア差
7. 公式資料と確認日

仕様表だけではなく、「どこを操作して、何が変わり、どう確認するか」までを1つの操作単位として扱います。
