# Panasonic S5IIX

S5IIXは、H.264 / H.265系の動画記録に加えてApple ProRes、ALL-Intra、V-Log / V-Gamut、外付けSSDへの直接記録、HDMI RAW出力を扱える動画志向のフルサイズ機です。

この初期版では**機能と記録条件を公式資料で確認した範囲**を掲載しています。メニュー階層は、操作マニュアルで再確認できた項目から追加します。

## 記録とメディア

Panasonicの公開情報では、MP4 / MOVでH.264 / H.265を使用でき、S5IIXではApple ProRes 422 HQ / ProRes 422やALL-Intra記録も扱えます。

### 外付けSSDへ直接記録

S5IIXはUSB接続の外付けSSDへ写真・動画を直接記録できます。

Panasonicが示している代表条件:

- 対応容量: 最大2TB
- Apple ProRes 422 HQ: 最大1.9Gbps
- 4:2:2 10bit ALL-Intra: 最大800Mbps
- USB-SSD記録中はSDカードとの同時記録不可

取り外すときは、カメラ側で［USB-SSD］をOFFにし、画面のUSB-SSDアイコンがカードアイコンへ変わったことを確認してからケーブルを抜く手順が案内されています。

### ALL-Intra

ALL-Intraは各フレームを独立して圧縮する方式です。PanasonicはS5IIXの高品位編集・合成向けの記録方式として案内しています。

800Mbpsの動画画質やS&QモードのALL-Intraには外付けSSDが必要な条件があります。

圧縮方式の違いは[記録方式・圧縮・4:2:2 / 10bit](../../concepts/recording-formats.md)を参照してください。

## V-Log / V-Gamut

S5IIXはV-Log / V-Gamutで動画を記録できます。PanasonicはV-Logで14+ストップのダイナミックレンジを公称しています。

このページでは、V-Logを有効にするメニュー経路をまだ一次資料で再確認していません。操作手順は確認後に追加します。

共通の確認項目は[Logで撮影する](../../tasks/log-shooting.md)を参照してください。

## HDMI RAW出力

S5IIXはHDMIから動画RAWデータを出力し、対応する外部レコーダーで記録するワークフローに対応します。RAW出力の対応解像度・フレームレートはセンサー領域によって異なります。

外部レコーダー側の対応バージョンも条件になるため、実際の収録前にカメラとレコーダー双方の現行互換表を確認します。
