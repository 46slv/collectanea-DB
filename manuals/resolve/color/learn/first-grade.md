# 最初のグレーディング

Colorページで最初に行うのは、映像を独特な色へ変えることではなく、**何を基準に画像を評価できる状態なのか**を確認することです。素材の色空間や表示条件が分からないまま調整すると、補正による変化と表示・変換による変化を区別できなくなります。

## 1. 最初に確認すること

- **素材**：カメラ・収録方式、Log／RAW／通常の動画などの特性は分かるか。
- **プロジェクトのカラー管理**：入力、作業用、出力の色空間やガンマが、どこで変換されているか。
- **出力先**：何の表示環境・納品仕様へ向けた補正か。
- **判断する画面**：Viewerの見た目に加え、波形などのScopesで暗部・明部を確かめられるか。

ここで特定の色空間設定を全素材の正解として固定しません。Log素材も、すでに変換された素材も、ノードへ入る時点の画像が何かを確認します。

## 2. 最小の補正順

### 明るさの分布を整える

まず暗すぎる／明るすぎる範囲と、主被写体が見やすいかを確認します。Primariesを使い、1つの調整だけを動かしてWaveformの変化を見ます。

### 色の偏りを整える

本来ニュートラルに見せたい部分があれば、光源や場面の意図と照らし合わせて色かぶりを調整します。すべての物体を無彩色にする必要はありません。

### 前後のショットを比べる

単独カットがよく見えても、切り替わるショット間で肌の明るさや背景の色が大きく違うと違和感が出ることがあります。同じ条件で比較し、まず基本的な明暗と色の関係をそろえます。

### 演出としての色を足す

基本補正と演出を別のNodeへ分けると、意図したLookだけを一時的に外して比較できます。Nodeの順序は実際の信号処理を変えるため、各段階の入力と出力を確認します。

## 3. 最小の例

室内で撮影した人物ショットを想定します。

1. 画像の入力条件とViewerの表示条件を確認します。
2. [Scopes](../reference/scopes)で黒側・白側に値がどう分布しているか観察します。
3. [Primaries](../reference/primaries-color-wheels)で露出感や全体の色の偏りを少量調整します。
4. 補正Nodeを一時的に無効化し、元画像との差を見ます。
5. 次のカットと交互に見て、明るさや人物の色が突然変わらないか判断します。

厳密な露出値や固定のRGB比率を、この例だけから指定することはできません。元の照明、画面内の分布、仕上げる規格によって選択が変わります。

## 4. 間違えやすい点

- Scopesは画像の信号の分布を示します。良い絵づくりの唯一の正解を判定するものではありません。
- 「コントラストを上げる」と「全体を明るくする」は別の調整です。
- ColorページのノードとFusionのノードは、名前が似ていても処理する対象・接続方式が異なります。
- Viewer LUTやカラー管理の変換と、実際のグレーディング操作を混同しません。
