# ColorページのNode Graph

Colorページでは、複数の補正を**ノード（Node）**として接続できます。どの補正を先に適用するかを可視化できるので、明るさの基礎調整と、人物・空など局所的な補正を分けて管理できます。

## 最小構成：順番に処理する

```text
入力画像 → [01 基本の明暗と色] → [02 局所的な補正] → [03 演出Look] → 出力
```

これはシリアルノード（Serial Node）を使う概念図です。左側の出力が次のノードへ渡されるので、途中で色や明暗を変えると、その次の補正が受け取る画像も変わります。

例えば「空を選択するための条件」を後段で使う場合、前段で青色を強く変えれば、後段の色による選択範囲にも影響する可能性があります。分離しているのは操作の役割であって、処理結果が互いに独立しているという意味ではありません。

## 何を別Nodeにするか

最初の整理では、次の3役割が分かりやすい構成です。

| 役割 | 画像へ行うこと | 分ける理由 |
| --- | --- | --- |
| 一次補正 | 明暗、全体の色の偏りを整える | 撮影条件をそろえる調整だけを比較できる |
| 二次補正 | 特定の色や形の領域を選んで補正する | 対象範囲と補正量を独立して見直せる |
| 演出 | 作品の色調やコントラストを決める | 自然な補正からLookだけを切り離せる |

すべての素材で3つのノードが必要なわけではありません。1つで済む補正を無理に分割せず、結果と修正しやすさを基準に選びます。

## 順序を入れ替えて確かめる

同じ補正量でも、Nodeの順序によって最終結果が変わることがあります。2つの補正が互いにどんな入力画像を受け取っているかを比較します。

確認例：

1. Node Aで全体の明るさを変える。
2. Node Bで色の一部を選んで補正する。
3. AとBの順序を変えた別候補を比較する。
4. 選択範囲や色の変化が意図に合う構成を採用する。

## FusionのNodeとは違う

Fusionでは、MediaIn、Merge、Mask、3Dなどデータの種類や接続関係を組み合わせて画像を生成・合成します。Colorでは、主にショットに対して補正を重ね、必要に応じて選択領域を定義します。両者のNode Graphを同じデータモデルとして読み替えないでください。
