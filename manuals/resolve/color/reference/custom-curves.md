# Custom Curves（カスタムカーブ）

**Custom Curves**は、Colorページで画像の暗部・中間調・明部の明るさや色を、任意の点を結んだカーブで調整するツールです。ひとつのホイールが広い階調を動かす[Primaries](./primaries-color-wheels)と異なり、曲線上の点を配置して「どの明るさの信号を、どの出力値に変えるか」を細かく制御できます。

ColorページのCurvesパレットにはCustomのほか、特定の色相・彩度・輝度を基準にしたカーブがあります。**Custom Curvesの横軸は画像の入力階調**であり、「赤い物体を選ぶ」「特定の色相の彩度を変える」といったHue系Curvesの選択とは役割が異なります。

## 画面とカーブの読み方

Colorページで対象のクリップと補正ノードを選び、中央のパレットにある**Curves**を開いて**Custom**を選びます。カーブ編集領域にはY（輝度）・R（赤）・G（緑）・B（青）の曲線が重なって表示され、右側から編集するチャンネルと効果量を扱えます。

- **横軸（入力）**：左が暗い信号、右が明るい信号です。
- **縦軸（出力）**：同じ入力を最終的にどの明るさ・チャンネル値へ写すかを示します。
- **左下から右上への対角線**：入力と出力が等しい、補正していない状態です。
- **対角線より上**：その入力域を持ち上げる方向。下なら下げる方向です。
- **Curve Edit／Gang**：チャンネルを個別編集するか、連動させて調整するかを扱います。
- **Curve Intensity**：各チャンネルのカーブの影響量を混ぜるスライダーです。マニュアル上、100で全効果、0で効果なしです。

たとえば中間調の点を少し上へ動かすと、中間調を中心に持ち上げられます。ただしその点の両隣に別の制御点がなければ、周辺の暗部・明部にも変化が及びます。カーブは1点だけを操作するマスクではありません。

## 制御点を増やす・動かす・戻す

21.1マニュアルの基本操作は次のとおりです。OSや入力装置によるキー表示の差は、実機で確認してください。

1. カーブ上をクリックすると制御点が追加されます。その点をドラッグして、対応する入力域の出力値を変えます。
2. **Shiftを押しながらクリック**すると、カーブの形を変えずに、その場所へ制御点を置けます。別の階調を保つための「固定点」に便利です。
3. 制御点を右クリックすると、その点を削除できます。
4. 曲線の特定チャンネルだけ戻す場合は、該当チャンネルのIntensity付近のリセットを使います。すべてを戻す場合はCustom Curves全体のリセットを選びます。

Viewer上の画像をクリックして、その場所の値に対応するカーブ位置へ制御点を追加する方法もあります。暗い服・肌・明るい壁など、実際に残したい領域を見ながら点を置くと、横軸上での当たりを付けやすくなります。ただしサンプルした画素の色や階調がその被写体全体を代表するとは限らず、Viewerと[Scopes](./scopes)による確認が必要です。

制御点が多過ぎるとカーブの形を把握しにくくなります。21.1マニュアルでは、Optionキーを押しながら点を動かしてニュートラル対角線にスナップする操作も説明されています。キーの読み替えはOS別に確認し、編集済みの状態を戻したいときだけ使用してください。

## 例1：弱いS字カーブでコントラストを整える

屋内の人物ショットを想定します。肌の明るさは大きく変えずに、暗い家具と窓際の明暗差を少しはっきりさせたい場合です。

1. 最初に素材の入力色空間、カラー管理と表示条件を確認します。基本の露出・ホワイトバランスが大きく外れている場合は[Primaries](./primaries-color-wheels)などで整えます。
2. 次のシリアルノードでCustom Curvesを開きます。まず連動したYRGBカーブを使い、全体のコントラスト変化を観察します。
3. 人物の中間調や保持したい明部付近に、Shiftクリックで制御点を置きます。カーブを変更しない位置から始めると比較しやすくなります。
4. 暗部寄りの制御点をわずかに下へ、明部寄りの点をわずかに上へ動かします。こうするとカーブは緩いS字になり、主に両端寄りの明暗差を広げられます。
5. [Waveform](./scopes)で黒付近と白付近の信号が不自然に詰まっていないか、Viewerで服・肌・窓の質感が残っているかを確認します。
6. ノードの有効／無効を切り替え、**コントラストが増えたかだけでなく、中間調の顔が暗くなり過ぎていないか**を確認します。

**S字にすれば必ず改善するわけではありません。** すでにコントラストが高いショットへ適用すると黒つぶれ・白飛びが強くなる場合があります。補正量だけでなく、固定点の位置と間隔を見直します。

## 例2：明部の青かぶりをRGB別に補正する

白い壁や窓の光が青っぽい一方で、暗部と肌は大きく変えたくないショットを想定します。

1. まず[RGB Parade](./scopes)で明部のRGBチャンネルの分布を確認します。ここでは明るいニュートラルな壁を基準に、**青チャンネルが他より過剰なケース**を仮定します。色付きの光や色のある壁では、チャンネルが一致すること自体を目的にしません。
2. Custom CurvesでR／G／Bの連動を外し、BlueのCurve Editを選択します。
3. 補正したくない中間調・暗部に制御点を残した上で、明部寄りのBlueカーブを少し下げます。Viewer上の白い壁の色味と肌の変化を確認します。
4. 補正が壁だけに留まらず、同じ階調の別の部分へも作用することを確認します。必要なら別ノードで[Power Windows](./power-windows)や[HSL Qualifier](./hsl-qualifier)による二次補正を検討します。
5. RGB ParadeとViewerで確認し、やり過ぎなら制御点を戻すか**Curve Intensity**を下げます。

チャンネル別編集は、ある色の**被写体を選択する機能ではありません**。同じ階調域にある別の被写体にも影響するため、背景だけを確実に分けたいときは、輝度カーブ単独では不十分です。また、カーブと他の一次補正の相互作用によって他チャンネルの見え方も変化し得ます。

## 端点・編集モード・Soft Clip

Custom Curvesには、通常の制御点に加えて、作業を速くする機能があります。

| 操作・機能 | 使いどころと注意 |
| --- | --- |
| 左下のBlack Point／右上のWhite Point | カーブ全体の黒側・白側の基準を変える。水平・垂直方向の動きで信号を広げたり圧縮したりするため、階調の端が急に失われていないか確認する |
| **Default Anchors** | カーブに追加の制御点を置き、暗部から明部までを複数の範囲に分ける。実画像の保持したい領域に合わない場合は点の位置を調整する |
| **Editable Splines** | 制御点にベジェハンドルを表示して曲線の形を細かく調整できる。折れや極端な湾曲を作らないようにする |
| **Curve Intensity** | 曲線の効果をチャンネル別に弱める。制御点をやり直す前の比較にも使える |
| **Soft Clip** | Custom Curves領域にある別の操作で、明暗端のクリッピングをなだらかにする。S字カーブと同じものではない |

**急な折れ曲がりや、近過ぎる制御点**は、階調が平らに詰まる現象やソラリゼーションに似た不自然な色の反転を生むことがあります。勾配の緩やかな壁や空を表示し、必要がなければ制御点を増やさない方が扱いやすくなります。

Soft Clipには全チャンネルを連動して処理する設定と、個別チャンネルごとの設定があります。個別チャンネルだけ極端にクリップを変えると、ハイライトやシャドウに色かぶりが加わる場合があります。ここではCustom Curvesと混同しないための説明に留め、Soft Clipの数値や納品規格の上限を一律には指定しません。

## カラー管理とHDRで注意すること

Curvesパレットは、Resolve Color Management（RCM）やACESを使用している場合、Timeline Color Spaceと映像のデータ範囲を考慮する**color-space-aware**な操作として説明されています。同じ制御点配置でも、Log信号・変換済み信号・HDRワークフローでの見た目を一律に保証できません。

21.1マニュアルには、ノードのコンテキストメニューから切り替える**HDR Mode**（Studioのみ）も記載されています。これはノードの扱うHDR範囲を拡張するモードで、[HDRパレット](./hdr-palette)そのものとは別です。通常のCustom Curvesを理解するためにHDR Modeを有効化する必要はありません。既存プロジェクトでHDR ModeやRCM/ACESが設定されている場合は、その状態を確認してからカーブの効き方を評価します。

## 判断の目安

- 画像全体の露出やホワイトバランスを素早く整えたい → [Primaries Wheels](./primaries-color-wheels)。
- ある明暗域のトーンやRGBバランスを細かく設計したい → **Custom Curves**。
- Shadows／Midtones／Highlightsの明暗域ごとに自然に微調整したい → [Log Wheels](./log-wheels)。
- 複数ゾーンとその範囲・Falloffを指定したい → [HDRパレット](./hdr-palette)。
- 赤い服だけの彩度など、**色相を基準に選択したい** → Hue系CurvesやQualifier（Custom Curvesとは別方式）。
