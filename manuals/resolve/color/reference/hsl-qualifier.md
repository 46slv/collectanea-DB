# HSL Qualifier（色相・彩度・輝度で補正範囲を選ぶ）

**HSL Qualifier**は、Colorページで画像の一部を**色相（Hue）・彩度（Saturation）・輝度（Luma）**の条件によって選ぶツールです。青い服の彩度を抑える、肌に近い色だけを整える、明るい壁の色かぶりを軽減する、といった二次補正に使います。

Qualifierが作るのは「どこに補正をかけるか」という**選択範囲（キー／マット）**です。選択した部分の色を実際に変えるときは、同じノードで[Primaries](./primaries-color-wheels)や[Custom Curves](./custom-curves)などを操作します。Qualifier自体は選んだ色を自動的に理想の色へ直す機能ではありません。

## 何が選べて、何が選べないか

HSLの3条件はそれぞれ異なる性質を見ています。

| 条件 | 見ているもの | 例 |
| --- | --- | --- |
| **Hue** | 色の種類。青・赤・黄などの方向 | 青いシャツと青空の両方が候補になり得る |
| **Saturation** | 色の鮮やかさ | 鮮やかな看板を、無彩色の壁から分ける |
| **Luma** | 明るさの範囲 | 同じ青でも、暗い紺色と明るい青を分ける |

HSLはこれらを組み合わせて選択します。同じ条件に入る画素なら、画面内の位置が離れていても選ばれます。**青いシャツを指定しても、似た色の背景や反射まで選ばれる可能性がある**ことを最初から想定します。

被写体の形や位置で領域を限定したい場合はPower Window、動くWindowを追わせたい場合はTrackerが隣接するツールです。HSL単独で被写体を追跡しているわけではありません。

## 最初の選択を作る

1. Colorページで対象クリップを選び、[Node Graph](../learn/color-node-graph)に補正用のシリアルノードを用意します。ベースとなる露出・ホワイトバランスは先に整えると比較しやすくなります。
2. **Qualifier**パレットを開き、モードを**HSL**にします。**スポイト（Sample Eyedropper）**を選択します。
3. Viewerで狙う色の部分をクリックします。色や明るさにむらがある被写体では、狙う範囲の中を短くドラッグして複数の画素をサンプルします。
4. Viewer上部の**Highlight**を有効にし、選択されている部分と除外されている部分を見分けます。標準のFlat-Gray表示では、選択域は元の色で残り、それ以外は灰色になります。
5. 狙っていない背景が選ばれていたら、いきなり色補正を始めず、次節のRange／SoftnessとMatte Finesseを調整します。
6. Highlightを解除してから補正を加え、ノードを一時的に無効化して差を確認します。[Scopes](./scopes)は補正後の信号を読むために併用します。

Highlightは補正結果の通常表示ではなく、**選択範囲を点検するための表示**です。作業を終えたら解除し、画面全体で色のつながりを見ます。

## スポイトは3種類の仕事に分かれる

21.1のHSLパレットには、最初のスポイトのほか、すでに作った選択を調整するサンプルツールがあります。似たアイコンでも役割が違います。

| 操作 | 何を変更するか | 使う場面 |
| --- | --- | --- |
| **Sample Eyedropper** | 最初の選択の中心となる色・明暗条件を取る | まずシャツや空を選ぶ |
| **Add / Subtract Color Range** | キーの中心となる範囲に画素値を追加・除外する | 選べていないシャツの部分を追加、背景の青を除外 |
| **Add / Subtract Softness** | 選択範囲の外縁のなだらかさを追加・減算する | 衣服の影や輪郭が急に切り替わるとき |

スポイトはクリックによる一点サンプルと、ドラッグによる範囲サンプルを使い分けます。クリックしたつもりでも選択が更新されないときは、**直前に使った別のサンプルツールが選択されたまま**になっていないか確認します。

## Hue・Sat・Lumの範囲を直接調整する

スポイトで大まかに選んだ後は、HSLの各範囲を直接調整すると、何が選択を狭めているのか判断しやすくなります。

- **Hue Center / Width**：選択する色相の中心と幅。Widthを広げると近い色相を含みやすくなり、狭めると厳密になります。
- **Hue Soft / Symmetry**：色相の端で選択が弱まる範囲と、その左右の効き方。端が急に切れる場合に確認します。
- **Sat Low / High、Low Soft / High Soft**：選択する彩度の下限・上限と、それぞれの移行のなだらかさ。
- **Lum Low / High、Low Soft / High Soft**：選択する明るさの下限・上限と、その移行のなだらかさ。

HSLの**Hue／Sat／Lumを個別に無効化**することもできます。たとえばHueとLumを無効にすると、色の種類と明るさに関係なく、彩度だけを条件に選べます。逆にHueだけ残せば、同じ色相を広い明暗域から選ぶ方向になります。目的と異なる条件がキーを削っていないか、ひとつずつ切り替えて確かめます。

21.1マニュアルでは、各範囲のグラフィカルなオーバーレイをドラッグしてLow／Highや中心を調整する方法も説明されています。正確な数値を先に決めるより、**Highlightで選択域がどう変化するか**を見ながら扱う方が実制作では判断しやすくなります。初期値や推奨値は素材と色処理の条件によって変わるため、ここでは固定しません。

## Matte Finesseでキーを整える

スポイトやHSL Rangeが決まっても、選択には小さな欠けや不要な点が残ることがあります。**Matte Finesse**は、すでに作ったキーの形や境界を整える段階です。

- **Clean Black**：除外側の黒い領域に残る白い点やノイズを減らしたいとき。
- **Clean White**：本来選択したい白い領域にできた黒い穴を埋めたいとき。
- **Blur Radius**：選択と非選択の境界をぼかし、硬い輪郭が見えにくくなるか確認するとき。
- **In/Out Ratio**：ぼかした境界を内側・外側へ寄せて、補正がはみ出す位置を調整したいとき。

設定する順番の一例は、**まず必要な色域を選び、次に黒側・白側の穴を整理し、最後に輪郭のなじみ方を確認する**ことです。Clean Whiteを強くし過ぎて異なる被写体までつなげたり、Blurで境界から別の色がにじんだりしたら、一度値を戻します。

キーの小さな欠けを見つけたいときは、Highlightの**High-Contrast（白黒）表示**を使います。選択が白、非選択が黒になるため、カラー画像のままでは分かりにくい穴やちらつきを見つけやすくなります。Flat-Gray表示は、選んだ被写体の色を見ながら作業したいときに向きます。

## 操作例：青いシャツだけ彩度を抑える

同じショットの背景に青い空が写っている場合を想定します。**青い服だけを少し落ち着かせたい**という目的です。

1. 露出と全体の色バランスを調整した後、別のシリアルノードを追加してHSL Qualifierを開きます。
2. シャツの明るい部分と陰になった部分をドラッグでサンプルします。Highlightで、シャツのどこが選ばれたか確認します。
3. 空まで選ばれていれば、まず**Lum**や**Sat**の範囲の違いで切り分けられるか試します。シャツと空のHue・Sat・Lumが近ければ、範囲調整だけでの完全分離は難しくなります。
4. 選択域の欠け・点状ノイズをMatte Finesseで整え、白黒Highlightでも境界を見ます。人物が動くショットでは複数フレームを確認します。
5. Highlightを外して、**PrimariesのSaturation**を少し下げます。顔・髪・背景の色も変わっていないか比較します。
6. 空への波及が残る場合は、HSLを過剰に狭めてシャツの陰影を失うより、**Power Windowを組み合わせて領域を限定する**方法を検討します。Windowを動かす必要があればTrackerを使用します。

この例の完成条件は「シャツの彩度が下がった」だけではありません。**素材を再生してもシャツの補正量が不自然に変動せず、背景と人物に目立つ影響が出ない**ことを合わせて確認します。

## 操作例：明部の色かぶりだけを軽減する

白いカーテンが青く見える一方、暗い家具と肌は保ちたいとします。色相を使わず明るさだけで選ぶ方が目的に合う場合があります。

1. Qualifierを**LUM**モードにして、明部の輝度域を選びます。HSLでHueとSatを無効にする方法でも、輝度のみのキーを作れます。
2. Highlightでカーテンが選ばれる一方、顔や白い服の明部も入っていないか確認します。
3. 選択域を整え、同じノードの色補正で明部の青みを弱めます。
4. 肌や窓外の白が不自然に変化していないか、Viewerと[RGB Parade](./scopes)で比較します。色付きの照明が意図された場面では、すべての白を中立色へ合わせることが正解とは限りません。

LUMで選べるのは「カーテン」ではなく「指定した明るさの画素」です。位置による限定が必要ならWindowを併用します。

## HSL・RGB・LUM・3Dをどう選ぶか

QualifierにはHSL以外のモードもあります。使用目的が違う場合、HSLの範囲調整だけで粘るより切り替えた方が速いことがあります。

| モード | 選択の基準 | 得意な状況と制限 |
| --- | --- | --- |
| **HSL** | 色相・彩度・輝度 | 条件ごとの幅・Softnessを自分で詰めたいとき。Hueだけ／Satだけにもできる |
| **RGB** | 赤・緑・青のチャンネル値 | RGB別の範囲から選びたいとき。HSLとは調整軸が異なる |
| **LUM** | 明るさのみ | ハイライトやシャドウだけに作用させたいとき。HSLでHue・Satを無効にした選択に相当する |
| **3D** | 画像上で線を描いて採取した色の組み合わせ | 服や空などを素早く抽出しやすい。ただし輝度だけのキーには向かず、HSLのような成分別の細かな制御とは異なる |

どのモードにも向き不向きがあります。たとえば青い衣服のような色領域なら3Dから試し、うまく範囲が絞れない場合にHSLでHue・Sat・Lumを手動調整する、という切り替えができます。一方、シャドウ全体を処理したいだけならLUMが直接的です。

## 期待どおりに選べない場合

| 症状 | 最初に確認すること |
| --- | --- |
| スポイトで選択が変わらない | Qualifierのモード、スポイトの選択状態、対象ノードとクリップ |
| シャツと空が両方選ばれる | Hueだけでは同じ青として入る。Sat／Lumで分けられるか確認し、難しければWindowを併用 |
| シャツの陰だけ抜ける | Lumの下限とSoftnessが狭過ぎないか確認 |
| キーがまだら、境界に穴がある | 白黒Highlightで確認し、Clean Black／Clean Whiteを少しずつ調整 |
| 補正の輪郭が硬く見える | Blur RadiusとIn/Out Ratio、HSL側のSoftnessを確認 |
| 静止画では良いが再生するとちらつく | 複数フレームでHighlightと元画像を確認し、サンプルの偏りや照明変化を疑う |
| 補正した色が想定と大きく違う | [Node Graph](../learn/color-node-graph)内の補正順と素材の色空間／変換位置を確認 |

なおHSL Qualifierは、色相を入力条件として処理範囲を作るツールです。**Hue vs Hue／Hue vs Satなどのカーブは色相・彩度と出力の関係を直接編集するツール**で、目的が近い場合も処理方法は同一ではありません。[Custom Curves](./custom-curves)とも区別してください。
