# Lightbox：タイムラインを一覧して色の流れを点検する

**Lightbox（ライトボックス）**は、Colorページでタイムライン内のクリップを、現在のグレーディングを反映したサムネイルとして一覧する表示です。ショットごとの調整を終えていても、並べて見ると特定のカットだけ暗い、肌が赤い、場面の雰囲気から外れる、といった不揃いに気づけます。

Lightboxで行う中心作業は、**違いを見つけ、見直すクリップを特定すること**です。細部を確定診断したり、一覧の上で最終的な画質を保証したりするための表示ではありません。見つけたクリップを通常のViewerへ戻し、[Scopes](./scopes)やノードを確認してから修正します。

Blackmagic Designの[公式Colorページ](https://www.blackmagicdesign.com/jp/products/davinciresolve/color)「ミスマッチのショットを見つける」は、Lightboxがタイムライン全クリップをグレード適用済みのサムネイルで表示し、画面右上のアイコンから開き、ズームスライダーで表示範囲を変え、サムネイル選択後に閉じると対象クリップのグレードへ移動できると説明しています。本記事の画面導線はその公式説明に基づきます。

## どの比較機能を使うか

| 機能 | 向いている判断 | 比較の単位 |
| --- | --- | --- |
| **Lightbox** | 補正漏れ、シーンの色の流れ、突出したカットを探す | タイムライン全体や連続する多数のクリップ |
| **Split Screen** | 比較するショットを絞り、隣接カットや複数案を見比べる | 選んだ複数フレーム |
| **Image Wipe** | よく似た構図、Stillと現在の画の局所的な差を確かめる | 2画像 |
| **Gallery／Stills** | 良い基準のフレームやグレードを保存・再利用する | 保存した基準 |
| **Scopes** | 明るさ・チャンネルの偏り・色相を画面観察と併せて調べる | 評価中の映像信号 |

Lightboxはグレードを保存するGalleryの代わりではありません。[GalleryとStills](./gallery-stills)で基準を残し、Lightboxで場面全体の整合を見て、必要なときに[Split Screen](./split-screen-comparison)で対象を絞る、という順序にすると役割を混同しません。Split Screenの詳細ページはWriter Bの別稿で、公開前にリンクの受け入れを確認する必要があります。

## 基本操作：一覧から修正すべきクリップへ戻る

1. Colorページで、今回点検するタイムラインを確かめます。複数のタイムラインを使っている場合、別の編集版を誤って評価しないよう、作業対象を先に特定します。
2. 画面右上の**Lightboxアイコン**を使って一覧表示へ切り替えます。公式説明では、タイムライン内のクリップがグレード適用済みサムネイルとして表示されます。
3. **ズームスライダー**を使い、多数のクリップを俯瞰する状態と、少数の隣接ショットを見比べやすい状態を切り替えます。スライダーの正確な段数や21.1での位置はここでは固定しません。
4. 映像の編集順と場面のまとまりを意識し、全体から浮いているサムネイルを探します。特に同じ場所・同じ照明のカットが交互に現れる部分、場面転換の直前直後を見ます。
5. 気になるサムネイルを**選択してLightboxを閉じます**。公式Colorページが案内するこの操作で、対象クリップのグレードへ移動します。選択しただけでグレードがコピーされたと考えないでください。
6. 通常のViewerで問題を再確認し、[Primaries](./primaries-color-wheels)、[Scopes](./scopes)、[Color Management](../learn/color-management-basics)などから原因に合う方法を選びます。
7. 調整後にLightboxへ戻って周辺カットとの並びを再確認し、最後は通常の再生表示でカットのつながりを判断します。

この順序は公式に記載されたLightboxの表示・選択機能を使った**推奨ワークフロー**です。グレード変更の方法や結果の良否は、対象素材や色管理に依存します。

## 最初の一覧で見る項目

Lightboxでは、明確な問題を見つけるために順序を決めると効率的です。

**明るさの連続性。** 同じ室内で顔の露出がカットごとに跳んでいないか、白い壁や衣服の明るさが理由なく変わっていないかを見ます。構図や被写体の距離が変わるだけでも印象は変化するため、サムネイルが均一な平均輝度になることを目標にはしません。

**色かぶりと白の方向。** 似た照明条件のショットで、白いシャツや灰色の机が一つだけ緑・赤に寄っていないかを探します。窓光と室内灯の混色など、画面内の光源差を色かぶりと決めつけないことが重要です。

**シーン全体のLook。** 昼の場面は中立、夜は青寄り、回想は暖かい、といった演出上の変化が場面内でつながっているかを見ます。場面をまたぐ色の違いそのものは異常ではありません。脚本・照明・演出意図と照合します。

**明らかな未補正の候補。** カメラLogのままのように平坦に見えるカットや、特定のショットだけ彩度・コントラストが突出している場合は見直し対象です。ただしサムネイルだけでは、Camera RAWの現像、RCMのInput、CSTやLUTの有無を確定できません。

## 判断例1：2カメラのインタビュー

A1→B1→A2→B2→A3→B3と続く、同一室内のインタビューを想定します。Aのショットは自然なのに、B2だけ顔と背景が緑っぽいとします。

まずLightboxで6カットの並びを見て、B1とB3も同じ方向に寄っているのか、B2だけなのかを切り分けます。Bの全カットが緑なら、Bカメラに共通するInput設定やグループ補正を確認する方が、B2だけを直すより適切な場合があります。一方、B2だけであれば、そのショットの露出・ホワイトバランスやノードの状態を優先して調べます。

B2のサムネイルを選んでLightboxを閉じ、通常のViewerで顔だけでなく背景や無彩色物の色を確認します。[RGB Parade](./scopes)でチャンネルの偏りを観察し、必要なら[ノードの無効化](../troubleshooting/node-bypass-diagnostics)でどの段階から見た目が変わるかを調べます。修正後はLightboxでA/B交互の連続性を再評価します。

**完成判定**は全ショットのサムネイルが同じ色になることではなく、カメラが切り替わっても不必要な肌色・背景色の跳びが気にならないことです。複数カメラの具体的な作業設計は[マルチカメラのショットマッチング](../recipes/matching-multicamera-interview)を参照してください。

## 判断例2：昼から夕方へ変わるシーン

昼の屋外から夕方の室内へ移る映像を想定します。Lightboxで両シーンのサムネイルを眺めると、昼はニュートラル、夕方は暖色という差が見えます。この差は物語上の時間経過を表している可能性があり、消す必要はありません。

ただし夕方の室内に挟まる一つのカットだけ、昼のように青白く見える場合は、周辺のカットと比較します。窓から差す青い光が意図されたショットなら保持します。共通照明なのにそのショットだけ違うなら、[GalleryのStill](./gallery-stills)を基準に、露出とホワイトバランスを調整する候補になります。

ここでは**場面内の連続性**と**場面をまたぐ意図的な差**を分けて判断します。Lightboxの一覧はこの全体判断に向きますが、最終的には時間順で再生し、トランジションを含めて違和感がないかを確認します。

## Lightboxで気づいても、その場で断定しないこと

| 一覧での症状 | 次に確認すること |
| --- | --- |
| 1カットだけLogのように平坦 | Input色空間、RCM／CST、LUTの処理位置、ノード無効化の状態 |
| 同じカメラの全カットが色かぶり | カメラ共通の撮影条件、[Group](./group-grading)、[Timeline](./timeline-grading)の補正範囲 |
| あるカットだけ白い窓が目立つ | 通常ViewerとWaveformで階調を検証。撮影段階の情報欠落と表示上のクリップを区別 |
| 明るさは近いのに肌だけ不自然 | 無彩色の背景と肌を別々に確認。局所補正を安易にコピーしない |
| サムネイルでは整っているが再生で跳ぶ | 動き・照明変化・カットの接続点を通常再生で評価 |
| 全カットがまとめて不自然な色 | 個別の色直しより先にColor Management、Output、表示経路を確認 |

小さいサムネイルでは、ノイズやシャープネス、髪の毛のマスク境界、微細なハイライトの階調を十分に評価できません。[白飛び・黒つぶれの診断](../troubleshooting/highlight-shadow-clipping)などは通常のViewerとScopesを使って行います。Lightboxで良く見えても、納品形式や外部モニターで同じ見え方になる保証はありません。

## 仕上げ前の使い方

先に主要カットをグレーディングし、次にLightboxで**場面ごとに突出するカットを探す**、続いて通常のViewerで必要な補正を行う、という往復を基本にします。最終確認では、実際の編集順に再生して色の移り変わりと各カットの連続性を見ます。

Lightboxは仕上げ作業を助けますが、納品前確認のすべてを代替しません。書き出し設定、カラーマネージメント、信号の範囲、納品先の要求は[Color QC](../recipes/pre-delivery-color-qc)で別に確認してください。サムネイルの見た目だけで納品可否を判断しないことが、一覧表示を使う際の実務上の境界です。
