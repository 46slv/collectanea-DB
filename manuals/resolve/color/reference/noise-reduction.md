# ColorページのNoise Reduction：ノイズを減らしても質感を失わないために

夜景や暗い室内で撮影した素材には、暗部の細かな粒や、肌の影にある色の斑点が見えることがあります。ノイズを減らせても髪の毛や衣装の織り目が消えてしまえば、映像は不自然になります。ColorページのNoise Reductionでは、**減らしたいノイズと残したい細部を同時に判断する**必要があります。

Blackmagic Designの[公式Colorページ](https://www.blackmagicdesign.com/jp/products/davinciresolve/color)は、Motion Effectsパレットに**Temporal（時間方向）**と**Spatial（空間方向）**のノイズ除去があると説明しています。Temporalは複数フレームからノイズを見分け、Spatialは単一フレーム内のノイズを滑らかにします。どちらも輝度（Luma）と色（Chroma）のノイズに対して調整できます。

## TemporalとSpatialは何が違うか

| 方法 | 参照する情報 | 調整するときの観察対象 |
| --- | --- | --- |
| **Temporal Noise Reduction** | 複数フレームの画像 | 暗部の粒だけでなく、動く輪郭・髪・腕が自然か |
| **Spatial Noise Reduction** | 1フレーム内の画像 | ノイズだけでなく、肌・布地・細線のディテールが残るか |
| **併用** | 時間方向と空間方向の両方 | 一方の効果に他方の平滑化が重なり、細部を消していないか |

公式Colorページでは、一般にTemporalから試し、その後必要に応じてSpatialを少しずつ加える方法が案内されています。ただし、すべての映像に両方を適用する必要はありません。粒子を意図的に残したいカットや、激しく動く被写体では、除去を弱める判断もできます。

**Temporalの評価には動画の再生が必要**です。静止フレームで暗部がきれいでも、動きの途中で輪郭が引きずられたり、細部の出方が不自然になったりすれば採用しません。Spatialも、静止画で良く見えたからといって、肌の質感を失ってよいわけではありません。

## LumaとChroma：どちらのノイズを抑えたいか

Lumaは明るさの揺らぎ、Chromaは色の不規則な揺らぎとして観察できます。

- 暗い壁に明暗の細かい粒がちらつくなら、輝度側のノイズを疑います。
- グレーの服や肌の影に赤・緑・青の細かい斑点が見えるなら、色側のノイズを疑います。
- 画面に四角いブロックが見える、グラデーションが段状になる、といった症状なら、圧縮やバンディングなど別の原因も考えます。

「色斑点だけを減らしたい」のか「明暗の粒も抑えたい」のかを最初に決めてください。Colorページ公式資料は双方の成分への調整ができることを説明していますが、**21.1の正確なスライダー名・値域・初期値は未照合**です。実機上の項目を確認し、最初からすべての成分を同じ強さにしない方が判断しやすくなります。

## 処理前の比較条件を固定する

Noise Reductionの強さを決める前に、次の確認をします。

1. **問題の場所を決める。** 暗い壁や肌の影など、ノイズが目立つ部分を選びます。同時に、髪・まつ毛・衣装の細かな模様など、残したい細部も決めます。
2. **動く部分を選ぶ。** 人物が止まっている位置と、歩く・顔を振る・手を動かす位置を両方確認します。時間方向の処理の判断に使います。
3. **表示条件を揃える。** 同じフレーム、同じViewer倍率、同じグレーディング状態で、ノイズ除去の有効／無効を比較します。
4. **補正との関係を見る。** [Primaries](./primaries-color-wheels)で暗部を持ち上げたときにだけノイズが目立つのか、元の映像から目立つのか確認します。
5. **処理の担当を明確にする。** 必要なら[Node Graph](../learn/color-node-graph)で処理を分け、後から有効／無効にして比較しやすい状態にします。ただし21.1のMotion Effectsとノードの処理順の細部は未確認です。

[Scopes](./scopes)は明暗やチャンネルの状態を把握する道具ですが、波形だけではノイズ除去後の毛髪や布地の自然さを判断できません。Viewerで映像を観察してください。

## 操作例1：暗い室内を歩く人物のノイズを抑える

暖色の照明下で人物が歩いているカットを想定します。暗い壁には明暗の粒があり、顔の影には色の斑点があります。背景を整えつつ、髪の輪郭や衣装を残したい場面です。

1. Colorページで対象クリップを選択し、暗い壁がよく見えるフレームと、人物の顔が動く区間を確認します。
2. 公式Colorページが案内する**Motion Effects**パレットを開き、Temporal Noise Reductionの設定を確認します。公式の説明ではColorページの画面左下に位置します。**21.1の正確なアイコン・項目配置は未照合**です。
3. Temporalを少量から試し、粒や色斑点がどう変わるか見ます。Luma側とChroma側を区別し、必要な方向だけ調整します。素材に共通の固定数値は指定しません。
4. 人物が歩く区間を続けて再生します。顔の輪郭、手、髪の毛が不自然になっていないか確認します。静止画のノイズが減っていても、動きが不自然ならTemporalの量や設定を見直します。
5. Temporalで十分ならSpatialを追加しません。細かい粒がまだ必要以上に目立つ場合だけ、Spatialを少しずつ加えます。
6. 処理を有効／無効にし、同じ動く区間で比較します。背景の改善よりも人物の自然さを優先するかどうか、カットの目的に合わせて判断します。

**採否例：** 暗い壁は滑らかになったが、歩く人物の輪郭が妙に柔らかくなるなら除去しすぎです。Temporalを弱め、許容できる粒を残します。これは公式に説明された仕組みから組んだ応用例であり、21.1実機の検証結果ではありません。

## 操作例2：固定インタビューで肌と布地の細部を残す

固定カメラのインタビューで、暗い背景と人物の肌に色の斑点があり、ジャケットには細かな織り目が見える素材を考えます。目的は、人物の見え方を損なわずに色ノイズを減らすことです。

1. 肌の色斑点と、ジャケットの織り目が同時に見えるフレームを選びます。問題の色ノイズと残したい情報を先に決めます。
2. Temporalを穏やかに試し、被写体が静止した部分だけでなく、話し始めて口や手が動く部分も確認します。
3. 色斑点の低減が主目的ならChroma側の変化を中心に観察します。Luma側まで強く処理する必要があるか、毎回見直します。
4. まだ気になる粒がある場合だけSpatialを追加し、まつ毛・髪・ジャケットの模様が減りすぎないか確認します。
5. 処理前後を同じ表示条件で見比べ、短い区間を連続再生します。静止から動きへ移ったときだけ質感が変わらないか確認します。

**採否例：** 肌は均一でも目元の細部や布地がなくなるなら、除去量を戻します。背景に多少の粒が残っても、人物が自然に見える方が適切な場合があります。素材に元々存在しない細部を、ノイズ除去によって復元できるわけではありません。

## ノイズ除去と別の症状を混同しない

撮影ノイズ、圧縮によるブロック状の崩れ、グラデーションの段差は原因が異なることがあります。ノイズ除去を強くしても改善しないときは、元ファイルと変換後のファイルを比べるなど、別の原因を確認します。

ノイズ除去で失われた微細な質感を、後段でシャープを強くかければ元どおりにできるとは限りません。処理後のシャープさより、**処理前からある細部が維持されたか**を優先して評価します。[Color Management](../learn/color-management-basics)やLUTの扱いで画面の明るさが変化している場合は、比較条件も揃えてください。

## 期待した仕上がりにならないとき

| 症状 | 確認すること | 次の判断 |
| --- | --- | --- |
| 色の斑点がまだ目立つ | Chroma成分と元画像の状態 | 気になる成分を中心に調整 |
| 動く輪郭に残像のような違和感がある | Temporalを加える前後の再生 | Temporalの量や設定を見直す |
| 肌がのっぺりする | Spatial前後の肌・まつ毛・髪 | Spatialを弱めて細部を残す |
| 布の細かな模様が消える | 同じフレームの補正前後 | 除去しすぎていないか判断する |
| 静止画では良いが動画で変 | 人物の動く区間 | 動画の結果を優先する |
| 暗部を持ち上げると粒が目立つ | 元画像と[Primaries](./primaries-color-wheels)の補正 | グレードとノイズの原因を分ける |
| 四角い崩れや段差が残る | 圧縮・バンディング等の別要因 | ノイズ除去以外の処置を考える |
| 比較結果が一定しない | 表示倍率、再生位置、処理の有効／無効 | 同じ条件へ戻して確認する |
| 再生が重くなる | 処理の有無によるプレビューの変化 | 再生負荷と画質評価を分ける |
