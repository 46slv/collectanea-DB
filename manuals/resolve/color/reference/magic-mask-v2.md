# Magic Mask v2：人物や物体をクリックして補正範囲を作る

**Magic Mask v2**は、Colorページの画像内で人物や物体をクリックすると、DaVinci Neural Engineが対象の形を推定し、局所補正用の**マット（どこを補正するかを示す白黒の選択範囲）**を作る機能です。衣服だけを暗くする、人物を背景と分けて色を調整するといった用途に使います。

DaVinci Resolve **21.1のStudio版向け機能**です。以下はBlackmagic Designの21.1公式Reference Manual、Chapter 139「Magic Mask」pp.3280–3288に基づきます。本文の操作は実機で再検証していないため、画面表示や処理速度、実素材でのマット品質は未確認です。

Magic Mask v2は、従来版（v1）の線を描く操作から**クリックで対象を指定する方式**に変わりました。v2には人物／物体のモード切り替えがありません。v1の操作手順や「人物モードを選ぶ」という説明をv2へ読み替えないでください。

## 何を入力し、何が得られるか

入力は、現在のクリップ画像と、対象を示す**追加クリック（青）／除外クリック（赤）**です。追跡を行うと、指定した対象の動きに合わせて各フレームのマットが生成されます。作成したマットは、そのノードの露出・彩度・色相などの補正範囲を制限するために使えます。

[HSL Qualifier](./hsl-qualifier)や[3D Qualifier](./3d-qualifier)は色の条件から範囲を選びます。[Power Windows](./power-windows)は画面上の形や位置を使います。Magic Maskは**対象の見た目や輪郭を推定**するので、衣服と背景が似た色でも選択できる場合があります。ただし、自動生成した境界が全フレームで正しいとは限りません。

## 基本操作：対象をクリックして追跡する

1. Colorページで対象クリップを開き、[Color Node Graph](../learn/color-node-graph)に局所補正用のノードを用意します。全体の色調整とはノードを分けると、マットの影響範囲を確認しやすくなります。
2. **Magic Mask**パレットを開き、Viewer上で残したい人物または物体の内側をクリックします。追加のクリックは**青**で表示されます。クリックは対象の中心寄りに置くのが基本です。
3. **Mask Overlay**を有効にし、赤い半透明の表示でどこが選択されたか確認します。必要な部分が欠けたら追加クリック、不要な部分が入ったら**Subtractive Click（除外クリック）**を使います。除外クリックは**赤**で表示されます。
4. クリックを置き直す場合は、ポインターで既存のクリックを移動します。クリックは結果へ随時反映されるため、同じ場所へ追加し続ける前に位置を調整します。
5. パレットの**Track Forward／Track Reverse**などで、クリックの周辺画像を追跡します。複数のクリックがあればまとめて追跡されます。追跡済みフレームは全体トラック表示の**青い範囲**で確認できます。
6. クリップの始点・中間・終点と、被写体が重なる場面でマットを点検します。崩れた箇所では、追跡の停止・1フレーム単位の追跡・クリック位置の修正を検討します。
7. 選択範囲が十分ならマットを表示しない状態へ戻し、[Primaries](./primaries-color-wheels)などで補正します。ノードのオン／オフを比較して、対象外の変化も確認します。

クリックは**そのフレームの座標を固定するWindowではなく、追跡する対象を教える手がかり**です。対象が画面内を動くなら、静止画での選択が良好でも時間方向の確認が必要です。

## 主な設定と使い分け

| 項目 | 役割 | 判断の目安 |
| --- | --- | --- |
| **Add／Subtract Click** | 選択対象を追加・除外するクリック | 欠けた領域には追加、余計な領域には除外を使う |
| **Click List** | クリックごとの選択、オン／オフ、削除と追跡範囲の確認 | 失敗したクリックを重ねず、既存のクリックを整理する |
| **Mask Overlay** | 赤い半透明のマット表示を切り替える | 対象と背景の境界を確認するとき |
| **Invert Mask** | 作成したマットの内外を反転する | 人物を残して背景だけを補正したい場合 |
| **Quality: Faster** | 速度を優先した、詳細が少ないマットを作る | 大まかな領域制限など、境界の精密さが不要なとき |
| **Quality: Better** | より詳細なマットを計算する | 輪郭の精度が必要なとき。処理負荷は大きい |
| **Smart Refine** | 画像解析を使ってマットを拡大・縮小する。**Better**で利用する | 輪郭を調整しつつ、周囲への不用意な広がりを抑えたいとき |

**Fasterが常に悪いわけではありません。** 広めの領域を限定するだけなら、詳細な輪郭を計算する必要がない場合があります。画面上で結果を比較してQualityを選びます。

## マットの穴・輪郭・ちらつきの調整

Magic Maskの**Matte Finesse**には、解析後のマットを整える設定があります。どの症状を直すか決めてから、少量ずつ変更します。

| 項目 | 主な働き | 注意点 |
| --- | --- | --- |
| **Mode／Shape・Radius** | Shrink／Grow、Opening／Closingなどでマットの領域や穴を調整する | 選択した処理の種類に応じてRadiusの意味が変わる |
| **Clean Black** | 選択外の黒領域に出る白い点状ノイズを抑える | 必要な細部まで削らないか確認する |
| **Clean White** | 選択内の黒い穴を埋める方向に作用する | 狭い隙間や本来の透過部分に注意する |
| **Blur Radius** | 境界をぼかす | 大きくすると被写体の周囲ににじみが出ることがある |
| **Denoise／Post Filter** | マットのノイズ抑制、画像に基づく細部の仕上げ | 毛髪などの細い形が残るか確認する |
| **Consistency** | 追跡後、信頼度の低い輪郭の時間方向のちらつきを抑える | 値を強めるほど負荷が増え、動きへの追従にも影響する |

**Consistencyはクリックに数フレーム以上の追跡区間が必要**です。短い区間だけのクリックでは、時間方向の平滑化によってその効果が弱くなる場合があります。静止フレームの見た目だけで調整を終えず、再生して輪郭を見ます。

[KeyパレットとMatte](./key-matte)では、マットと補正強度を区別する考え方を説明しています。

## Paint Toolは短い破綻の修正用

v2には**Add／Subtract Paint Stroke**とブラシサイズの調整があります。例えば追跡中の数フレームだけ指輪が誤って人物マットへ入った場合、**Subtract Paint Stroke**でその箇所を除外できます。

ただし、Paintの修正は**フレーム単位**で、追跡に合わせて移動しません。長い区間で同じ間違いが続くなら、Paintを多数のフレームへ追加する前に、クリックの追加・除外・移動や追跡結果を見直します。

## 判断例：人物のジャケットだけ彩度を抑える

青いジャケットを着た人物が、似た色の背景の前を歩くショットを想定します。

1. ジャケットの内側に追加クリックを置き、Mask Overlayで選択を確認します。腕や胴体の一部が欠ければ追加クリックを検討します。
2. 背景や肌が含まれたら、まず除外クリックの位置を見直します。人物全体が選択される場合もあるため、望むのがジャケットか人物全体かを確認します。
3. 前後へ追跡し、人物が別の被写体の前を通るフレームと画面端を確認します。短時間の誤抽出はPaint Tool、長い区間の問題はクリックと追跡を調整します。
4. Matte Finesseで輪郭と穴を整え、彩度の補正を適用します。ジャケット以外の色が変わらず、動きの途中で輪郭が目立たないことを確認します。

これは**21.1の機能に基づく作業例**であり、実際のジャケット素材で成功を測定した結果ではありません。クリックで目的の部分を分離できない場合は、[Power Windows](./power-windows)による位置の制限や[Qualifier](./hsl-qualifier)との併用を検討します。

## 外部マットの作成と旧版の区別

公式Manualには、パレットの**3点メニュー → Render in Place Magic Mask**からキャッシュフレームの保存先を指定し、結果を外部マットとして利用する方法が記載されています。出力先や管理方法はプロジェクト運用に依存するため、既存メディアやファイルを上書きしない場所で確認します。

同じメニューにある**Legacy Object Mask**は従来のMagic Mask v1を開くための選択肢です。v1では線を描く手法や人物・物体モードを用います。本ページのクリック操作、Quality、Paint Toolの説明は**v2**が対象です。
