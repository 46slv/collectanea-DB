# インタビュー中のホワイトバランスの揺れを整える

固定カメラのインタビューで、人物が色の強い物を手に取るたびにカメラのオートホワイトバランスが変わり、肌や白い壁が青み・黄みに寄ってしまうことがあります。このレシピでは、**変化していない壁の一部を分析基準にして、ショット全体の不要な色の揺れを抑える**方法を扱います。

使用するのはDaVinci Resolve **21.1 Studio版**のResolve FX **Color Stabilizer**です。機能の各項目は[Color Stabilizerリファレンス](../reference/color-stabilizer)を参照してください。ここでは実際の作業で、**どの領域を分析し、何を残すか**を中心に説明します。

## 素材条件と完成の判断

想定素材は、室内で同じ人を約30秒間撮影した単一ショットです。カメラ位置と照明は固定。背後には影の少ない灰白色の壁があり、人物が途中で赤い小物をカメラの近くに持ち上げます。小物が入る前後で、壁と肌の色が意図せず変わります。窓の外の明るさはほぼ一定で、壁の小さな範囲は人や小物に隠れません。

撮影時の入力色空間とガンマ、プロジェクトの色管理方式を確認しておきます。RCMとCSTのどちらで入力／出力変換を担っているか曖昧なら、まず[カラーマネージメントの基礎](../learn/color-management-basics)で整理します。色変換を重ねた状態で、色の揺れをStabilizerだけで解決しようとしません。

完成の目安は、同じ壁が時間とともに不必要に青・黄へ動かず、肌の色も急に切り替わらないことです。**小物そのものの赤色や、照明で生じた本当の変化を消すことは目標にしません。**完成判定には基準フレーム、変化が最大のフレーム、小物が去った後のフレームを使用します。

## 1. 変動の原因を先に確認する

1. Colorページで対象クリップを選び、Viewerを再生します。小物が入る直前、色が変わった時点、元の構図へ戻った時点を確認します。
2. [Scopes](../reference/scopes)のRGB Paradeも使い、壁と人物の色の変化を確認します。構図が変わるとスコープ全体の分布も変わるため、**Paradeだけでホワイトバランス変動を断定しない**でください。
3. 収録時点で壁の色が動いているか、既存のノードや自動調整によって生じた変化かを切り分けます。元映像の照明自体が変わるなら、その変化を残すべきか先に判断します。
4. 明るい壁や窓がすでにクリップしていないか確認します。公式ManualはColor Stabilizerについて**クリップしていないハイライトの素材で結果が良くなる**と説明しています。失われた階調をこのFXで復元できるとは想定しません。

## 2. Color Stabilizer用のノードを分ける

最初は、次のような単純な直列構成にします。

| ノード | 役割 |
| --- | --- |
| 01：必要なハイライト調整 | 保持できるハイライトを、Stabilizerに入る前に整える |
| 02：Color Stabilizer | ショット内の露出・色の時間変動だけを補正する |
| 03：最終的なグレード | 肌の印象、コントラスト、作品のLookを仕上げる |

Colorページの02ノードにColor Stabilizerを適用します。公式Manualは、Colorページで使用する場合に、必要なハイライトを先に調整してからStabilizerを掛けるよう案内しています。また、**完成グレードを先に作ってからStabilizerを使うと結果が予測しづらい**としています。このため、01は必要な準備にとどめ、Look作りは03に分けます。

Manualにある「1023以下」は同Manualのハイライト処理についての数値であり、すべてのカラーマネージメント構成で共通の表示目標として扱いません。色管理とスコープの表示条件に合う方法でクリップ状態を判断します。

## 3. 壁の一定領域を分析する

1. 小物が入っていない、壁・肌が自然に見えるフレームへPlayheadを移動します。以後、このフレームを基準とします。
2. Color Stabilizerの**Region of Analysis**を**Selected Area**にします。Viewerに現れる矩形を、壁の中でも影や反射が少ない領域へ置きます。
3. クリップの最初から最後までその矩形の中身が一定であることを確認します。人物や小物が一瞬でも重なるなら、矩形の位置・大きさを変えます。
4. 基準フレームへ戻り、**Analyze Now**を実行します。
5. **What to Stabilize**を**White Balance and Brightness**とし、この例では**Stabilize White Balance**だけを有効にして比較します。実際に露出も揺れる場合に限り、**Stabilize Brightness**を別に有効化して効果を確認します。

**Selected Areaはその矩形だけに補正を掛けるマスクではありません。**解析を行う場所を限定し、補正はクリップ全体へ作用します。したがって、赤い小物の色まで不自然に変わらないかも確認します。被写体に追従する領域を使う必要がある場合はFX Trackerを利用できますが、この例のように固定された壁の領域を選べるなら追跡は必須ではありません。

## 4. 三つの時点と無効化比較で評価する

基準フレーム、色の揺れが最も目立つフレーム、終了付近のフレームを行き来して、次を確認します。

- 灰白色の壁が、同じ照明下なのに急に青・黄へ切り替わらなくなったか。
- 肌の色の切り替わりが減った一方で、赤い小物の見え方まで不自然に変化していないか。
- 明るさが維持されるべきショットで、予期しない明暗の変動が増えていないか。
- 02ノードだけを一時的に無効化すると、問題の色の揺れが再び現れるか。

この比較は[ノード無効化とグレードバイパス](../troubleshooting/node-bypass-diagnostics)の考え方で行います。**壁の色が一様に見える静止フレーム1枚だけで成功と判断せず、再生して時間方向の変化を確認します。**

補正後に階調まで不自然になった場合は、Color Stabilizerの**Stabilize**方式を**Levels and Contrast／Offset／Gain**で切り替えて結果を比べます。公式Manualは三方式の利用を案内していますが、この素材でどの方式が最良かは実機・素材依存です。固定値や万能な順位は示しません。

## うまくいかないとき

| 症状 | 最初に調べること | 次の操作 |
| --- | --- | --- |
| 人物の動きに合わせて補正が不安定 | Selected Area内に人物・小物・動く影が入っていないか | 壁の遮蔽されない領域へ矩形を置き直して再解析する |
| 壁は安定したが肌の色が不自然 | 壁の照明と顔の照明が異なり、実際の光変化まで補正していないか | 無効化比較を行い、補正自体の適否を判断する |
| 明るさも不自然に変わる | Stabilize Brightnessが必要なく有効になっていないか | Brightnessを外し、White Balanceだけで比較する |
| 完全に白く飛んだ窓の階調が戻らない | 元素材のハイライトがクリップしていないか | 元素材で保持されている情報と前段補正を確認する |
| 基準フレームと別時点の色が余計に離れた | 基準フレーム、矩形の位置、補正方式が適切か | 別の基準フレーム・分析領域・方式を比較する |
| 一定にしたい壁ではなく照明演出まで平坦になる | 残すべき時間変化を解析対象へ含めていないか | 適用範囲の設計を見直し、必要ならFXを使わない |

Color Stabilizerで揺れを抑えた後、03ノードで必要な肌色やコントラストを調整します。最終的には**補正なし／Stabilizerのみ／最終グレード**を切り替え、実時間で確認します。[Primaries](../reference/primaries-color-wheels)を使う場合も、色の揺れと単なるLookの好みを分けて判断してください。
