# ノードリファレンス（Node Reference）

Fusionで使うノード（Node）と関連要素を、名前だけでなく、何を受け取り、何を返し、どの場面で使うかから確認するためのリファレンスです。

一覧から探す場合は [ノードA–Z（Node A–Z）](../index/node-a-z) を使ってください。一般的な仕組みは [Learn](../learn/) に、複数ノードへ再利用できる組み方は [Patterns](../patterns/) に分けています。

## 掲載範囲

現在は **359ページ** を収録しています。

- Fusion 21カタログ由来の357項目
- Resolve内Fusionの入出力境界となる `MediaIn` / `MediaOut`
- 通常のFlowノードだけでなく、ModifierとPaint内部要素も検索対象に含む
- 2D Image、Mask、Shape、Particle、Classic 3D、USD、Deep、Krokodoveを区別して記述

カタログ上で同名の `Offset` は、Modifier版とKrokodove版を別ページとして扱います。

## 各ページで確認できること

Node Referenceは、ノード名や分類を検索するだけの一覧ではありません。初めてそのNodeを見る場合でも、**何を入れると、何が起きて、どこへ出せて、実際に何へ使うのか**を判断できることを基準にします。

各ページでは、確認できている範囲で次を説明します。

- **役割** — Flowの中で何を担当し、入力前と出力後で何が変わるか
- **入力** — 何を接続するのか、どのデータ領域を受け取るのか
- **出力** — 何が返り、次にどの種類のNodeへ渡せるのか
- **主な設定項目** — 値を変えると見た目や処理がどう変わるか
- **主な用途** — 実際にどんな画や処理を作るときに使うか
- **最小構成** — Nodeの役割だけを確認できる最短のFlow
- **運用例** — 素材、目的、接続結果まで含めた具体例
- **似たNodeとの違い** — どちらを選ぶべきか判断できる比較
- **バージョンと検証状況** — どこまで現行仕様を確認できているか

「ShapeをGrid複製」「色を処理」のように、別の専門語へ言い換えただけの説明は完成扱いにしません。専門語が必要な場合は短く意味を説明し、詳しい概念ページへつなぎます。

## 記述の境界

役割と系譜を確認できても、Fusion 21.1実機で端子名・Inspector項目・初期値・数値範囲を確認できていない項目は `partial` としています。

未確認の仕様は推測で埋めません。ただし、端子名や数値範囲が未確認であることを理由に、役割や使い方まで抽象的な一行で済ませません。確認済みのデータ領域・処理内容・接続関係から、読者が結果を想像できるところまでは具体的に説明します。

Shape、Mask、Deepなど、複数Nodeにまたがる概念はLearn側に説明ページを持たせます。Node本文では重要な初出を下線付きの用語表示にし、hover / focus / tapで短い説明を確認できるようにします。
