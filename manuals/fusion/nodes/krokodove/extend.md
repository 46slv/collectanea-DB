# Extend（Krokodove）

**Extend**は、画像の端にある画素を水平方向または垂直方向へ繰り返し、元画像の色や模様が横・縦に引き伸ばされたような見た目を作るKrokodoveのツールです。

たとえば画像の左端が赤い画素の列なら、その列が横方向へ続くと赤い帯に見えます。端の色が縦方向に細かく変化していれば、その色の変化を残した縞のような見た目になります。これは**効果の考え方を示す例**であり、実際にどの端からどの範囲へ画素が反復されるかは未確認です。

DaVinci Resolve 21.1 Reference Manualは、Extendを「Image Tools」に分類し、画像端の画素を横または縦の軸に沿って複製する効果と説明しています。**画面外の被写体を復元する機能**としては紹介していません。

## 画像端の画素を繰り返すとは

ここでいう画像端は、画面を囲む長方形の上・下・左・右の縁です。人物や文字など、画像内にある物体の輪郭を自動認識して伸ばすという意味ではありません。

| 方向 | 模式的な考え方 | 見た目の例 |
| --- | --- | --- |
| 水平 | 左右いずれかの端の縦一列を横方向に繰り返す。 | 上下方向の色の変化が、横に続く帯や筋になる。 |
| 垂直 | 上下いずれかの端の横一行を縦方向に繰り返す。 | 左右方向の色の変化が、縦に続く帯や筋になる。 |

この表は公式の短い説明を理解するための**概念的な例**です。どの端を選択するのか、反復を始める位置、範囲、補間方式、横と縦の併用可否を公式の一行から確定することはできません。

Extendが元画像の端を材料にする以上、元の画像に存在しない腕や建物の続きが自然に生成されると考えるべきではありません。端の色や模様を反復したことが見える、グラフィック的な効果として理解すると用途を判断しやすくなります。

## 入力と出力

| 段階 | データ | 役割 |
| --- | --- | --- |
| 入力 | 2D Image | MediaInや画像生成ツールなどから、画素を持つ画像を受け取る。 |
| 処理 | 画像端の画素の反復 | 端の画素を水平または垂直方向に繰り返す。 |
| 出力 | 2D Image | 加工した画像をViewer、後段の合成、出力へ渡す。 |

<Term id="image">Image</Term>は、色や透明度などの値を持つ画素からなる画像データです。Krokodoveの中にはShapeや3D Sceneを扱うツールもありますが、ExtendはManualのImage Toolsに分類され、既存カタログでも画像の入力・出力として整理されています。

この表は**扱うデータの種類**を示しています。正式なポート名・端子数・補助入力は実機未確認であり、表の「入力」と「出力」はInspectorやノードタイルの表示名を示すものではありません。

## 主な用途

### 写真の端から帯を作る

写真の端に、空の青・建物の灰色・人物の服の色などが並んでいる場合、その端の色を横または縦方向に反復させることで、素材由来の配色を持つ帯状の背景を作る発想に使えます。元画像とまったく無関係な単色を足すのではなく、**元の映像の外周にある色をデザインの材料にする**方法です。

### タイトルや画面分割の背景

タイトルの後ろに細い色の筋を並べたい場合や、画面分割の一部を抽象化したい場合にも候補になります。ただし、Extend単体でキャンバスが広がるか、透明な余白が埋まるかは確認できていません。最終的な配置は後段の合成結果を見て決めます。

### 動画の端を使った動きのある表現

動画では画面端の色もフレームごとに変化します。元映像に合わせて帯の色が変わる演出を検討できますが、境界の揺れやちらつきが生じる可能性もあります。Extendに時間方向の平滑化機能があるとは確認されていないため、動画の前後のフレームを含めて観察します。

## 最小構成と具体的な確認方法

以下は動作を見分けるための**確認用の接続例**です。公式Manualに掲載された専用グラフではありません。

    MediaIn（端の色が分かりやすい素材） → Extend → MediaOut

1. 左右の端と上下の端が、それぞれ異なる色になるテスト画像を用意します。単色だけの画像より、どの端の画素が使われたか観察しやすくなります。
2. Extendの前の画像をViewerで表示し、外周の色と模様を確認します。
3. Extendを接続し、Inspectorに**実際に表示される**方向・作用範囲に関する設定があれば、一つずつ変更して前後を比較します。この記事では未確認の設定名や数値を指定しません。
4. 横方向へ色が伸びた部分と、縦方向へ伸びた部分をそれぞれ探します。画像全体を単に拡大・移動した場合と異なり、**端の色が繰り返される見た目になっているか**を確認します。
5. 次に細かな模様がある画像や透明領域を含む画像で試し、反復した筋、境界、Alphaの変化を観察します。
6. 動画で利用する場合は、端の色が大きく変化する箇所を再生して、不自然な跳ねやちらつきがないか確かめます。

変化が分かりにくい場合は、ツールが無効だと判断する前に画像端の色をはっきり変えたテスト素材を使います。効果が出る位置や画像の有効範囲も、この確認作業で調べる対象です。

## 近いツールとの違い

| ツール | Manualで確認できる役割 | 用途の違い |
| --- | --- | --- |
| **Extend** | 画像端の画素を水平・垂直方向に繰り返す。 | 端の色や模様が一方向に続くグラフィックを作りたい。 |
| [Clean Edges](./clean-edges) | フレーム端の画素を複製または単色で補う。 | 不要な線・色の帯を目立たなくしたい。 |
| [Grow Color](./grow-color) | 画像端の色を伸ばし、透明部分を埋める。 | 透明領域に周辺の色を広げたい。 |
| [Seamless](./seamless) | 反対側の端を鏡映しにして混ぜる。 | 画像を並べるときの継ぎ目を調整したい。 |
| Crop・トリミング | 画像の不要な外周を表示範囲から外す。 | 伸ばさずに切り落とせる場合。 |

**ExtendとGrow Colorは、どちらも「伸ばす」ものだと一括りにしない**ことが重要です。Grow Colorは公式説明に「透明部分を埋める」とありますが、Extendは「端の画素を反復させた効果」とされています。この違いは用途選択の手掛かりになります。ただし、両者の透明度処理や正確な複製範囲は実機未確認です。

## 仕上がりと未確認事項

- **反復の見え方：** 同じ色が長く続くと自然な背景ではなく筋に見えることがあります。意図した演出か通常倍率でも確認します。
- **境界：** 元画像と反復領域の境目が目立つ可能性があります。最終的な合成背景でも見ます。
- **Alpha：** 色の反復に透明度がどう追随するかは未確認です。暗い背景と明るい背景を切り替えて確かめます。
- **出力範囲：** Extendが解像度、画像の有効範囲、キャンバスサイズを変えるかは確認されていません。「空白を必ず埋める」「画像サイズを広げる」とは断定しません。
- **実機差：** 実機例ではStartとDirectionを使用しました。全項目の初期値・値域、REGID、Resolve Free・Studio・Fusion Studioでの差は未確認です。
