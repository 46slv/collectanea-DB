# Heightfield Create 3D

**Heightfield Create 3Dは、画像の明るさをもとに平面へ奥行き方向の起伏を作る**Krokodoveの3Dツールです。平らな板の上に画像を貼るだけではなく、画像の明暗を立体の形を決める情報として利用します。

たとえば、暗い領域と明るい領域のある画像を用意すると、その違いを平面の高さの差に反映する表現が考えられます。DaVinci Resolve 21.1 Reference Manualでは、画像の輝度による奥行き変形に加え、**四角形や棒状の形に変形を整える**機能が説明されています。

ここでいう高さは、画面上の上下移動ではなく**3D空間で平面の奥行きが変わること**です。実際の起伏は正面から見るだけでは分かりにくいため、斜めから観察すると違いを確認しやすくなります。

## Imageと3D形状の役割

このツールを理解するには、**変形を指示する画像**と**できあがる立体**を分けて考える必要があります。

- **画像マップ**：どこをどの程度変形させるかを表すための画像。Manualが明記する基準は画像の輝度（luminance）です。
- **平面の奥行き変形**：画像を参照して立体の凹凸を作る処理です。単に画像の色を明るくしたり、2D画像を上下にずらしたりする処理ではありません。
- **四角形・棒状の表現**：Manualには、平面の変形を squares または bars の形へ整えられると記載されています。ただし、切り替えに使うInspectorの正式な設定名や、形状を分割する具体的な計算方式は記載されていません。

Fusionの<Term id="image">Image</Term>は画素を持つ2Dデータです。一方、<Term id="classic-3d">Classic 3D scene</Term>は立体の位置や形状を後段の3Dツールへ渡すためのデータです。記事メタデータの `inputs: [image]` と `outputs: [classic-3d]` はこの役割を探すための分類であり、**実機の接続端子名や本数を証明するものではありません**。

## 入力と出力

| 段階 | 確認できる内容 | 未確認の点 |
| --- | --- | --- |
| 画像マップ | 輝度をもとに平面の奥行きを変える。画像マップによる押し出しが説明されている。 | 画像の必須入力端子名、複数入力の有無、どのチャンネルを読むか |
| 形状生成 | 平面に起伏を作り、四角形・棒状の変形も扱う。 | 平面の分割数、変形量、方向、基準位置の正確な設定 |

Manualの説明だけでは、**明るい画素が手前に伸びるのか、奥へ引っ込むのか**、黒をゼロ高さとするのか、画像のAlphaを参照するのかまでは確定できません。明暗と高さの関係を説明するための例と、実際の設定値を混同しないようにします。

## 主な用途

### 画像の明暗から地形状の起伏を作る

緩やかなグラデーションや濃淡のあるノイズ画像を形状の基準にすると、滑らかな高低差のある面を作る用途が考えられます。これは**公式の個別作例ではなく、輝度による奥行き変形を応用した制作案**です。平面の細かさやノイズの解像度だけで見た目が決まるとは限らないため、まず単純な画像で挙動を確かめます。

### 棒状の立体でデータ表示風の背景を作る

Manualには変形を棒状に整える機能が記載されています。複数の棒が並ぶような立体背景や抽象的な情報グラフィックを検討できます。ただし、**各棒の位置・本数・高さを独立した数値で直接指定できる**とまでは確認されていません。

### タイトルの背後に凹凸のある面を置く

画像マップから作った立体を、カメラと照明を使って描画し、タイトル用の背景素材にする構成が考えられます。立体を作っただけでは画像として完成しません。3D結果を2Dへ描画する段階は、標準の[Renderer 3D](../3d/renderer-3d)の役割です。

## 制作例：白黒マップで起伏を比較する

次は、公式Manualの機能説明をもとにした**実機確認用の手順案**です。Heightfield Create 3Dの端子接続・Inspector操作を検証済みのレシピではありません。

1. 白と黒が大きく分かれた画像を用意します。最初は細かい写真よりも、二つの明るさの違いが分かる単純な画像のほうが比較しやすくなります。
2. FusionにHeightfield Create 3Dを追加し、実際に表示される入力端子を確認します。画像を受け取る端子がある場合は、種類を確かめてから白黒画像を接続してください。**正確な端子名は未確認**です。
3. 平面を正面と斜めの視点から確認します。明暗の境界に対応して凹凸が変わるかを見て、単なる表面色の変化との違いを確かめます。
4. Inspectorに四角形・棒状の変形を選ぶ項目があれば、画像はそのままで切り替えて違いを観察します。Manualはこの形状を挙げていますが、正式な項目名や選択方法は示していません。
5. 生成結果が標準のClassic 3D sceneとして接続できることを実機で確認できた場合は、[Merge 3D](../3d/merge-3d)でカメラや照明と合わせ、Renderer 3Dへ送ります。3D経路の実際の互換性は、このページでは未検証です。
6. 画像マップを一様な明るさ、二階調、グラデーションの順に替えてみます。結果を比較すると、どの種類の明暗変化が立体に反映されるかを観察できます。

画像の**色がそのまま立体の表面へ貼られる**とは限りません。形の変化と見た目の色・材質は別の要素として確認してください。

## 標準の3Dツールとの違い

| ツール | 役割 | 選ぶ目安 |
| --- | --- | --- |
| **Heightfield Create 3D** | 画像の輝度を使って平面の奥行きに起伏を作る。四角形・棒状の変形にも言及がある。 | 明暗をもとに平面そのものの立体表現を作りたい |
| [Displace 3D](../3d/displace-3d) | **入力済みの3Dメッシュ**の既存頂点を、画像の画素値に応じて移動する。 | 自分で用意したメッシュを変形したい |
| [Fold Create 3D](./fold-create-3d) | 平面を区画に分け、定めた順序で折る。 | 折り紙・折れるカードのような動き |
| [Mapped Duplicate 3D](./mapped-duplicate-3d) | 3Dオブジェクトを格子状に複製し、画像で変化を制御する。 | 同じ立体を繰り返し配置したい |

似ているのはDisplace 3Dですが、**既存メッシュを変位させるのか、画像をもとに平面の立体表現を作るのか**が選択の目安です。Displace 3Dの分割数・UV・設定値を、Heightfield Create 3Dにも同じように使えるとは推測しません。

## 注意点と未確認事項

- **明暗と高さの対応**：輝度を使うことは確認できますが、明部と暗部がどちら向きへ動くか、変位の単位や基準値は未確認です。
- **端子**：画像入力の正式名・数・必須条件、出力の正式な型、マスク・材質入力の有無は実機で確認が必要です。
- **Inspector**：四角形・棒状の変形は公式に記載されていますが、切替項目名、初期値、範囲、分割設定を推測しません。
- **画質と負荷**：画像解像度、形状の分割数、描画負荷の関係はこのツール固有の実測がありません。
- **バージョンとエディション**：21.1 Manual掲載を確認した範囲です。Resolve Free / Studio / Fusion Studioの提供差、内部REGID、実機の動作確認は未実施です。
