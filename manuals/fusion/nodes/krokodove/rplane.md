# rPlane

rPlaneは、**平らなカードのような形の「作用範囲」**を作るKrokodoveのRegionツールです。たとえば、映像の一部だけに別の処理をかけたいとき、その処理を受け持つノードへ「この範囲を使う」という情報を渡す役割があります。

ここでいう<em>Region</em>は、効果を適用する場所を指定するためのデータです。rPlaneそのものが板のCGを描いたり、入力映像を直接加工したりするわけではありません。画像（Image）、3Dシーン、作用範囲（Region）は別の種類の情報であり、接続先のノードも異なります。Krokodove全体の分類は[画像・Shape・3D・Regionの案内](./)を参照してください。

## 入力と出力

| 接続 | 何を扱うか |
| --- | --- |
| 入力 | ManualはrPlaneを領域の**生成**ツールとして説明しています。必須入力の有無、補助入力の数や正式名称は未確認です。 |
| 出力 | 平らなカード状の**Region**。Region入力を備えた対応ツールへ渡し、効果の作用範囲として使います。 |

Manualが明示しているのは「flat card regionを作り、Region入力のある他ツールと組み合わせる」という役割です。標準のImage入力、Mask入力、3Dシーン入力へ同じように接続できるとは限りません。ソケットの色、正式なポート名やデータの内部表現も、21.1の記述だけでは確定できません。

## どのような範囲になるか

「flat card」は、厚みのある箱や球ではなく、**平らな面を基準にした領域**を指します。領域に対応する効果へ渡すと、その面を基準にどこへ効果を適用するかを決める材料になります。

ただし、これを「画面のXY平面に固定された長方形」や「厚みが厳密にゼロの無限平面」と読み替えるのは適切ではありません。Manualの短い説明からは、面の初期方向、領域の広がり、厚さ、カメラとの関係、裏表の扱いまで分かりません。実際の範囲は、接続先とViewerで確認します。

## 主な調整

21.1 Reference Manualは、rPlaneに**Softness / Invert / Transformに相当する調整**があると説明しています。次は操作を理解するための目安であり、Inspectorの正式なラベル・初期値・数値範囲を列挙したものではありません。

- **Softness（境界の柔らかさ）**：効果が効く範囲と効かない範囲の境目を調整する考え方です。境界のぼかし方や減衰の計算方法は未確認です。
- **Invert（反転）**：指定した領域と、その外側のどちらを対象にするかを切り替えるための調整です。具体的な結果は対応ツールで比較します。
- **Transform（変形）**：平らな範囲の配置や形を調整するための操作群です。位置・回転・大きさにそれぞれ独立した項目があるか、座標の単位や変形の順序はManualからは断定できません。

## 運用例：平らな範囲で効果を制限する

映像の一部分だけに効果をかけたい場合を想定した、**接続と動作を確かめるための手順**です。特定のKrokodove効果との組み合わせを実機で確認した完成レシピではありません。

1. Fusionで、適用したい処理を担当するツールを置き、**Region入力があること**を確認します。Region入力がない場合、この方法をそのまま使うことはできません。
2. rPlaneを追加し、Regionを受け取る入力へ接続します。画像など処理対象のデータを渡す経路と、rPlaneから領域を渡す経路は分けて考えます。
3. 接続先の結果をViewerに表示し、rPlaneのTransformに相当する調整を少し動かします。効果の位置や範囲に変化があるか確認します。
4. Softnessを変更して境界の変化を見比べ、Invertに相当する調整で対象範囲がどう切り替わるかを確かめます。
5. rPlaneを一時的に切り離した場合と比較します。変化が見られなければ、接続先がRegionを受け付けているか、効果自体が現在の映像で見える状態かを先に確認します。

この例で確認するのは「領域情報を別経路で渡す」という仕組みです。rPlaneだけをMediaOutへつないで板状の画像が描かれることは期待しません。

## 関連ツールとの違い

| ツール | 役割 |
| --- | --- |
| [rPlane](./rplane) | 平らなカード状のRegionを作る。 |
| [rCube](./rcube) | 箱状のRegionを作る。立方体のCGモデルを描画するツールではありません。 |
| [rSphere](./rsphere) | 球状のRegionを作る。 |
| [rNoise](./rnoise) | Perlinノイズを使ったRegionを作る。均一な幾何形状とは異なる範囲の候補です。 |
| [rTransform](./rtransform) | すでにあるRegionの変形を担当する別ツールです。 |
| [rModify](./rmodify) / [rMerge](./rmerge) | Regionの変更、複数Regionの統合を担当します。 |

rPlane自身にもTransform系の調整があるため、単純に範囲を調整するだけなら、まずrPlane内で必要な操作ができるか確かめます。複数のRegionを組み立てたり、領域の変形工程を分けて管理したりするときは、上記の別ツールを検討します。ただしrMergeの合成方式やrModifyの具体的な変更メニューを、名称だけから決めつけることはできません。
