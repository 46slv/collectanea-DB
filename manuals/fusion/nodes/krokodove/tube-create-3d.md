# Tube Create 3D

**Tube Create 3Dは、決められた経路に沿って管のような3D形状を作る**Krokodoveのツールです。針金を曲げたときの通り道を中心線と考え、その線に沿って厚みのある立体が続く様子を想像すると、役割が分かりやすくなります。

DaVinci Resolve 21.1 Reference Manualが明記しているのは、「指定した経路に沿う管状の3D形状」を作ることと、断面の選択肢に `Polygon` と `Star` があることです。経路をどう編集するか、実際の端子やInspectorの項目名は、この説明だけでは確定できません。

## 経路と断面は何を決めるか

このツールで区別するのは、**管がどこを通るか**と、**管を輪切りにしたときにどんな形か**です。

| 要素 | 意味 | 見た目への関係 |
| --- | --- | --- |
| 経路（Path） | 管の中心がたどる道筋。 | 立体が空間のどこを通り、どの方向へ伸びるかに関係する。 |
| 断面（Profile） | 管を進行方向と交差する向きに切ったときの輪郭。 | 同じ経路でも、外周の形が変わる。 |
| `Polygon` | 多角形を基準にする断面の選択肢。 | 角を持つ輪郭の管を考えるときの候補。 |
| `Star` | 星形を基準にする断面の選択肢。 | 星形の輪郭を持つ管を考えるときの候補。 |

たとえば、曲がった経路を固定したまま断面だけを変えれば、道筋は同じでも外形の異なる立体を比べられると考えられます。ただし、**断面の辺数・尖り具合・太さを個別に調整できるか、どの項目で切り替えるかは未確認**です。

「pipe-style」というManualの表現は管に似た外形を指します。内側に空洞があるメッシュかどうかまでは保証しません。2Dの線を太く描く処理と、3D空間に立体を生成する処理も区別してください。

## 入力と出力

| 段階 | 確認できること | まだ確認できないこと |
| --- | --- | --- |
| 経路の指定 | 形状が「指定された経路」に沿うことは21.1 Manualに記載されている。 | 経路をInspector内で描くのか、外部のPath／Shape／3Dデータから受け取るのか。 |
| その他の入力 | 必須の画像入力について、該当するManualの説明はない。 | 入力端子の正式名称、本数、マスクや材質を接続できるか。 |
| 生成結果 | Krokodoveの「3D Create」に分類され、管状の立体を生成する。 | 出力端子の正式名、材質やUV、メッシュ構造。 |

このページの `outputs: [classic-3d]` は、既存カタログが採用している**3D形状の分類**です。実機で確認した端子仕様ではありません。

Fusionの<Term id="classic-3d">Classic 3D scene</Term>は立体やカメラなどを扱うデータです。<Term id="image">Image</Term>は画素を持つ2D画像で、同じ種類のデータではありません。Tube Create 3Dを3Dシーンとして後段へ接続できる場合、最終的に画像として表示・合成するには[Renderer 3D](../3d/renderer-3d)などで2D画像へ描画する段階が必要です。**Tube Create 3Dから標準3Dノードへの実際の接続互換性は未検証**です。

## 主な用途

### 曲がったパイプ状の装飾

画面の奥行きに沿って伸びるパイプや、曲線状の立体をデザインするときの候補です。経路に沿って管が作られるという確認済みの役割を利用する制作案であり、任意の曲線データをそのまま読み込めることまでは確認していません。

### 星形の断面を持つ抽象グラフィック

同じ道筋に対し、多角形と星形の断面を比較する使い方が考えられます。断面の輪郭が変われば、斜めから見た外形や光の当たり方にも違いが出る可能性があります。ただし、ライティング、表面の滑らかさ、法線の処理について、このツール固有の実測はありません。

### 立体的なタイトル背景の素材

タイトルの背後に管状のオブジェクトを配置し、カメラの向きや照明を変えて奥行きを見せる構成も考えられます。タイトル文字を自動で管に変換したり、文字の輪郭を経路として取り込んだりする機能があるとは確認していません。

## 最小確認：断面だけを変えて比べる

次は、Manualで確認できる機能から組み立てた**実機確認の手順案**です。正確なInspector操作や端子配線を再現済みのレシピではありません。

1. FusionでTube Create 3Dを追加し、Inspectorに表示される経路関連の操作と入出力端子を確認します。経路の指定方法はManualの該当箇所に記載されていないため、外部ノードの接続を前提にしません。
2. 単純で見分けやすい経路を一つ設定できたら、いったん固定します。管の通り道と断面の変化を混同しないためです。
3. Profileに相当する選択肢が確認できた場合は、`Polygon` と `Star` を切り替えます。**経路を変えずに断面の違いだけを見る**ことが目的です。
4. 出力が標準Classic 3Dとして接続できることを確認できた場合に限り、[Merge 3D](../3d/merge-3d)でカメラなどと組み合わせ、Renderer 3Dで描画します。接続できなければ、このツール固有の出力型を先に調べます。
5. 正面からの外形だけでは差が分かりにくい場合は、視点を変えて断面の輪郭を観察します。経路自体の変化と、断面を変更した結果を別々に記録します。

3D出力が標準ノードと互換だった場合に試す構成は次のとおりです。**Tube Create 3Dの正式な配線図ではありません。**

```text
Tube Create 3D ──(3D接続を確認した場合)──→ Merge 3D → Renderer 3D → MediaOut
                                      ↑
                           必要に応じてカメラなど
```

単に「立体が生成される」ことと「その立体が2D画像として表示される」ことは別です。Viewerで期待した結果が出ない場合は、形状生成と描画のどちらまで動いているかを分けて確認します。

## 似たツールとの違い

| ツール | 21.1資料などで確認できる役割 | 選ぶ目安 |
| --- | --- | --- |
| **Tube Create 3D** | 経路に沿う管状3D形状を作る。断面はPolygon／Star。 | 道筋に沿って続く立体が必要なとき。 |
| [Heightfield Create 3D](./heightfield-create-3d) | 画像の輝度で平面の奥行きに起伏を作る。 | 明暗に応じた地形状の面を作りたいとき。 |
| [Fold Create 3D](./fold-create-3d) | 平面の区画を定めた順序で折り動かす。 | 折れるカードのような動きが必要なとき。 |
| [Mapped Duplicate 3D](./mapped-duplicate-3d) | オブジェクトを3D格子状に複製し、画像による制御も扱う。 | 同じオブジェクトを多数配置したいとき。 |
| [Connect 3D](./connect-3d) | 21.1公式発表では頂点間に接続を作るツールとされる。 | 頂点同士をつなぐ用途を検討するとき。 |

Tube Create 3Dの「経路」と、Connect 3Dの「頂点間の接続」は同じ機能だと確認されていません。また、2Dの[Connect](./connect)が作る線をTube Create 3Dへそのまま渡せるという根拠もありません。

## 注意点と検証状況

- **経路の編集方法**：Pathの追加・削除、ポイント数、閉じた経路への対応、外部からの経路入力は未確認です。
- **Inspector**：Polygon／Starという断面の選択肢以外に、正式なControl名、初期値、太さ、断面の頂点数、分割精度、アニメーションの可否は確認していません。
- **出力**：端子名、標準3Dとの互換性、空洞の有無、表面のUV・法線・材質の扱いは未検証です。
- **製品差**：DaVinci Resolve Free／Studio／Fusion Studio間の提供条件、内部REGID、21.1実機での表示は確認していません。
