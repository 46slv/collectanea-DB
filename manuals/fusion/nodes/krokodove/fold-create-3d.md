# Fold Create 3D

**Fold Create 3Dは、1枚の平面をいくつかの区画に分け、区画ごとに決まった順番で折る**Krokodoveの3Dツールです。紙を小さなパネルに分けて、端から順に開いたり閉じたりするような動きを考えると分かりやすくなります。

平面全体を1つの板として回転させる動きとは異なり、分割された部分ごとに折るアニメーションが働きます。DaVinci Resolve 21.1 Reference Manualが明記しているのは、**平面のポリゴンを事前に決められた順序で折り、各分割面のアニメーションを独立させる**ことです。

ここでの「ポリゴン」は平面を構成する小さな面、「分割面」はそのうち折り動作を持つ区画を指します。写真を格子状に並べる処理でも、画面全体に同じ回転をかける処理でもありません。

## 何を変えるツールか

折り始める前の平面には、隣り合った区画があります。Fold Create 3Dで折り動作を付けると、それぞれの区画が時間の経過とともに異なる向きを持つような演出を作れます。

このツールを理解するときは、次の3点を分けます。

| 要素 | 見るところ | 意味 |
| --- | --- | --- |
| 面の分割 | 平面がいくつの区画に分かれて見えるか | どの部分が個別に折れるかを決める考え方 |
| 折る順番 | 最初に動く区画と後から動く区画 | 全体が一度に倒れる動きとの違い |
| 区画ごとの折り動作 | 動き始め・向き・動き終わりの違い | 各分割面に独立したアニメーションがあるという特徴 |

上の表は**見た目を観察するための整理**です。これらと同名のInspector項目があることや、任意の順番・角度を数値で指定できることを示すものではありません。

## 入力と出力

| 段階 | 21.1 Manualから分かる役割 | まだ確認できないこと |
| --- | --- | --- |
| 元になる面 | 「image plane」の分割面を折る3D Createツール。 | 平面をツール内部で生成するか、外部画像や3D平面を入力できるか。入力端子の名前・本数・必須条件。 |
| 折る処理 | ポリゴンをあらかじめ定められた順番で折り、分割面ごとにアニメーションする。 | 分割数、開始時刻、折る角度、順番の指定方法と正式なInspector項目。 |
| 生成結果 | 折り動作を持つ3D平面として説明され、Krokodoveの「3D Create」に分類される。 | 正式な出力端子名、材質・UV・Alphaの保持、標準3Dツールとの接続互換性。 |

記事メタデータの `outputs: [classic-3d]` は、リポジトリ内で3D生成結果を探すための分類です。<Term id="classic-3d">Classic 3Dシーン</Term>は形状や位置などを扱うデータで、画素を持つ2D画像とは違います。Fold Create 3Dの接続端子の種類を実機で確定したという意味ではありません。

なお、Manualの「image plane」は折る対象の平面を指す表現です。Fusionの標準ノードである[Image Plane 3D](../3d/image-plane-3d)を必ず接続する、という記述ではありません。

## 主な用途

### 順番に開くカード状の背景

いくつかのパネルが端から順に開いて背景を見せる、というモーショングラフィックスの候補です。同じ場所に置いた1枚の板を回すよりも、どの部分が先に開いたかを見せやすい構造です。実際に画像や動画を各面へ貼れるかは、別途確認が必要です。

### 複数区画で構成された画面転換

1枚の面が区画に分かれて折れる動きを、画面切り替えの前景として使う構成が考えられます。ただし、切り替え前後の映像を直接入力できる機能を確認したわけではありません。トランジションとして使う場合、必要な映像合成は後段で組み立てます。

### 折り紙・シャッター風の立体演出

区画が別々に向きを変える様子を斜めから撮ると、立体として折れていることが伝わりやすくなります。面の厚み、蝶番、物理的な折り目の再現などはManualの記述だけでは保証できません。

## 最小構成を考える

まずは**Fold Create 3Dの生成結果を単独で3D Viewerに確認できるか**を調べます。そのうえで標準のClassic 3Dノードと接続できることを確かめられた場合、一般的な3D描画の流れは次のようになります。

```text
Fold Create 3D ────┐
Camera 3D ─────────┼→ Merge 3D → Renderer 3D → 2D画像
（必要ならLight）─┘
```

これは**接続を実証した完成レシピではなく、確認のための構成図**です。[Merge 3D](../3d/merge-3d)で立体とカメラを同じシーンへまとめ、[Renderer 3D](../3d/renderer-3d)で2D画像に変換する部分は標準Classic 3Dの仕組みです。Fold Create 3Dがその入力に直接つながるかは実機で確認します。

1. Fold Create 3Dを追加し、単独の3D表示と時間変化を確認します。
2. 折る区画が判別できる構図を選び、平面全体が動いているのか、一部分ずつ動くのかを見ます。
3. 前後の時間を比べ、区画の動き出す順序を観察します。
4. 標準3Dノードへの接続が成立する場合だけ、[Camera 3D](../3d/camera-3d)とRenderer 3Dを使って画像化し、映像合成へ渡します。

## 似たノードとの違い

- [Heightfield Create 3D](./heightfield-create-3d)は、画像の明るさで平面の奥行き方向の起伏を変えるツールです。Fold Create 3Dは**区画を折って動かすこと**に注目します。
- [Mapped Duplicate 3D](./mapped-duplicate-3d)は、3DオブジェクトをX・Y・Z方向に複製し、画像で複製の変化を制御します。平面を折る動きそのものとは目的が違います。
- [Transform 3D](../3d/transform-3d)は、3Dの物体やシーン全体を移動・回転・拡大縮小します。Fold Create 3Dのように分割された面を順に折る専用の処理ではありません。
