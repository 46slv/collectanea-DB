# Fold Create 3D

Fold Create 3Dは、平面を小さな面に分け、その面を決まった順序で折り動かすKrokodoveの3D生成ツールです。1枚のカード全体を回転させるのではなく、カードをいくつかの区画に分け、それぞれが順に開いたり閉じたりするような動きを作ります。

ここでいう**分割面（subdivision surface）**は、平面を構成する個々の小さな面です。たとえば紙を4つの区画に分けたと考えると、紙全体が同時に回る動きと、区画が順番に折れる動きの違いを想像できます。この「4区画」は仕組みを説明するための例で、実際の分割数や折る方向の選択肢を示したものではありません。

21.1 Manualで確認できるのは、**平面を生成すること、面ごとに折りのアニメーションが分かれていること、折る順序があらかじめ定められていること**です。折り目や動きのタイミングをInspectorでどこまで変更できるかは、同Manualの説明だけでは確定できません。

## 入力と出力

| 項目 | 役割 | 確認状況 |
| --- | --- | --- |
| 生成する内容 | 折り動作を持つ3D平面 | 21.1 Manualに記載 |
| 出力の用途 | <Term id="classic-3d">Classic 3D</Term>のシーンとして描画する | 3D生成ツールとしての分類と一般的なFusion 3Dの構成に基づく |
| 外部画像などの入力 | 画像を直接受け取るか、表面へ貼れるかは不明 | 端子名・本数ともに未確認 |

平面そのものは3Dの形状なので、画像用のMergeやBlurへそのまま渡す前提にはしません。通常の2D合成で使うには、[Renderer 3D](../3d/renderer-3d)で画像へ変換する工程が必要です。

## どういう動きを作るのか

通常の[Transform 3D](../3d/transform-3d)で平面を回転させると、平面全体がひとまとまりとして動きます。Fold Create 3Dでは、平面の中にある複数の面が、それぞれ折りのアニメーションを持つ点が異なります。

カードのような図形を段階的に見せるモーショングラフィックスが、用途として考えられます。観察するときは、**平面全体の向きが変わっているだけなのか、隣り合う面の角度が別々に変わっているのか**を見ると違いが分かります。

「決められた順序」とはManualが説明するノードの動作であり、ユーザーが任意の順番を指定できるという意味ではありません。順序の編集方法や、各面の開始・終了時刻を個別指定できるかは未確認です。

## 確認用の構成例

まず複雑な素材を用意せず、Fold Create 3Dで作られる平面の形と時間変化を観察します。Fusionの3D Viewerで形状を確認し、異なるフレームを表示して、どの区画が先に折れるかを見比べる方法が考えられます。

2D画像として動作を確認するときの構成は、次のようになります。

~~~text
Fold Create 3D → Renderer 3D → Merge → MediaOut
                                  ↑
                          背景画像（MediaIn）
~~~

これは**データの流れを示す概念図**です。Fold Create 3D固有の端子配置や、実機での直接接続までは確認していません。必要なら[Camera 3D](../3d/camera-3d)などを含む3Dシーンを[Merge 3D](../3d/merge-3d)で構成し、Renderer 3Dから平面を見やすい角度で描画します。

確認の順番としては、次のように進めると動きの違いを把握しやすくなります。

1. まず時間を変えて、平面のどの区画が動くかを見る。
2. 次に視点を斜めにして、区画同士の角度が変化しているかを見る。
3. 最後に2D画像へ描画し、実際の背景映像との重なり方を確認する。

この手順は**Manual記載の正式な操作手順ではなく、役割を理解するための観察例**です。Inspectorの項目名、既定値、折り方の種類を推測したものではありません。

## 関連ツールとの違い

| ツール | 作るもの・動かすもの | 使い分け |
| --- | --- | --- |
| **Fold Create 3D** | 分割した平面の面ごとの折り動作 | カードが順番に開閉するような表現 |
| [Image Plane 3D](../3d/image-plane-3d) | 2D画像を3D空間に置いた平面 | 写真や映像を3Dシーン内に配置する。分割面の順次折り動作とは別 |
| [Heightfield Create 3D](./heightfield-create-3d) | 画像の明るさで高さが変わる平面 | 高低差のある地形やパネル状の起伏 |
| [Tube Create 3D](./tube-create-3d) | 経路に沿った管状の3D形状 | 線状の装飾やパイプ状の形 |

特にHeightfield Create 3Dは、面を**折る**のではなく、画像の明るさによって面の**奥行きを変える**点が異なります。
