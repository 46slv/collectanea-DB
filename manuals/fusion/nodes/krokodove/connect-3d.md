# Connect 3D

**Connect 3Dは、3D空間にある頂点同士の接続を作るKrokodoveのツール**です。Blackmagic DesignのDaVinci Resolve 21.1発表では、頂点間の接続（vertex connections）を作る新しい3Dツールとして紹介されています。

たとえば立方体の角を考えると、角の位置が「頂点」、角同士を結ぶ部分が「辺」です。Connect 3Dを理解するときは、画像の上に線を手描きするのではなく、**3D空間に置かれた点と点の関係を扱う**ものとして考えます。ただし、立方体のすべての角を自動的に結ぶ、という動作まで公式発表で保証されているわけではありません。

## 頂点を接続するとは

3Dの**頂点（vertex）**は、形を構成する位置を表す点です。位置は左右・上下に加えて、手前と奥を含む三つの方向で決まります。複数の頂点を結ぶと、空間内の点同士の関係を線のように捉えられます。

四つの頂点A・B・C・Dがある場合、「AとB」「BとC」「CとD」をつなぐのか、「Aから残りすべて」をつなぐのかで、できる構造は変わります。この例は接続の概念を説明するもので、Connect 3Dにその接続方法を選ぶ機能があると確認したものではありません。

重要なのは、**点を用意すること、点同士の接続を決めること、画面へ描画することは別の段階**だという点です。Connect 3Dについて公式発表で確かめられるのは、頂点間の接続を作るという役割までです。どの頂点をつなぐか、接続を線・管・別の形のどれとして出力するか、線幅や材質を設定できるかは分かっていません。

## 入力と出力：分かっている範囲

| 段階 | 確認済みのこと | 未確認のこと |
| --- | --- | --- |
| 接続対象 | 3Dの頂点に対して接続を作る役割。 | 対応する3Dオブジェクトや頂点データの種類。 |
| 入力 | 頂点情報が処理に関係する。 | 正式な入力端子名・端子数、必要な前段ノード、複数入力の有無。 |
| 処理 | 頂点と頂点の接続を作る。 | 距離・接続順・隣接関係など、接続を決める条件とInspector項目。 |
| 出力 | 頂点接続の結果を扱う。 | 出力データ型、正式な端子名、線・面・形状としての表現方法。 |

「3Dツール」という紹介だけでは、**出力が必ず通常のClassic 3Dシーンであるとは断定できません**。このためfrontmatterへ推測したinputs / outputsを記入していません。端子名と接続できるデータ型を実機で確認したうえで、後段のノードを選びます。

一般にFusionのClassic 3Dでは、3Dシーンを[Renderer 3D](../3d/renderer-3d)で2D画像へ変換します。しかし、Connect 3DからRenderer 3Dへ直接つなげるかは未確認です。標準の3D処理経路を、Connect 3Dの確認済み仕様と混同しないでください。

## 主な用途として考えられるもの

### 3Dの骨組みやネットワーク表現

離れた頂点同士の接続を可視化できるなら、立体的なワイヤー構造やネットワークのグラフィックを設計する候補になります。2Dの線画とは違い、頂点を手前と奥に配置できることが3D表現の特徴です。

ただし、**任意の点を自由に結べることや、接続が必ず描画可能な線になることは未検証**です。これは公開された基本機能から考えた制作案です。

### 動く形状のつながりを調べる

元となる3D形状を動かしたとき、接続がどのように更新されるかを調べる用途も考えられます。頂点が動いても同じ組み合わせが維持されるのか、毎フレーム計算し直されるのかによって見た目は変わります。時間変化への対応は公式発表に書かれていないため、静止した形状で基本動作を確かめてから試すのが適切です。

## 最初に確認する手順

以下は**資料にない仕様を実機で確かめるための検証案**です。Connect 3Dの個別端子やInspectorを実際に確認したチュートリアルではありません。

1. FusionのSelect ToolなどでConnect 3Dを探し、表示名と登録状態を確認します。名前の似た2DのConnectを選ばないようにします。
2. ノードの入力と出力を確認します。接続できるデータの種類と、入力端子が複数あるかを把握します。
3. 通常の3D形状を入力できることを確認できた場合だけ、[Cube 3D](../3d/cube-3d)のように頂点の位置を想像しやすい単純な形状を試します。接続できなければ不具合と決めつけず、要求されるデータ型を確認します。
4. Connect 3Dを通す前と後で、何が変わったかをViewerで比較します。頂点数や形状を一度に大きく変えず、観察する項目を絞ります。
5. 出力がClassic 3Dとして扱えることを確認できた場合だけ、[Merge 3D](../3d/merge-3d)やRenderer 3Dを後段に置き、画像化できるか試します。接続できない場合は、別の出力型や変換が必要かを調べます。

~~~text
3D頂点を含む素材（実際の対応型を確認）
               ↓
          Connect 3D
       （頂点間の接続を作る）
               ↓
       出力型を確認する
               ↓
       対応する後段・Viewer
~~~

この図は**考え方を示す概念図**であり、実機で確定した端子の接続図ではありません。正確な端子名、接続規則、Inspectorの数値は資料で確認できていないため記載していません。

## Connectやほかの3Dツールとの違い

| ツール | 確認できる役割 | 選ぶときの考え方 |
| --- | --- | --- |
| **Connect 3D** | 3Dの頂点同士に接続を作る。 | 空間内の点のつながりを扱う。 |
| [Connect](./connect) | 個別に位置を指定した2Dの点を一本の連続線で結ぶ。 | 画面内に経由点を通る線を描く。 |
| [Tube Create 3D](./tube-create-3d) | 指定した経路に沿って管状の3D形状を作る。 | 経路に沿う管の形が欲しい。 |
| [Mapped Duplicate 3D](./mapped-duplicate-3d) | 3DオブジェクトをX・Y・Z方向に複製し、画像で変化を制御する。 | 同じ立体を大量に配置する。 |

Connectは21.1 Reference Manualの**Image Tools**に掲載され、2Dの点を連続線で結ぶツールと説明されています。Connect 3Dとは**扱う空間と確認できる役割が異なる別ツール**です。2D Connectの点編集UIや描画設定をConnect 3Dに転記する根拠はありません。

Tube Create 3Dは「経路に沿う管を作る」ツールです。頂点の接続を作るConnect 3Dとは役割が違い、**両者を直接接続できるという根拠もありません**。

## 対応バージョンと出典

**役割の一次資料**：Blackmagic Design「[Blackmagic Design Announces DaVinci Resolve 21.1](https://www.blackmagicdesign.com/media/release/20260908-03)」（2026年9月8日）。Fusionへ追加されたKrokodoveの3DツールとしてConnect 3Dを挙げ、頂点の接続を作ると説明しています。

**Reference Manualとの関係**：Blackmagic Design『DaVinci Resolve 21.1 Reference Manual』（September 2026）、Chapter 105「Krokodove Nodes」、pp.2433–2438。ここでは**2D Connect**やTube Create 3Dを確認できますが、Connect 3Dについて独立した詳細説明は確認できません。Manualの一覧に見当たらないことは、実機に存在しないという意味ではありません。

**未確認**：実機でのREGID・表示名、入出力型と端子数、頂点の接続方法、接続の描画・材質、Inspectorの項目名・既定値・数値範囲、キーフレーム動作、Resolve Free / Studio / Fusion Studio間の提供差。公式発表で分かることと制作案を区別するため、verification: partialを維持しています。
