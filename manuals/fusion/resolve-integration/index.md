# Resolveとの連携（Resolve Integration）

Fusionは独立した考え方を持つNode-based compositorですが、DaVinci Resolveの中ではEdit / Color / Fairlight等と同じprojectを共有する作業ページです。

この章はFusionのNode説明ではなく、**その仕事をどのPageへ置くか**を判断するために使います。
